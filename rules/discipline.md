# 个人投资纪律

> 血泪教训换来的规则，不是感悟。
> 违背任何一条，系统都阻止你 — 不阻止就是系统失职。

---

## 规则一：不接飞刀（左侧买入控制）

**为什么：** 买入后长期浮亏的痛苦损失比金钱更大。好公司 + 坏时机 = 长期折磨。
但一刀切"禁止左侧买入"会杀死逆向价值投资。好公司暴跌正是价值投资者该出手的时候。

### 三级规则

| 级别 | 条件 | 动作 |
|:----|:-----|:-----|
| 🔴 **硬拦截** | MA50<MA120 + **基本面恶化**（FCF持续为负、ROE下降、营收萎缩、D/E恶化） | **禁止买入** |
| 🟡 **条件通过** | MA50<MA120 + **真价值 + 极端估值**（PE<历史20%分位或PB<1或股息率>5%） | **可买入，但必须 DCA 分步，初始不超过上限的50%** |
| 🟡 **条件通过** | 跌幅超过 70% + Vibe-Trading 确认止跌企稳（MACD底部金叉+量能放大） | **可买入，但必须 DCA** |
| 🟢 **PASS** | MA50≥MA120 或 Vibe-Trading 确认趋势右侧 | **正常买入** |

### 判断逻辑

```
不接飞刀 ≠ 永远不接。接的姿势决定风险。

质地普通 + 暴跌 → 🔴 不接。核心风险在公司本身。
好生意 + 暴跌 → 🟡 结构性地接（DCA+仓位上限）。
趋势右侧 → 🟢 正常接。
```

**退出信号：** 如果买入后继续下跌超过 15%，启动研究验证。如果不是基本面变化 → 继续持有；如果是价值陷阱 → 割。

## 规则二：不蹭热点（禁止 FOMO 买入）

**为什么：** 2020 年科技股追高的教训。涨了看涨是人性，不是分析。

**条件检查：**
- ❌ 该标的上月涨幅 > 30% → 禁止买入（等回调至少 10%）
- ❌ 周围朋友/社交媒体/财经新闻都在讨论 → 增加警惕
- ❌ 券商研报最近一个月集中发布"买入"评级 → 反向指标 (卖方天然看多，计-1 分)

**执行：** 检查财经媒体情绪指数 > 70% → 观望。情绪指数 < 30% 才是最舒服的买入区间。

## 规则三：不信噪音（过滤垃圾话）

**为什么：** 券商和普通人是"涨了看涨，跌了看跌"。他们的意见不是分析，是情绪的滞后指标。

**具体过滤标准：**
| 噪音来源 | 过滤方式 | 权重调整 |
|---------|---------|---------|
| 券商研究报告 | 买入评级自动减权。只看其陈列的数据，不看其结论 | -1 分 |
| 财经媒体头条 | 如果所有媒体都在说同一件事 → 反向信号 | -1 分 |
| 社交媒体讨论热度 | 大面积讨论 → 情绪过热 | -1 分 |
| 朋友/同事推荐 | 一般是最危险信号，说明连圈外人都进场了 | -2 分 |

**核心原则：** 水则资车，旱则资舟。
> 洪水的时候准备车（等水退了大家需要车），干旱的时候准备船（等下雨了大家需要船）。
> 但注意：一直旱就出大事了。逆向布局的前提是判断"旱"是暂时的，不是永久荒漠。

## 规则四：识别真价值 vs 假价值

**为什么：** 有些东西看上去有价值，实际上没有。白酒大多数人觉得难喝，"价值"只是上涨带来的幻觉。价格在涨 ≠ 有价值。

**假价值判断：**
- 该资产没有真实消费需求支撑（靠"升值预期"维持价格）
- 主要买家是为了"涨价才买"，不是因为产品本身好
- 没有替代品？不，只是大家还没去找替代品
- 没有现金流回报（无股息、无租金、无利润分配）

**真价值判断：**
- 有真实的消费需求（不管价格涨跌，都有人买来用）
- 能产生持续现金流（股息、利润、租金）
- 在不好看的时候也有价值（"旱的时候船也还是船"）

## 规则五：价值投机识别（为重大的机会预留空间）

**为什么：** 2020 年电动车、2023 年 AI 的上涨，一部分是投机，一部分是价值创造。
一个真实的技术革命在发展初期往往以"泡沫"的形式呈现 — 但如果底层价值确实存在，这不是赌博。

**识别标准：**
- 🟢 **纯投机**（不参与）：meme 币、无基本面题材、微盘股炒作、零营收概念
- 🟡 **价值投机**（可考虑但设止损）：技术突破真实存在 + 长期价值路径清晰 + 短期涨幅主要由情绪驱动
- ✅ **典型特征**：
  - 有真实的营收/用户/技术突破支撑
  - 不是零和博弈（价值在创造，不是在转移）
  - 赛道足够大（千亿级市场）
  - 但短期情绪过热，透支了 1-2 年的涨幅

**参与条件（全部满足才行）：**
1. 确认底层价值存在（有营收、有技术、有不可替代性）
2. 只拿计划仓位的 50%（另一半等泡沫消化后）
3. 设 20% 硬止损
4. 持有期不超 6 个月
5. 如果 3 个月内没涨 → 退（说明判断错了）

## 规则六：技术分析辅助（量价关系优先）

**为什么：** 价值投资容易忽略技术面，但量和价是市场用真金白银投票的结果，成功率高于纯技术指标。

**必看的几个技术信号（按成功率排序）：**
| 信号 | 成功率 | 说明 |
|------|:------:|------|
| 放量突破关键阻力位 | 高 | 量能验证突破真实性 |
| 缩量回踩支撑位不破 | 高 | 抛压衰竭，容易反弹 |
| MACD 底部金叉 | 中高 | 但需放量配合 |
| RSI 超卖反弹 | 中 | 可能在空头趋势中被反复超卖 |
| 布林带下轨反弹 | 中 | 单边下跌趋势中不可靠 |

**用法：**
- 只在趋势扫描（Vibe-Trading）中使用技术指标
- 不进价值评估环节（不因"技术面好"就认为生意好）
- 量价关系优先于纯价格指标
- 成功率低的技术信号忽略，不用硬凑

## 通用仓位纪律

| 类型 | 上限 | 说明 |
|------|:-------:|------|
| 单只标的（个股/ETF 同规则） | 20% 🔴 / 15% 🟡 | 占总资产（含资金池）口径，超黄线关注、超红线超配 |
| segment 轴（细分板块） | 25% 🔴 / 20% 🟡 | 细分到风险驱动（如 半导体.AI算力 ≠ 半导体.存储） |
| market 轴 | 35% 🔴 / 28% 🟡 | 家国市场暴露 |
| 资金池（真现金+准现金） | 无硬底线 | 低波高息等准现金当现金用；建议 ≥15% 参考，进资金池不参与权益集中度 |
| 融资/杠杆 | **0%** | 任何时候。没有例外。 |
| 做空 | **0%** | 不做空。没有例外。 |

> 阈值明细见 docs/09-portfolio.md；运行期计算 `python tools/fengportfolio.py check`。

## 买入前强制性 Checklist（缺一不可）

1. ✅ 趋势扫描通过（Vibe-Trading 确认不是下跌趋势/不是接飞刀）
2. ✅ 价值初筛通过（ai-berkshire investment-checklist 六关，见 docs/ai-berkshire-integration.md；护城河极高的可降低"好生意"权重）
3. ✅ 深度研究出报告（有估值区间和买入策略）
4. ✅ 不在 FOMO 状态（如果明天下跌 15%，还买吗？还睡得着吗？）
5. ✅ 券商/媒体没有疯狂唱多（检查规则三的噪音过滤）
6. ✅ 没有更好的替代标的（跟组合里已有持仓比，确定这只更好）

## 卖出触发条件

只允许以下理由卖出：

| 触发条件 | 动作 | 优先级 |
|---------|------|:-----:|
| 公司基本面彻底变坏（不是股价跌了） | 清仓 | 强制 |
| 买入论文证的假设被推翻 | 清仓 | 强制 |
| 发现重大欺诈/管理层问题 | 立即清仓 | 强制 |
| 价值投机买入的标的 3 个月不涨 | 退出 | 强制 |
| 价值投机止损线被触发 (-20%) | 退出 | 强制 |
| 找到明显更好的替代标的 | 换仓 | 可选 |
| 仓位超限需要再平衡 | 减仓至上限 | 强制 |
| 持有满 5 年重新评估 | 更新报告 | 惯例 |

## 永久不碰清单（Persistent Skip List）

> 与 L0 不同——L0 是"我不懂所以不看"。不碰清单是"我懂了，但我认为这是坑"。
> 每次分析后更新。一旦加入，除非有结构性变化，否则不碰。

### 加入条件（满足任一条即可）
- 经历过欺诈/财务造假
- 管理层诚信有严重问题
- 产品有不可逆的结构性衰退
- 生意模式本质有缺陷（赚不到真钱）
- 估值长期不合理但无矫正动力

### 当前清单
| 标的 | 加入日期 | 原因 | 复查条件 |
|:----|:--------|:-----|:---------|
| 金嗓子(6896.HK) | 2026-07-14 | 管理层收割(研发-88%)+失信被执行人+营收-20.4%(行业+3.85%)+结构下滑+单一产品92.6% | 管理层更换+2026年报营收企稳+应收回落 |

### 从清单移除的条件
- 结构性变化发生（新管理层、业务重组、行业复苏）
- 间隔至少 12 个月后重新分析
- 需要通过 L0 能力圈确认 + 全流程分析
- 不与已有持仓形成过高集中度
