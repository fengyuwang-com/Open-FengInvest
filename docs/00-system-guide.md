# FengInvest 系统指南（人话版）

> 写给忘了系统全貌的你。10 分钟读完，不用懂术语——每个词出现时就地解释。
> 本文只讲系统里真实存在的功能，每个命令都来自 `tools/` 实际文件。

## 1. 这系统是干什么的

**一句话**：FengInvest 是一套个人价值投资决策操作系统——从「研究一只股票」到「买入、持有、卖出、复盘」，每一步都有记录、有检查、有规矩；AI 当助手，你自己拍板。

**一个比喻**：它像一栋装了门禁的研究大楼。想研究哪家公司，必须按楼层顺序一层层走（能力圈 → 市场 → 纪律 → 量化 → 定性 → 碰撞 → 报告），上一层的检查没做完，电梯不让你去下一层。买入之后，系统帮你天天盯盘；想卖的时候，先逼你说清楚理由、检查有没有情绪上头；卖完还要写复盘。你不用记住规矩——规矩写在系统里，它替你盯着。

**两副面孔**：

- **AI 界面**：`tools/` 下的 62 个 Python 工具，研究分析时在命令行调用
- **人看界面**：`fengweb` 网站（端口 23456），看总览、持仓、日志、架构图

## 2. 十秒钟看懂：一个故事走一遍

假设你想买腾讯（0700.HK），系统会带你走一遍（研究 → 买入 → 持有 → 复盘 → 卖出）：

1. **能力圈（L0）**：先问自己——看得懂腾讯这门生意吗？不懂？直接跳过，不买。这一步防的是「别人赚了我也要」。
2. **市场（M）**：现在整个大环境适不适合买？看四盏灯：利率、估值、情绪、趋势。这层权重最低——市场不好不等于好公司不能买。
3. **硬纪律（L1）**：四灯红线检查——有没有踩「不碰」清单：看不懂的、过热的、要加杠杆的、赌财报的。踩了就出局。
4. **量化打分（L2b）**：6 个因子（质量、估值、成长、动量等）算 z-score（偏离平均水平的程度，衡量"贵不贵/好不好"的相对位置）。数据缺就 abstain——明说「这项我不知道」，不硬填。
5. **定性分析（L2a）**：投资研究小组（多个 AI agent 协作）从 4 位大师的视角看这家公司，再做会计质量检查（利润是真的吗）。
6. **碰撞（L3）**：把看多的证据和看空的证据放一起撞，专挑反方观点检查——最怕只见自己想见的。
7. **报告（L4）**：出两版：人话版（给你看）和华尔街版（正式格式），每条判断必须带数据来源。
8. **买入前先筛选**：用 `/fengscreen` 的 7 条硬指标把不够格的公司提前刷掉（宁可漏网，不可误杀）。
9. **买入后**：用 `/fengholding` 登记持仓（四段登记：记下买入理由、预期、红线）；之后 `/fengwatch daily` 天天监控，10 条退出规则触发就提醒。
10. **定期复盘**：用 `/fengreview` 把当初的买入逻辑逐条按四态检查（成立 / 弱化 / 受损 / 破裂），并给每条预期做 outcome 判定（兑现了没有）。
11. **卖出**：用 `/fengexit` 先查触发源、分类理由、检查有没有偏误，再执行；卖出后把本金滚回资金池（滚存），最后再做一次卖出复盘。

全程有一个**状态机**（流程管理员）卡着顺序：八层必须按序走完，跳步自动拦截；工具坏了就修工具，不许手工填结果。

## 3. 七层 + 组合层：框架总表

| 层 | 人话 | 干什么 | 谁产出 |
|:---|:-----|:-------|:-------|
| **L0 能力圈** | 只做看得懂的 | 不懂的行业直接跳过，不研究 | `/fengstate skip` |
| **M 市场** | 现在适合买吗 | 四盏灯：利率 / 估值 / 情绪 / 趋势（权重最低） | fengdata.py + 搜索 |
| **L1 硬纪律** | 踩红线了吗 | 四灯红线：不碰看不懂的、过热的、加杠杆的、赌财报的 | fengrule.py |
| **L2b 量化** | 数据怎么说 | 6 因子 z-score 打分，缺数据 abstain | fengquant.py |
| **L2a 定性** | 生意好不好 | 6 灯 + 会计检查 + 大师视角（多 agent 小组） | investment-team |
| **L3 碰撞** | 多空撞一撞 | 看多 / 看空证据对撞 + 反方检查 | fengcollision.py |
| **L4 报告** | 写给人看的结论 | 两版报告（人话版 / 华尔街版），每条带来源 | AI 写作 |
| **P 组合层** | 我的钱怎么摆 | 三轴盘面 + 资金池 / 资金墙 + 实时汇率 | fengportfolio.py |

**P 层（组合层）细节**：每笔持仓打三个正交标签——市场（A股 / 港股 / 美股…）、板块、现金属性（真现金 / 准现金）。风险集中度按这三个方向分别算，互不混淆；资金池分境内、境外两个池子；**资金墙 = 买入预算**（这层还能买多少钱），它不是风险指标；跨币种按实时汇率折算成人民币。

状态机常用命令（`research/state/` 下的状态文件是唯一依据，只能经它修改）：

```bash
python tools/fengstate.py init 0700.HK     # 开始研究这只股票
python tools/fengstate.py status 0700.HK   # 看到哪一层了
python tools/fengstate.py skip 0700.HK     # L0 不懂 → 全层跳过，不买
python tools/fengstate.py verify 0700.HK   # 全量验证 + 跨层一致性检查
```

## 4. skill：什么时候用哪个

skill 是装在系统里的「工种」，按一只股票的完整生命周期接力：

| 阶段 | 用哪个 | 干什么 |
|:-----|:-------|:-------|
| 批量选股 | `/fengbatch` | 自动筛一批：公开list（中证红利/纳指100/SCHD…）→ 规则粗筛 → 规则精筛 → 幸存者名单 → 逐只七层分析 → 汇总报告 |
| 买入前 | `/fengscreen` | 去劣筛选：7 条硬指标 + 3 条豁免，宁可漏网不可误杀 |
| 买入前 | `/fenginvest <TICKER>` | 完整七层分析（就是第 2 节的故事） |
| 持有期 | `/fengholding` | 登记持仓 / 检查持仓 / 后管理（滚存检测） |
| 卖出 | `/fengexit <TICKER>` | 触发源识别 → 理由分类 → 偏误自查 → 执行卖出 |
| 复盘 | `/fengreview <TICKER>` | 四态检查 + outcome 判定 + 健康度评分，写回记录并推进下次回顾日期 |
| 论断验证 | `/fengverify <论断号>` | 喊一句人话验证某个投资论断：引擎算数 → 12 项协议打标 → 出一张白话论断卡 |

接力顺序：**研究（screen → invest）→ 买 → 持有（holding）→ 卖（exit）→ 复盘（review）**，然后继续持有，循环。在聊天里直接输入 `/xxx` 就能召唤对应 skill。

表外还有几件事，同样在聊天里可用（它们不在上面的接力链里，但随时能喊）：

- **验证论断**：`/fengverify 验证 1 号论断`。系统自己跑回测（`tools/backtest_core.py` 负责算数 + `000-claims-def.md` 提供论断配方），按 12 项协议（判据对齐 / 复权 / 成本 / 显著性 / 样本外 / 幸存者 / 文献对标 / A股制度……）打红绿灯，最后给一张**不懂代码的人也能读懂的白话论断卡**——5 秒扫红绿灯（✅🟡❌❓）、30 秒看懂方法、想抠细节再看证据链。
- **两条钱包轨道**：买入分两种，互不混用。**价值买（INVESTMENT）** 走上面七层框架、论文止损；**交易买（TRADING）** 是投机性买入（右侧突破 / 事件驱动），走 `/fengspec`，机械止损 -20%，试盘 ≤3% / 单票 ≤10% / 总仓 ≤30%。
- **观点交锋**：`/fengdiscuss`（AI 带独立判断锚跟你辩论，基于框架和事实，不随指令漂移）+ `/fengdiscusslog`（纯记录员，只客观记录讨论过程）。落档 `Discussion/`，独立于个股分析。

## 5. 数据从哪来

本地数据库 `data/market_data.db`（约 2GB，gitignored），多源汇入：

```
行情：Futu / yfinance / AKShare（东财）
        └─→ data/market_data.db
              ├─ daily_data  日线（约 1300 万行）
              ├─ indices     指数（2126 条）
              └─ dividends   分红（5.4 万条）

A股基本面：CSMAR ──→ cn_financials（35.7 万行，每行带报告期 accper + 公告日期 declare_date）
美股一手资料：SEC EDGAR（python tools/fengsec.py：10-K 年报 / 10-Q 季报 / 13F 机构持仓 / 内部人交易）
A股三表：新浪（python tools/fengdata.py 600036.SS --sina-financials，自带公告日期）
```

管理规范（2026-08-23 定稿）：本库一切批量写入必须可回滚——文件快照 + 库内 bak 表 + 分批事务为底线，SQLite session 扩展 changeset 支持按批精确撤销（invert）；对外同步只传增量 changeset 至百度网盘。详见 [DATA-MANAGEMENT.md](DATA-MANAGEMENT.md)。

**PIT 纪律（最重要的一条）**：判断「当时」对不对，只能用「当时看得到」的数据——**不许拿今天的财报去验证半年前的判断**。工具 `fengpit.py` 用双轴（事件发生日 vs 你得知日）保证这一点。

**论断验证的数据纪律**：验证一条论断，判据必须和这条论断承诺的量一致——用错了量就是**判据错位**，算出来再漂亮也是假的（#1 教训：原「年线上买更赚」按「7/7 支持」口径看着成立，复测改按承诺的度量后 ❌ 不成立）。程序结果与白话卡上的数字必须逐位一致（#4 复测纠正为 2.12x、#7 ❌、#33/#40 🟡、#42 ❓，已回写 `000-CONCLUSIONS.md`）。

## 7. 网站是干什么的

`fengweb`（TypeScript + Express + EJS），23 页，全中文界面。顶栏「⟳ 更新数据」按钮一键更新数据库（汇率→持仓现价→国际日线→财报，走 safe_batch 可回滚）；服务启动时若超过 12 小时没更新过会自动跑，之后每 30 分钟巡检一次，不用再靠跟 AI 说话来更新：

| 页面 | 人话 |
|:-----|:-----|
| 系统总览（首页） | 一屏看今天的提醒、持仓概览、市场状态 |
| 纪律执行账本（/ledger） | 信条 7"执行>判断"的镜子：论文齐备率、回顾拖欠、监控出勤、分析烂尾、红灯台账——数据算出，不是自我评分 |
| 系统架构（/system） | 上半是手工画的 Mermaid 架构图（给人看），下半是自动生成的组件关系图（`tools/system-map/` 生成） |
| 市场数据 | 指数/估值分位/利率/经济事件 + 噪音防火墙声明（信条 3：无涨幅榜无涨跌家数） |
| 持仓监控 | 10 退出规则触发情况 / 卖出 / 历史 |
| 持仓 | 总览 + 单只详情（论文卡 C 位：thesis 原文 + 证伪红线 + 假设验证 + 处置效应守卫） |
| 研究 | 历史个股分析 + 关注领域徽章（垄断性收费/资源型/成长引擎）+ L1 红灯深度价值路径核对单 |
| 知识库 | 投资大师 / 方法论 |
| 钱仓滚存 | 卖出回收本金的记录 |
| 决策日志 | 每笔决策的日志（journal） |
| 股票分析 | 输入代码出分析 |

启动方式（二选一）：

```bash
cd fengweb && npm run build && node dist/index.js
```

或者直接双击 `start-web.bat`，然后浏览器打开 `http://localhost:23456`。

   python tools/fengscreen.py --market CN --top 200

## 10. 术语速查表

| 术语 | 一句话 |
|:-----|:-------|
| 七层框架 | 研究一只股票的 7 个必经步骤：能力圈 → 市场 → 纪律 → 量化 → 定性 → 碰撞 → 报告 |
| L0 能力圈 | 只投资看得懂的行业，不懂直接跳过 |
| M 市场层 | 看整体大环境适不适合买（利率 / 估值 / 情绪 / 趋势四盏灯），权重最低 |
| L1 硬纪律 | 四灯红线：不碰看不懂的、过热的、加杠杆的、赌财报的 |
| L2b 量化 | 用数据打分：6 因子 z-score |
| L2a 定性 | 看生意本身：6 灯 + 会计检查 + 大师视角 |
| L3 碰撞 | 多空证据对撞 + 反方检查 |
| L4 报告 | 两版报告，必须带数据来源 |
| P 组合层 | 管「钱怎么摆」：三轴盘面 + 资金池 / 资金墙 + 汇率 |
| 三轴 | 每笔持仓的三个正交标签：市场 × 板块 × 现金属性 |
| 资金池 | 钱分境内 / 境外两个池子 |
| 资金墙 | 买入预算（还能买多少钱），**不是**风险指标 |
| z-score | 一个数值偏离平均水平几个标准差，衡量「贵不贵 / 好不好」的相对位置 |
| abstain | 数据不足时明说「不知道」，不硬填 |
| PIT | Point-in-Time：只用「当时能看到」的数据判断当时 |
