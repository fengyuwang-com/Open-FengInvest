图5: 卖出前检查流程

stateDiagram-v2
  [*] --> 卖出触发

  state 卖出触发 {
    [*] --> 选择卖出理由
    选择卖出理由 --> 价值回归: 价差已收敛
    选择卖出理由 --> 逻辑变了: 新信息/环境变化
    选择卖出理由 --> 纪律执行: 止损/止盈
    选择卖出理由 --> 钱仓滚存: 回收本金
    选择卖出理由 --> 情绪冲动: ⚠️ 请三思
  }

  卖出触发 --> 原则检查

  state 原则检查 {
    [*] --> 坐标原则: 卖出后对标逻辑还在吗?
    [*] --> 家国原则: 卖出方向符合国家利益?
    [*] --> 息价原则: 卖出价格合理?
    [*] --> 取舍原则: 资金有更好去处?
    坐标原则 --> 坐标结果
    家国原则 --> 家国结果
    息价原则 --> 息价结果
    取舍原则 --> 取舍结果
  }

  原则检查 --> 钱仓决策

  state 钱仓决策 {
    [*] --> 全部卖出
    [*] --> 留零成本筹码
    [*] --> 先回收本金
  }

  钱仓决策 --> 情绪检查
  情绪检查 --> 记录决策日志
  记录决策日志 --> [*]
