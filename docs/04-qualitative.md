# L2a — 定性核心（权重最高）

## 职责

通过 **Skill("investment-team")** 执行。4个AI agent并行分析。
禁止自己写定性分析代替 investment-team。

## 6个灯（固定）

| 灯 | 🟢 | 🟡 | 🔴 |
|:--|:--|:--|:--|
| 好生意 | 定价权+护城河深+现金流可预测 | 有优势但受限 | 无竞争优势 |
| 护城河 | 宽(品牌+技术+转换成本+网络效应) | 有但削弱 | 窄/无 |
| 管理层 | 优秀+利益一致 | 及格+有风险 | 差/不诚信 |
| 安全边际 | PE<历史均值20%+ 或 PE<10x 或 PB<1x 或 净现金/市值>30% | PE≈历史均值 | PE>历史均值+ |
| 需求稳定 | 消费刚性+长期增长 | 结构变化中 | 结构性下降 |
| 会计质量 | ≤2项红旗 | 3-4项红旗 | ≥5项红旗 |

### L2a 整体判定

≥3个灯🟢 + 无🔴 → 整体🟢 (好生意可接受)
其他 → 整体🟡
有🔴 → 整体🔴

"好生意"判据的两大核心是**定价权**和**护城河厚度**。ROE、FCF、利润率是验证指标不是判定标准。
Buffett 的测试：这个公司能不能在通货膨胀的环境中提价而不丢失客户？能 → 好生意。不能 → 不是好生意。

## 会计质量10项检查

1. 收入确认是否激进？
2. 折旧与资产实际损耗匹配？
3. 商誉/净资产>50%？
4. R&D/营销资本化比例突变？
5. 大额关联交易无合理解释？
6. 应收增速>营收增速？
7. 库存增速>营收增速？
8. 净利润为正但经营现金流为负？
9. 非标准审计意见？
10. 薪酬依赖单一财务指标？

## DK 扩展：息价原则 + 六步法

参考 `knowledge/principles/息价原则.md`，在每位大师分析中追加：

| 检查 | 内容 |
|:-----|:-----|
| **安全边际>30%** | 当前价格比硬资产价值低多少？ |
| **极端压力** | 持股腰斩后市值仍低于清算价值？ |
| **股息/回购** | 持有期现金回报是否充足？ |

**六步法**（补充四大师分析框架）：

1. **主营业务** — 收入从哪里来？结构稳定性？
2. **科技含量** — 研发投入占比、技术护城河
3. **重大事项** — 解禁/减持/增发/回购动态
4. **当前定价** — 市场在博弈什么？price in了什么？
5. **催化剂** — 什么能触发价值回归？
6. **管理层** — 能力圈、诚信、资本配置历史
