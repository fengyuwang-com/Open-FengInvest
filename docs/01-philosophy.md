# FengInvest 核心信条 + 架构总览

## 信条

1. **不接飞刀** — MA50<MA120 → 谨慎，不是禁止。价值投资优先于技术纪律
2. **不蹭热点** — 月涨>30% → 禁止买入
3. **不信噪音** — 券商/媒体涨了看涨 → 自动反向。**噪音定义**：对"公司内在价值判断"零增量信息的短周期信号——股民评论/论坛情绪、涨停跌停榜、短期涨幅排行、热点概念炒作、日内波动、市场热度。判别标准：**这条信息会不会改变我对公司长期价值的判断？不会 = 噪音，不看、不采、不讨论**。同花顺式信息流（股评、涨停榜、龙虎榜、话题热度）整体是噪音，对本系统无参考价值，明确不接入
4. **水则资车旱则资舟** — 但要防"一直旱"
5. **识别真价值** — 真实消费需求 vs 涨价幻觉。关注领域见 `knowledge/关注领域.md`
6. **结论不模棱两可** — BUY / HOLD / ADD / REDUCE / WAIT / PASS，没有"也有道理"
7. **执行 > 判断** — 投资最难的不是判断，是执行：方法论再简单，坚持执行它才是最难的部分。本系统存在的全部意义就是**强迫执行**——状态机卡死顺序、出站验证防糊弄、定期复盘强制回顾，都是为了让一个人"说到做到"。任何功能若分散注意力、削弱坚持，即使信息量再大也是负债

## 风险盘面：正交维度

- **风险按正交轴计算，不按资金域**：持仓标注 `market × segment × qualifier` 三轴（见 holdings/SCHEMA.md），集中度由 `fengportfolio.py check` 运行期分组求和得出，**不预设命名桶**。
- **人民币一盘棋**：跨币种（CNY/HKD/USD）统一按实时汇率折算合并评估，不按账户/市场分割。
- **资金墙 = 买入预算，非风险维度**：境内/境外资金池只约束现金划转，不产生"境外超配"类告警。
- **准现金 = 现金**：低波高息等 `qualifier=quasi_cash` 标的当现金使用，进资金池，不参与权益集中度。

## 持仓哲学：集中投资立场（2026-08-16 讨论定稿）

> 来源：与系统所有者讨论（2026-08-16），基于巴菲特 1993 致股东信原文、段永平公开实录、芒格语录、邱国鹭价值陷阱研究、行为金融证据（Odean 1998）。本文为所有者投资哲学的正式表述，含边界条件与反方证据。

### 立场（所有者原话整理）

1. **好机会必须抓住**：研究一家公司极其困难；一旦经过七层框架确信公司没问题，就该买。形式上保持纪律，但"好机会不抓住"= 便宜货扔掉、好东西扔掉、烂货买进来、贵的买进来。
2. **认知不变现等于没认知**：集中风险确实不对，但确信正确却不集中投资，认知就没有变现。确定性越高的机会，仓位应越重。
3. **反对机械价格止损**：亏损本身不是卖出理由。买入时认定"它能赚回来"，价格下跌不改变这个判断；因亏损而卖出是散户思维，不是专业投资者思维。专业投资者按论文（基本面）决策，不按价格。
4. **一定程度的集中**：巴菲特、段永平都是集中投资者（段永平苹果曾占仓位 80%、持有 15 年 20 倍；巴菲特苹果近年占投资组合 40%+）；"分散化是对无知的保护"（芒格）——过度分散是承认无知，不是美德。
5. **双账户**：投资账户纯价值（集中 + 论文止损）；交易账户可容纳投机/交易性机会（机械止损），两账户隔离、规则不同。

### 边界条件（讨论确认，防走火）

1. **"确信"必须有证伪机制**：段永平的完整做法 = 集中 + 估值纪律（合理区间分批买入）+ 认错机制（"买错了现价立即卖出，当时损失就是最少的损失"）。"确信"必须是七层框架/碰撞/反方检查的**产物**，不是前提。没有证伪条件的"确信"= 过度自信（Kahneman）。
2. **论文止损仍然存在**：不因价格卖出，但**因论文证伪卖出**（段永平"买错了立即卖"；巴菲特 2020 清仓航空、砍 IBM）。系统机制：`thesis.redlines` + 证伪条件 + 定期复盘（/fengreview）。持有亏损股的唯一合法理由是论文仍有效——**论文缺失时（如券商导入待补），"亏损持有"退化为处置效应**（Odean 1998：散户卖盈持亏，PGR 14.8% vs PLR 9.8%）。
3. **价值陷阱是集中投资的头号杀手**（邱国鹭 6 类）：技术淘汰 / 赢家通吃里的小公司 / 分散重资产夕阳行业 / 景气顶点周期股 / 无自由现金流公用事业 / 会计欺诈——共性 = 利润不可持续，"便宜"是表象。柯达 90→3 元的每一刻都有人"确信它能回来"。
4. **集中上限仍存在**：确定性极高可突破 20%，但设绝对上限（单标约 40%）防单一判断错误毁灭组合；机械阈值从"硬限制"降级为"警示 + 触发重审"。
5. **机会成本检验不变**（取舍原则）：重仓的前提是"这是当前最好的机会"——新标的与现有持仓比较。

### 反方证据（记录备查，不粉饰）

- **幸存者偏差**：巴菲特/段永平是数十年幸存样本；"百分之八十的股民亏钱"（段永平对比文章），破产的集中投资者无人纪念。
- **集中投资实证混合**：主动基金整体长期跑不赢指数；散户无私有信息优势，"确信"多为过度自信（行为金融共识）。
- **处置效应**：因亏损而持有若无论文支撑，与因亏损而卖出是同一价格锚定偏误的两面。
- **价值陷阱**：便宜 + 下跌 + 论文"看似"成立 = 最危险的组合；价值投资最怕"一知半解地坚守垃圾公司"（邱国鹭）。
