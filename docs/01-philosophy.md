# FengInvest 核心信条 + 架构总览

## 信条

1. **不接飞刀** — MA50<MA120 → 谨慎，不是禁止。价值投资优先于技术纪律
2. **不蹭热点** — 月涨>30% → 禁止买入
3. **不信噪音** — 券商/媒体涨了看涨 → 自动反向
4. **水则资车旱则资舟** — 但要防"一直旱"
5. **识别真价值** — 真实消费需求 vs 涨价幻觉
6. **结论不模棱两可** — BUY / HOLD / ADD / REDUCE / WAIT / PASS，没有"也有道理"

## 层级优先级

| 层 | 权重 | 在碰撞中的角色 |
|:---|:----:|:--------------|
| L0 能力圈 | **绝对** | 不懂→PASS，不进后续 |
| L1 硬纪律 | **绝对** | RED→深度价值/PASS |
| L2a 定性核心 | **最高** | 好生意/护城河是根本 |

## 仪表盘灯色

| 颜色 | 含义 |
|:---:|:-----|
| 🟢 绿灯 | 正常/通过 |
| 🟡 黄灯 | 有条件/需注意 |
| 🔴 红灯 | 有问题/不通过 |

M/L1/L2b 的总状态 = 该层最差的灯色（🔴 > 🟡 > 🟢）。
L2a 定性层：≥3灯🟢+无🔴 = 整体🟢（不要求全部绿灯才判定为好生意）。
🔴 可以往上推翻，不能往下忽略。

## 风险盘面：正交维度

- **风险按正交轴计算，不按资金域**：持仓标注 `market × segment × qualifier` 三轴（见 holdings/SCHEMA.md），集中度由 `fengportfolio.py check` 运行期分组求和得出，**不预设命名桶**。
- **人民币一盘棋**：跨币种（CNY/HKD/USD）统一按实时汇率折算合并评估，不按账户/市场分割。
- **资金墙 = 买入预算，非风险维度**：境内/境外资金池只约束现金划转，不产生"境外超配"类告警。
- **准现金 = 现金**：低波高息等 `qualifier=quasi_cash` 标的当现金使用，进资金池，不参与权益集中度。

## 执行流程

```
/fenginvest <TICKER>

01-capability   → L0 能力圈确认
02-market       → M  市场数据
03-discipline   → L1 硬纪律
04-quantitative → L2b 量化因子
05-qualitative  → L2a 定性核心
06-collision    → L3 碰撞+反方检查
07-report       → L4 最终报告
08-portfolio    → P  组合检查
```

每层执行：`读对应 docs/ 文件 → 机器工具(AI都行) → AI分析(A) → 写 artifact → 状态机 complete`
