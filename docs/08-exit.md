# 退出纪律

## 止损规则

| 类型 | 触发 | 动作 |
|:-----|:-----|:-----|
| 价格止损(硬) | 买入后跌>20% | 强制退出 |
| 基本面止损 | FCF由正转负/营收连续2季降/ROE<10% | 退出或降50% |
| 时间止损 | 6个月论文未兑现 | 重新评估，不通过则退出 |

跌15%流程：检查基本面是否同步恶化 → 基本面不变继续持有/恶化则割。

## 止盈规则

| 路径 | 触发 | 动作 |
|:-----|:-----|:-----|
| 估值回归 | PE>历史80%分位+无中枢上移理由 | 减至半仓 |
| 估值泡沫 | PE>95%分位或市值/FCF>50x | 清仓80%+ |
| 趋势反转 | MA50<MA200+月跌>10%+放量 | 退50% |

## 论文失效

| 级别 | 动作 |
|:-----|:-----|
| 🔴 核心论点推翻 | 立即清仓 |
| 🟡 关键假设动摇 | 降50%，观察1季 |
| 🟢 时间框架超出 | 重新评估 |

## 定期重审

- 每季度：检查论文+新闻
- 每半年：完整重跑 01→07 + P 层组合盘面（`python tools/fengportfolio.py check`）
- 股价异动>5%：检查
