# 退出纪律

> 卖出决策执行走 `/fengexit` skill（触发源识别 → 六类理由 → 偏误自查 → 执行卖出闭环），本文件为规则依据。

## 双账户规则（2026-08-16 定稿，最高优先级）

| 账户类型（`account_type`） | 止损方式 | 依据 |
|:-----|:-----|:-----|
| **INVESTMENT**（默认） | **论文止损**：价格跌不触发卖出；论文证伪条件（redlines）触发才卖 | 集中投资哲学：不因价格卖，因论文卖（见 docs/01-philosophy.md） |
| **TRADING** | **机械止损**：-20% 价格线强制退出 | 交易账户做概率游戏，纪律优先于观点 |

- 机械止损的反面是散户处置效应（Odean 1998：PGR 14.8% vs PLR 9.8%）——**INVESTMENT 账户因亏损而卖 = 散户思维**，fengwatch 对 INVESTMENT 账户的价格止损只降级为警示 + 触发论文复盘。
- 集中度超标**不是卖出理由**（只约束买入）；卖出只由六类退出理由触发。

## 止损规则

| 类型 | 触发 | 动作 |
|:-----|:-----|:-----|
| 价格止损(机械) | 买入后跌>20% | **仅 TRADING 账户**强制退出；INVESTMENT 账户降级为警示+论文复盘 |
| 基本面止损 | FCF由正转负/营收连续2季降/ROE<10% | 退出或降50% |
| 时间止损 | 6个月论文未兑现 | 重新评估，不通过则退出 |

跌15%流程：检查基本面是否同步恶化 → 基本面不变继续持有/恶化则割（INVESTMENT 账户同样以论文为准）。

## 止盈规则

| 路径 | 触发 | 动作 |
|:-----|:-----|:-----|
| 估值回归 | PE>历史80%分位+无中枢上移理由 | 减至半仓 |
| 估值泡沫 | PE>95%分位或市值/FCF>50x | 清仓80%+ |
| 趋势反转 | MA50<MA200+月跌>10%+放量 | 退50% |

## 论文失效

| 级别 | 动作 |
|:-----|:-----|
| 🔴 核心论点推翻 | 立即清仓 |
| 🟡 关键假设动摇 | 降50%，观察1季 |
| 🟢 时间框架超出 | 重新评估 |

**论文是持有的前提**：无 thesis.original + redlines（证伪条件）的持仓 = 黄灯（fengwatch check_thesis_missing），亏损持有无论文支撑即处置效应；新登记持仓 redlines 缺失直接拒绝（fengholding add 校验）。

## 定期重审

- 每季度：检查论文+新闻
- 每半年：完整重跑 01→07 + P 层组合盘面（`python tools/fengportfolio.py check`）
- 股价异动>5%：检查
