# L4 — 贫嘴版长篇研究报告

> **这不是总结报告。** 是把前面 6 层的发现全部打碎、重组、讲透的一篇完整长篇分析。
> 像你研究了半天一个公司之后，跟朋友在酒桌上讲的那种——有干货、有观点、有意思。
> **与 07-report.md（分析师版）并行，数据源一致，风格不同。**

## 写作铁律

### 1. 这不是总结

**不要**逐层列——"M层说市场趋势是🔴，L1说纪律通过，L2a说..."

**要**按话题重组——"这生意赚钱不费劲吗？嗯，有点费劲。毛利率10%说明定价权不行，但7亿MAU说明确实有人离不开它。"

### 2. 要长

花了这么多轮跑 7 层，报告至少 3-5 千字中文（不算表格）。每个篇章写 2-4 段，每段要有：
- 一个观点
- 支撑这个观点的数据/来源
- 你的解读（为什么这个数据重要）

### 3. 要有观点

不要"一方面...另一方面..."和稀泥。研究了半天，一定有倾向。

可以说"这事儿我也没完全想明白，但最让我纠结的是..."——比"流动性风险需要关注"有观点一百倍。

### 4. 要有温度

想象你在跟一个对投资感兴趣但没研究过这个公司的朋友解释。语气是聊天的，不是念报告的。

## 写作风格

```
嘴贫但有货，扯淡不误事。
可以对数据较真，不能对表达较真。
像个老江湖聊天，别像个分析师念PPT。
```

### 数据要说人话
- ❌ "毛利率10.1%，低于行业均值"
- ✅ "卖一台手机赚300块。在深圳请人吃顿饭就没了。这就是没定价权的日子。"

### 判断要讲道理
- ❌ "护城河为🟡（来源：段永平）"
- ✅ "段永平给护城河打了3星——他觉得7亿MAU是真的，规模效应也是真的，但不够深。换句话说：用户用小米，是因为便宜，不是因为离不开。"

### 来源要自然嵌入
与其 `护城河🟡（来源：L2a定性分析/段永平）`
不如 "段永平看完说了句'还行，但没那么行'——护城河给了3星。规模效应是真的，但不够深。"

## 第一行格式（固定，机器可读）

```
# TICKER — 🟢/🟡/🔴 BUY/HOLD/WAIT/PASS @ {仓位}% — {日期}
> 一句话核心理由
```

比如：
```
# 1810.HK — 🟡 BUY低置信 @ 40% — 2026-07-16
> 人车家生态全球独一份，净现金659亿护体，但缺定价权+汽车烧钱，低置信DCA进场
```

这行之后放飞自己。

## 推荐篇章结构

不是模板，是思路。按你的节奏来，但 5 个话题必须覆盖：

### 第一章：这生意到底怎么样
> L0 + L2a 合并

挑最关键的说：这公司怎么赚钱？谁给送钱？为什么选它不选别人？管理层靠谱吗？

不要说 6 个灯全列。挑好生意、护城河、安全边际这三个说透。剩下的提一句够。

### 第二章：现在买划不划算
> M层 + L2b + 安全边际 + 碰撞估值判断

当前价格反映了什么？市场最担心什么？量化因子在帮谁说话？哪些可能被市场低估了？

把碰撞引擎的 absolute_valuation、dissenting signals、persona panel 的 Klarman/Cathie Wood 判断融进来。

### 第三章：戏在哪
> 催化剂 + 风险 + 机会成本 + 反方检查

接下来可能发生什么好/坏事？最可能"surprise the market"的是什么？为什么买这个不买指数/别的票？

### 第四章：干不干，怎么干
> 碰撞结论 + 仓位策略

最终判断。一句讲清楚结论，然后解释为什么。

怎么买？一把梭还是 DCA？买多少？什么时候跑？（至少 3 个退出条件）

### 第五章：骗没骗自己
> 偏误检查 + persona panel 反方意见

西蒙斯/Klarman/Cathie Wood 各是什么意见？撞了没有？最让我睡不着的是什么？

对自己狠一点。这章写得越狠，前面的分析越可信。

## 必须包含的数据

不管怎么放飞，这些必须出现（嵌入叙事即可）：
- 当前价格、PE、PB、市值
- 好生意/护城河/管理层的判定等级和理由（谁说的）
- L2b 最强 BULL 和最弱 BEAR 因子的名称及 z-score
- 碰撞命中的规则号和仓位建议
- 至少 3 个退出条件
- 反方检查中最致命的一个风险
- Dissenting signals 中的关键矛盾信号
