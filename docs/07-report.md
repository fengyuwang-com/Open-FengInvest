## 报告结构

以下结构是模板，不是铁律。但每个部分都必须有数据支撑和来源引用。

### 1. 投资论点 (Investment Thesis)

**1-2 段**总结核心判断，涵盖：
- 为什么买/不买这个标的（一句话）
- 当前价格反映了什么市场预期
- 你的判断与市场共识的差异（哪里"非共识"）
- 核心催化剂的 timing

语气：克制、精准。不是"我觉得"，而是"数据表明"。

### 2. 业务概览 (Business Overview)

**结构化呈现**：

| 维度 | 内容 |
|------|------|

| 竞争地位 | 市场份额、行业排名 |

### 7.5 DK 原则审计

| 原则 | 检查结果 | 影响 |
|:-----|:---------|:-----|
| **坐标原则** | 对标标的、价差、坐标类型 | 无对标支撑→降置信 |
| **家国原则** | 行业政策方向、货币周期 | 与国家利益冲突→PASS |
| **息价原则** | 安全边际是否>30%、极端压力 | 安全边际不足→WAIT |
| **取舍原则** | 机会成本对比、组合约束 | 存在更好机会→降仓位 |

DK 纪律规则检查结果（来自 L1 扩展规则 + L3 碰撞 Rule 10-14）：
- 全部 DK 🟢 + L1 🟢 → 调高置信度（双重验证加分）
- 任一 DK 🔴 → PASS（DK 纪律高于一切）

数据来源：L1 03-discipline.json（DK扩展规则）+ L3 碰撞 dk_assessment

## 写作规范

1. **第一行必须是机器可读的结论行**
2. **所有数据必须有来源** — 格式：`[来源]` 或 `（来源：L2a定性/段永平）`
3. **表格为王** — 财务数据、估值倍数、风险矩阵尽量用表格
4. **语气客观克制** — 不说"我觉得"，说"数据显示"
5. **不要省略反方意见** — 每个看多论点后面都跟着看空数据
6. **来源标注方式**：统一用 `（来源：层名/具体来源）`，例如 `（来源：L2a定性/巴菲特★4）`、`（来源：L2b量化/价值因子 z=1.38）`、`（来源：M层/宏观分析）`
