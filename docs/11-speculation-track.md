# 投机/交易钱包轨道（fengspec）— 概念定稿

> **定位**：本文件把六条纪律之「双账户制」（`knowledge/discipline/双账户制.md`，source 奇衡DK-CAPITAL）从"一句声明"做实为**可运行的独立交易轨道**，是独立 Skill `/fengspec` 的法理依据。本轨道**完全不触碰**投资路径（`/fenginvest` → `/fengholding` → `/fengexit` → `/fengreview`）。
>
> **一句话**：市场是赌场，但交易不是赌博——两个钱包，规则两套，互不干扰。

## 1. 两个钱包（出处：docs/01-philosophy.md:84、docs/08-exit.md:5-13）

| 维度 | 投资钱包 INVESTMENT（默认，现有完整链路） | 交易钱包 TRADING（本轨道） |
|:--|:--|:--|
| 目的 | 价值发现、长期持有、论文驱动 | 投机性买入：趋势/事件/动量、回报来自对手盘错误 |
| 持有周期 | 1–5 年+ | 3–12 个月（事件交易 1–3 个月） |
| 决策方式 | 七层框架、四大原则、定性/定量 | 本轨道六步流程 + 交易纪律 |
| 止损 | 论文止损：价格跌不触发；redlines 证伪才卖 | 机械止损：-20% 价格线强制退出（`fengwatch` 已按 account_type 分流，见 docs/08-exit.md:9-10） |
| 反方心智 | L3 碰撞（卖=投机=负面） | 反方=纪律执行（是否违反试盘/止损/滚存） |

## 2. 交易钱包只做"投机性买入"

- **做**：右侧突破（阻力最小路线）、事件驱动（重组/并购/业绩超预期/题材暖风）、动量与结构确认——奇衡《奇衡论投机性买入-研究文档.md》界定：投机=买机会、投波动,回报来自对手盘错误。
- **不做**：价值式抄底（那是投资钱包的事）、"投井"（无方向的区间空转死买）、A/B 点（逃顶/抄底）——只做 C/D 点。
- **硬前提**（T1 环境闸）：大盘趋势向上 + 标的在年线上方 + 大盘仓位法则（2638）。环境不对，本轮不做。

## 3. 六步流程（草案，SKILL.md 细化）

```
T0 触发源    右侧突破 / 事件驱动（禁止投井、A/B 点）
T1 环境闸门  大盘 + 年线上方 + 2638 规则 → 环境不对本轮不做
T2 结构确认  右侧确认（复用 fengrule 后发制人 4 信号）+ 阻力位突破量能确认
T3 纪律捆    全部预写：试盘·止损线(条件单)·滚存线·时间窗上限
T4 记录&监控 登记 TRADING 钱包；fengwatch 机械止损 + 事件证伪即时退出
T5 卖出复盘  卖出艺术细则 + 交易级复盘（手气 vs 结构可重复）
```

## 4. 仓位纪律（初版默认，可经用户拍板调整）

| 规则 | 数值 | 来源/备注 |
|:--|:--|:--|
| 首次试盘 | ≤3% | 奇衡：首次试盘 3%（系统原无"试盘"概念，正式引入） |
| 单票上限 | 5–10% | 奇衡口径；与 P 层 `single` 红>20/黄>15 取更严者 |
| 单行业上限 | <20% | 奇衡口径 |
| 交易钱包总预算 | 10–15%（不超账户 30%，永不爆仓） | 奇衡"投机仓 10-15%" + "账户总资金 30% 上限"；与 2638 法则大盘上限 30% 是两回事，取更保守 |
| 单标最大浮亏 | -20% 机械止损 | 已实现（fengwatch TRADING 分支） |
| 杠杆 | **0（初版硬约束）** | 与系统硬件约束一致；"右侧杠杆可加"作为单独议题，默认不启用 |

## 5. 冲突解决（初版决定——这是"独立 skill、不改 fenginvest"的原因）

| 冲突 | 投资钱包现状 | 交易钱包处理 |
|:--|:--|:--|
| 信条3「不信噪音」 | 涨停榜/龙虎榜/热点概念"不接入" | 作用域限定在**投资钱包**；交易钱包用动量/事件信号，但受本轨道纪律约束，两层不接入边界清晰 |
| L1 四灯（no_fomo 月涨>30 禁买 / no_chasing 偏离年线>30 拦截） | 硬拦截 | 不用于交易钱包的审核对象；用 T1 环境闸 + T2 结构确认替代 |
| fengscreen 7 硬指标 | 全档题材/右侧股 | 投机标的**绕开 fengscreen**，走 T2 结构 + T3 纪律捆 |
| thesis/redlines | 强约束 | TRADING 不强制完整价值论文，用轻量 `trade_entry`（entry_trigger/stop_line/time_window/证伪触发/滚存线） |
| 杠杆=0 | 硬件约束 | 交易钱包初版同为 0 |

## 6. 与投资钱包的接口（隔离 + 记账）

1. **资金隔离**：两账户分账，交易钱包预算独立（§4），不并进投资组合的归因/HRP 主体口径（单独标注）。
2. **同票双钱包**：允许同一只股票同时存在于两个钱包（投资长线 + 交易波段），隔离记账、互不干扰；登记时给出"同标双钱包"警示，避免混淆。
3. **监控分流**：`fengwatch` 已按 `account_type` 分流（INVESTMENT 论文止损 / TRADING 机械止损），沿用。
4. **联动**：交易钱包的买卖都走 `/fengspec` 自己的闭环；复盘用 `/fengspec` 的交易级复盘（手气与结构区分），不进 `fengreview` 的四态论文复盘。
