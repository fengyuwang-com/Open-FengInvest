# L3 — 碰撞引擎

## 铁律

碰撞引擎**不产生新信息**。结论只能来自前层已有输出。
禁止加入训练知识。每个结论必须有来源引用。

## 反方强制检查（碰撞前必做）

```
问题1：列出这个股票让你亏钱的5种方式
→ 对抗确认偏误

问题2：如果当前价格下跌30%，你会加仓还是割肉？
→ 加仓=懂。割肉=你不应该买。

问题3：如果当前价格上涨30%，你会卖吗？
→ 卖=投机。不卖=投资。

问题4：这个决策受什么最近的新闻/价格走势影响？
→ 暴露近因偏误
```

## 碰撞规则（按优先级）

```
L1有🔴？
  ├─ 好生意🟢 + 极端低估 + 非陷阱 + 催化剂
  │   → 深度价值路径(DCA 30-50%)
  └─ 其他 → PASS

L1 🟢/🟡：
 规则1: 好生意/护城河🔴 → PASS
 规则2: 好生意🟢+护城河🟢+安全边际🔴 → WAIT @ 0%
 规则3: 好生意🟢+安全边际🟡 → BUY低置信 @ 30-50%
 规则4: 好生意🟡+安全边际🟡+绝对低估 → BUY中置信 @ 50-80%
 规则5: L2a整体🟢+L2b🟡/🔴 → BUY中置信 @ 80%
 规则6: L2a整体🟢+其他层🔴 → BUY低置信 @ 30-50%
 规则7: L2a整体🟢+M层🔴 → BUY+提高安全边际
 规则8: L2a整体🟢+L2b🟢+无🔴 → BUY高置信 @ 上限
 规则9: 全绿 → BUY满仓（按能力圈+组合约束）

### DK 碰撞规则（10-14）

 规则10: DK任何🔴 → PASS（DK纪律高于一切，优先级2）
 规则11: 坐标原则🔴 → WAIT降置信；🟡 → 追加冲突（无对标支撑不可靠）
 规则12: 家国原则🔴 → PASS（不做国家交易对手）
 规则13: 安全边际<30% → WAIT（价格不够便宜）
 规则14: 全部DK🟢+L1🟢 → 调高置信度（双重验证加分）
```

优先级从上到下，命中即退出。多规则重叠时取**更严格**的。

**绝对低估条件**（满足任一项即触发）：
- PE < 10x（Trailing）
- PB < 1x
- 净现金/市值 > 30%

## 行为偏误检查（碰撞后必做）

- 确认偏误：支持vs反对的证据比例？
- 锚定效应：是否受历史高价影响判断？
- 近因偏误：最近涨跌影响判断？
- 过度自信：多因子一致时容易过度自信

## 输出

**双格式（状态机出站验证要求 JSON，需与 fengstate 一致）：**

1. 写入 `research/060-companies/<TICKER>-<中文名>/<YYYY-MM-DD>/06-collision.json`（060-companies 为本地 gitignored 目录），**必须包含**：
   - `decision`（BUY/HOLD/WAIT/PASS）
   - `confidence`（0-1）
   - `position_pct`（建议仓位）
   - `conflicts` 数组（冲突来源+消息+处理方式）

2. 补写 `06-collision.md` 可读版（反方人物视角 + 偏误检查 + 规则树命中明细）。

`complete` 参数用 JSON 文件（`fengstate.py complete <TICKER> 06-collision "$BASE/06-collision.json"`）。
