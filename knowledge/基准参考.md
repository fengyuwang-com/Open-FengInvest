## 判定标准

| 结果 | 条件 |
|------|------|
| **PASS** | 所有工具通过 + 所有清单项 ✅ |
| **CONDITIONAL PASS** | 有 FAIL 项但非致命（标注待修项，可交付） |
| **FAIL** | 有致命缺失（必须修复后重跑对应层） |

### 致命缺失定义

- 任意一层的 JSON 文件缺失或空壳
- `fengstate.py verify` 有 FAIL
- `fengdoclint.py --strict` 不合规
- 报告首行格式不合规
- 00-INDEX.md 缺失
