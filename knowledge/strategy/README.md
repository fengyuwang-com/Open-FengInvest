## 使用顺序（新钱进场）

1. 先定结构（卡 03）：几只、核心卫星怎么分。
2. 再定仓位（卡 01+04）：每只买多少、留多少现金。
3. 最后挂纪律（卡 02）：跌破年线怎么减、什么时候回补。
4. 所有卡都不指示"买哪只"——选股走 /fengscreen → /fenginvest 七层框架，本库只管"买了之后怎么拿、怎么卖"。
