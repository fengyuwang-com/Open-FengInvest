## 规则

**不做第一个发现机会的人。等大局已定、右侧信号确认后再进场。**

后发制人的核心思想：不追求买在最低点，而是等趋势确认后再参与。先发者承担价格发现的风险和成本，后发者享受确定性。股市不是抢跑比赛——晚几步进场的成本远低于抄底在半山腰的损失。

## IF-THEN

| 条件 | 动作 |
|------|------|
| IF 还在做价格发现（新题材/底部不明） | 🔴 等，不参与 |
| IF 大局已定（右侧确认/趋势明朗） | 🟢 可以买了 |
| IF 已经涨了一段但逻辑清晰 | 🟢 仍可进，不要因为涨了就不敢买 |
| IF 跌了很多但是逻辑还在 | 🟡 分批建仓，不要一次full position |

## 适用范围

所有投资场景，尤其适用：
- 新股/新行业 (等几个季度财报验证)
- 抄底 (等底部确认)
- 突发事件 (等市场消化)

## 常见陷阱

- ❌ "这次不一样，必须早点上车" — 被FOMO驱动
- ❌ "已经跌了这么多了，不可能再跌了" — 左侧抄底
- ✅ "等等看，让市场先走两步" — 后发制人

## 在系统中的位置

- **L1层**: no_first_mover 检查
- **持有期**: 买入方式推荐（分批 = 后发制人的体现）
