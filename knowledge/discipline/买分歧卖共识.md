## 规则

**在分歧中买入（有争议才有便宜价格），在共识中卖出（大家都看好时价格已充分反映）。**

安全边际的源头不是数据计算，而是分歧——因为有人不看好，才有人愿意低价卖给你。当所有人都看好时，价格已经没有安全边际了。

## IF-THEN

| 条件 | 动作 |
|------|------|
| IF 市场存在显著分歧（多空都有理由） | 🟢 有安全边际来源，可以考虑买入 |
| IF 市场一致看多（分析师全部推荐） | 🔴 危险信号，价格已经反映乐观预期 |
| IF 市场一致看空（没人看好） | 🟡 可能有机会，但要区分是真的差还是情绪 |
| IF 自己跟市场共识一致 | ⚠️ 提醒自己：我的想法是不是已经在价格里了？ |

## 适用范围

所有投资场景

## 如何判断分歧 vs 共识

1. **搜索验证**: 爬取"看多"和"看空"的分析文章，看两边都有没有合理的逻辑支撑
2. **卖方覆盖**: 分析师评级分布——如果100%都是买入评级，太一致了
3. **价格行为**: 坏消息不跌 = 分歧偏多；好消息不涨 = 共识偏空
4. **日常观察**: 朋友圈/股吧/雪球讨论热度——人人都在谈的时候警惕

- **L1层**: divergence_or_consensus 检查
