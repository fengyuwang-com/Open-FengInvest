## 规则

**当持仓盈利达到一定幅度时，回收本金，让利润继续奔跑（零成本持仓）。**

钱仓滚存是投资中的"杠杆"——不是借钱加杠杆，而是用盈利加杠杆。回收本金后剩下的筹码成本为零，可以无限期持有。

## 核心理念

投资赚四种钱：
1. **钱生钱** — 股息、利息等现金回报
2. **钱仓滚存** — 回收本金，剩下的零成本筹码继续跑
3. **事件驱动** — 套利/并购/重组等一次性机会
4. **周期轮动** — 不同市场/板块的轮动

钱仓滚存是最重要的持续赚钱方式——它让一次的盈利变成永久性的成本优势。

## 计算方法

```
可回收金额 = (当前价 - 平均成本) × 持仓股数
如果 可回收金额 ≥ 总投入本金
  → 可以全部回收本金
  → 剩余 = 零成本筹码

如果 市值 ≥ 总投入 × 1.3
  → 建议回收本金
  回收股数 = ceil(总投入 / 当前价)
  剩余零成本股数 = 总股数 - 回收股数
```

## IF-THEN

| 条件 | 动作 |
|------|------|
| IF 浮盈 > 15% | ⚠️ 关注钱仓滚存机会 |
| IF 浮盈 > 30% 或 市值 > 投入×1.3 | 🟢 强烈建议执行滚存 |
| IF 浮盈很大但还没回收本金 | 🔴 风险：浮盈会回撤 |
| IF 已经零成本持有 | 🟢 可以无限持有，涨跌都不怕 |

## 在系统中的位置

- **持有期管理**: 触发引擎 → 价格触发 → 钱仓滚存建议
- **卖出检查**: 钱仓滚存作为一个卖出理由
- **工具**: `python tools/fengwatch.py check <TICKER>`（滚存建议）+ Web UI `/rollover` 计算器
