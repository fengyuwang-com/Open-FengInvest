## 规则

**上证指数低于2638时，仓位不超过30%，不做多。**

2638点是2016年熔断底，后来成为A股长期多空分界的关键点位。指数跌破这个位置意味着市场处于系统性风险区间。

## IF-THEN

| 条件 | 动作 |
|------|------|
| IF 上证指数 > 2638 | 正常操作，仓位可超过30% |
| IF 上证指数 ≤ 2638 | 仓位 ≤ 30%，不做新增多头 |
| IF 大盘低于年线 | 🟡 降仓位提醒，仓位 < 30% |

## 适用范围

A股投资（上证指数相关标的）

## 例外

无（硬规则）

## 注意

- 2638是A股参考值，港股/美股需要确定各自的市场锚点
- 大盘低于年线时即使没有跌破2638，也要降仓位——这是更敏感的信号

## 在系统中的位置

- **L1层**: no_2638 检查
- **触发引擎**: 大盘低于年线时 → 待办提醒降仓位
