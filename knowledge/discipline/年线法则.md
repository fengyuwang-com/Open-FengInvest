## 规则

**年线（MA200/MA250）是牛熊分界线。个股/指数在年线之上和之下，操作策略完全不同。**

年线是市场的平均成本线，也是最重要的趋势线。在年线之下买入安全边际更高（因为大家都在亏钱），在年线之上追高要小心。

## IF-THEN

| 条件 | 动作 |
|------|------|
| IF 个股价格 > 年线 | 🟡 警惕追高，不适合重仓买入 |
| IF 个股价格 < 年线 | 🟢 可以买，但需要确认右侧信号 |
| IF 个股价格 = 年线附近 | 观察突破还是跌破，等确认 |
| IF 大盘 < 年线 | 🟡 整体仓位 ≤ 30% |

## 适用范围

所有市场（A股、港股、美股）

## 补充说明

- 年线下方买入 = 在别人恐慌时买入
- 年线上方但已经回调到年线附近获得支撑 = 可能是加仓点
- 年线不是精确的买卖信号，而是一个风险参考

## 在系统中的位置

- **L1层**: no_chasing 检查
- **触发引擎**: 大盘低于年线 → 降仓位提醒
