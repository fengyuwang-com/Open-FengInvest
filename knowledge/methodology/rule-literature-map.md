# 规则 → 文献 → 反证 映射表（系统规则层）

> **用途：改任何系统规则前，先查本文档。** 每条系统规则（退出规则 / 量化因子 / 组合阈值 / 筛选与纪律）必须能回答三个问题：
> ① 标尺论文是什么、作者结论是什么；② 已知反证/边界是什么；③ 阈值本身是否有文献支撑（没有就标"无文献标尺"）。
> 规则=论文的**落地层**，与另三份文档分工：`literature-map.md`=论文**元数据**（DOI/出处）、`literature-conclusions.md`=论文**作者结论**（标尺）、`papers/01-06`=逐篇**方法层**研究笔记（判定细节）。本文档只做"系统规则 ↔ 论文"的映射，全部事实来自上述四份来源，不新造结论。
> 维护规则见文末。

## 维护规则

1. **新增/修改任何系统规则（退出规则、因子、阈值、筛选指标、纪律检查）前，先查本文档**：该规则有没有标尺论文？标尺的作者结论是什么？有没有反证注册在案？改完规则在本表同步更新一行。
2. **新论文结论更新 papers/01-06 后，同步本文档**：只改"结论要点/反证"列，不重复登记元数据（元数据在 literature-map.md）。
3. **阈值类参数**：论文支持机制/方向≠阈值有标尺。凡"具体数值无文献表述"的（-20%、15%/30%、50x、6 个月、8%/2x/15%/0.7/5%/20%、30% 等），一律标注"无文献标尺"；需要落地的候选阈值先进第五章注册表验证，不直接写进代码。
4. **引用纪律**：反证注册表（第六章）与标尺论文必须并陈引用；发现 papers 与 literature-conclusions 结论冲突时，以"摘要未取得的标'待补'"为默认态，不得凭记忆补写。
