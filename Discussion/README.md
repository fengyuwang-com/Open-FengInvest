# FengInvest Discuss — 观点交锋档案

> **一句话**：这里是"我与 AI 就投资哲学 / 方法论 / 框架"的对抗式讨论的家。每条讨论 = 立场 + 反方 + 结论 + 对系统的改动，一条一个文件。
> **用法**：`/fengdiscuss`（发起一场讨论）→ `/fengdiscusslog`（落档记录）。
> **来源**：由原 `docs/10-discussion.md`（观点辩论档案）迁移而来；原页保留历史指针。

---

## 为什么存在

讨论（尤其是**对抗式**讨论）是这套投资系统的核心资产之一。你要的不是"帮你得出一个顺耳的结论"，而是一个**会跟你顶嘴、不讨好你的对手**——每条结论背后必须站着一个没被安抚的反方。本书是这些交锋的家，避免它们散落在 `docs/`、`FENGMEM.md`、`research/` 各处而"讨论完就找不到"。

## 宪法（不可违反）

1. **不讨好**：AI 主动给最强反方；立场不因"顺着用户"而成立，只因证据成立。
2. **反方必须完整记录**：任何讨论都不得只有一面之词；放不下反方的讨论不落档。
3. **结论可推翻**：新证据/复测可以推翻旧结论（这是正面案例，如实宣告，参考"年线上"被复测推翻）。
4. **改哲学前先辩论**：修改 `docs/01-philosophy.md` 等定稿立场前，先在本档案完成辩论并记录结论。

## 条目规范

- 命名：`YYYY-MM-DD-<kebab-英文主题>.md`（一天多条用序数或不同主题词区分）。
- 一条讨论 = 一个文件；文件内模板沿用原辩论档案：

```
## YYYY-MM-DD 议题

**立场**（谁 + 原话要点）：
**支持证据**（来源 + 原文）：
**反方**（最强反对论点 + 来源）：
**结论**（定稿/待定，写入 01-philosophy.md 的内容）：
**系统改动**（已实施 / 待实施）：
```

- 头部加 `状态: 待定 | 定稿`；底部加一行 `来源:` 指向原始出处。
- 新增讨论：用 `/fengdiscuss` 辩论（或 `/fengdiscusslog` 纯记录）→ 落新文件 → 在本索引加一行。

## 公开边界

本目录随私有仓库 `FengInvest`（默认私有，个人想法可放心写入）。**公开仓库 `Open-FengInvest` 零个人数据**：若要把某条讨论发布到公开版，必须单独脱敏（去掉个人持仓/血泪史/可识别信息）后手动复制，未经处理不公开。
