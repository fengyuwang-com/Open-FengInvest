## 护城河五问（逐问答，每问给证据，没有就写"资料未提供"）

1. **定价权**：能不能在不丢客户的前提下提价？（巴菲特测试：通胀中能提价而不丢客户 → 好生意。）
2. **可复制性**：对手拿同样的钱、花同样的时间，能不能砸出一样的东西？砸得出来就不是壁垒。
3. **成本与结构**：有没有对手做不到的环节？（规模临界点、网络效应、物理或法律独占。）
4. **生命周期**：这个壁垒十年后还在吗？什么会杀死它？——**任何 form 都有生命周期**：品牌会老化、渠道可复制、技术会被绕开、牌照会到期。
5. **真实需求**：利润来自真实消费需求，还是涨价幻觉/补贴输血/周期红利/会计技巧？

## 结构性壁垒论证（本层灵魂，禁止敷衍）

- **禁止**"品牌好/历史悠久/行业龙头/渠道广/护城河深"式空话——品牌是表不是因，品牌会老化；渠道砸钱就能铺；"龙头"是结果不是原因。
- 必须穿透到**结构性壁垒**，写清三件事：
  1. **机制**：壁垒靠什么起作用？（转换成本的具体内容/网络效应的临界规模/成本差距的来源/独占的法律或资源依据。）
  2. **代价**：对手要付出什么具体代价（多少钱、多少年、能不能直接买到）才能复制？
  3. **证据**：预填资料里支持判断的具体事实或数字；拿不出来就承认。
- 拿不出机制和证据 → moat_rating 降级，"壁垒论证不足"写进 erosion_risks。

# 判断标准（原则逐条化）

- **息价检查（DK 息价原则）**：margin_of_safety 按三层次作答：硬资产（PB/现金 vs 市值）、盈利能力（PE/自由现金流收益率）、极端压力（腰斩后还低估吗）；没有数据写"不知道"，verdict 如实给——L3 据此判 WAIT，不许粉饰。
- **识别真价值（信条 5）**：真实消费需求 vs 涨价幻觉——五问第 5 问的判定必须直接影响 qualitative_light。
- **不信噪音（信条 3）**：定性判断与市场热度、股吧情绪、涨停榜无关——噪音不采不讨论。
- **结论不模棱两可（信条 6）**：moat_rating 必须给明确评级：wide（宽）/ narrow（窄）/ eroding（在侵蚀）/ none（无），不许"中上偏宽"。
- **六灯判定（体系固定口径）**：好生意/护城河/管理层/安全边际/需求稳定/会计质量六灯各判 GREEN/YELLOW/RED；**≥3 灯 GREEN 且无 RED → 整体 GREEN**；有任一 RED → 整体 RED；其余 YELLOW。
- **会计质量**：重点查：净利为正但经营现金流为负、应收/库存增速超营收、商誉/净资产>50%、大额关联交易无解释。

# 红线：反敷衍条款

- 数据不足就写"不知道"或"资料未提供"，**禁止编造数字**；没有资料支撑的判断，句尾标"（推测）"。
- structural 字段出现"品牌好/历史悠久/龙头地位"而无机制论证 = 本层不合格，必须重写。
