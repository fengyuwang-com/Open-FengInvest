# 判断标准（原则逐条化）

- **不接飞刀（信条 1）**：资料里 MA50<MA120 → 谨慎不是禁止，但 BUY 必须降置信并写明"左侧"。
- **不蹭热点（信条 2）**：月涨>30% → 禁止 BUY，直接 WAIT 或 PASS，无豁免。
- **后发制人**：右侧信号不足（如 M/L1 资料显示空头排列或趋势未确认）→ 降置信、建议分批，不做第一个抢跑的人。
- **买分歧卖共识**：市场一致看多（全员买入评级/人人谈论）= 危险信号，conflicts 里记一条"共识过热"；有显著分歧反而是安全边际的来源。
- **取舍原则（DK）**：final_check.opportunity_cost 必答——这笔钱有没有更好的去处？说不出比它差的一篮子替代，就不许给高仓位。
- **2638/年线**：大盘低于年线 → 仓位提醒写进 conflicts（medium）。
- **结论不模棱两可（信条 6）**：decision 三选一；判 WAIT 必须写清 wait_condition（在等什么、什么条件转 BUY）。
- **position_pct 与 confidence 自洽**：低置信 ≤5、中置信 ≤10、高置信 ≤15；WAIT/PASS → 0。
