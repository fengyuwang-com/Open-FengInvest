# 任务：把各层结论写成白话报告书

对 **{{TICKER}}**（{{NAME}}）按以下结构成文（顺序固定，标题可微调，**每节都必须有内容，缺资料就写缺**）：

1. **结论卡（放最前面）**：一句话给最终结论——买/不买/等，加建议仓位，加一句话为什么。结论必须是 BUY / HOLD / ADD / REDUCE / WAIT / PASS 之一，**没有"也有道理"**（信条 6）。判 WAIT 必须写清"在等什么"。
2. **这家公司是干嘛的**：讲给家里人也能听懂的一句主话 + 两三句展开（钱从谁口袋来、为什么非它不可）。
3. **生意好不好**：把 L2a 的护城河结论翻译成人话——壁垒的机制是什么、对手要付出什么代价、最致命的侵蚀风险是什么。宽就是宽，窄就是窄，在侵蚀就明说。
4. **数字检查说了什么**：把 M/L1/L2b 的工具结果翻译成人话（趋势、四盏纪律灯、六个因子的意思）。每个数字后面必须跟一句"这意味着什么"。
5. **反方说了什么**：把 L3 碰撞的质疑清单挑最重的三条翻译出来——**不许只报喜**，红队的话要原汁原味保留锋利度。
6. **便宜不便宜**：把息价检查翻译成人话——安全边际够不够 30%，不够就直说"还不够便宜"。
7. **钱怎么摆**：仓位建议 + 原因；补一句取舍原则——这笔钱有没有更好的去处。
8. **什么情况下证明我错了**：把红线/证伪条件列成清单，写清触发后该做什么（复盘或退出）。
9. **下次什么时候再看它**：具体日期或触发条件。

各节信息来源对应：结论卡=L3 裁决，生意=L2a 定性，数字=M/L1/L2b 工具结果，反方=L3 红队质疑，便宜=L2a 息价检查，钱怎么摆=仓位建议与取舍原则，红线=买入论文的证伪条件。翻译时保持各层原有的判断，不许替任何一层改口或粉饰。

# 翻译规则（零术语）

常用黑话必须翻译，示例口径：
- 年线 → "过去一年买入者的平均成本"；MA50/MA120 → "近 50 天/近 120 天买入者的平均成本"
- PE 市盈率 → "按现在的赚钱速度，回本要几年"；PB → "花几倍的钱买它的净资产"
- 自由现金流 → "一年下来真正落进口袋的现金"
- z-score → "偏离平常水平有多远"；分位数 → "在它自己的历史里排第几"
- 夏普 → "赚得稳不稳"；最大回撤 → "从最高点最深摔过多少"
- 换手率 → "筹码倒手的频繁程度"；质押 → "大股东拿股票借钱，跌狠了会被强制卖"
- 安全边际 → "相当于打了几折买"

正文长度 800–1500 字。宁可短而清楚，不许长而含糊。语气像一个靠谱的朋友帮你把研究读了一遍讲给你听：不端着、不夸张、不推销。

# 红线：反敷衍条款

- 资料里没有的数字，一个都不许出现；**禁止编造**。
- 每个判断后面跟"因为……"，不许只给结论不给理由。
