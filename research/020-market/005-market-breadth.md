# 市场广度（Market Breadth）

## 一、什么是市场广度

市场广度衡量股市参与面的宽度——上涨的股票是多还是少。广度数据可以揭示真实的市场强度是否与指数价格一致。

**核心概念：** 指数上涨但广度下降 -> 上涨集中在少数股票（不健康）。
指数下跌但广度上升 -> 大部分股票已在筑底（可能见底）。

---

## 二、主要广度指标

### 1. A/D 线（涨跌比线）

| 维度 | 说明 |
|:----|:----|
| **计算** | 每日（上涨股数 - 下跌股数）的累计和 |
| **范围** | 纽交所所有股票（最常用）或仅 S&P 500 成分股 |
| **使用** | 价格新高时需要 A/D 线也同步新高 |

**背离信号：**
- A/D 线持续下降，指数创新高 -> 广义市场弱、少数大盘股拉升指数 -> **顶部警告**
- A/D 线持续上升，指数创新低 -> 广义市场在筑底 -> **底部信号**

### 2. 新高/新低指标（NH/NL）

| 维度 | 说明 |
|:----|:----|
| **定义** | 52 周新高股数 vs 52 周新低股数 |
| **比率** | NH / (NH + NL)，> 0.5 时看多 |
| **差数** | NH - NL，正数看多 |
| **来源** | 纽交所、纳斯达克每日发布 |

| 新高-新低差 | 市场状态 |
|:----------:|:--------|
| > 400 | 广泛强势（牛市）|
| 100 至 400 | 正常强势 |
| -100 至 100 | 中性 |
| -400 至 -100 | 弱势 |
| < -400 | 广泛弱势（熊市）|

### 3. 涨跌比（Advance-Decline Ratio）

| AD 比率 | 含义 |
|:------:|:----|
| > 3.0 | 超强广度 |
| 1.5 至 3.0 | 健康 |
| 0.5 至 1.5 | 正常 |
| < 0.5 | 弱势 |
| < 0.2 | 极度弱势 |

### 4. 阿姆斯指数（Arms Index / TRIN）

TRIN = (上涨股数 / 下跌股数) / (上涨成交量 / 下跌成交量)

| TRIN | 含义 |
|:----:|:----|
| < 0.7 | 成交量集中在上涨股（强势）|
| 0.7 至 1.3 | 正常 |
| > 1.3 | 成交量集中在下跌股（弱势）|

### 5. McClellan 摆动指数

McClellan = 涨跌差的 19 日 EMA - 39 日 EMA

| McClellan | 含义 |
|:--------:|:----|
| > +100 | 超买 |
| < -100 | 超卖 |
| 穿越零线 | 趋势确认信号 |

## 三、综合评分体系

改编自 tradermonty 市场广度分析的五区评分系统，将 6 个组件评分加权合成 0-100 的综合分数：

| 组件 | 权重 | 测量内容 |
|:----|:---:|:--------|
| 广度水平与趋势 | 25% | 当前 8MA 水平 + 200MA 趋势 |
| 8MA vs 200MA 交叉 | 20% | 动量信号 |
| 峰谷周期 | 20% | 在广度周期的位置 |
| 看空信号 | 15% | 特定的看空形态 |
| 历史百分位 | 10% | 与全部历史比较 |
| 价格 vs 广度背离 | 10% | 指数与广度是否一致 |

### 综合评分对应

| 分值 | 市场状态 | 建议仓位 |
|:---:|:--------|:-------:|
| 80-100 | 强劲 | 90-100% |
| 60-79 | 健康 | 75-90% |
| 40-59 | 中性 | 60-75% |
| 20-39 | 走弱 | 40-60% |
| 0-19 | 危险 | 25-40% |

## 四、广度背离识别

| 背离类型 | 价格 | 广度 | 信号 | 可靠性 |
|:--------|:---:|:----|:----|:-----:|
| **看空背离** | 新高 | A/D 线未确认（或下降）| 趋势不健康，潜在顶部 | 中高 |
| **看多背离** | 新低 | A/D 线未确认（或上升）| 抛售衰竭，潜在底部 | 中 |
| **趋势确认** | 新高 | A/D 线也新高 | 健康上涨 | 高 |
| **趋势确认** | 新低 | A/D 线也新低 | 广泛下跌 | 确认熊市 |
