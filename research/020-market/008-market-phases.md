# 市场阶段分类（Market Phases）

## 一、概述

市场阶段分析解决的核心问题是：**现在是上涨、下跌还是盘整？** 不同阶段对应不同的投资策略和风控标准。

---

## 二、三阶段趋势分类

### 上升趋势

| 判定标准 | 说明 |
|:--------|:----|
| 价格 > MA50 > MA200 | 均线系统多头排列 |
| 更高的高点 + 更高的低点（HH + HL）| 经典道氏定义 |
| MA50 > MA200（金叉状态）| 长期趋势确认 |
| 广度指标 > 60（健康）| 确认参与面广 |

### 下降趋势

| 判定标准 | 说明 |
|:--------|:----|
| 价格 < MA50 < MA200 | 均线系统空头排列 |
| 更低的高点 + 更低的低点（LH + LL）| 经典道氏定义 |
| MA50 < MA200（死叉状态）| 长期趋势确认 |
| 广度指标 < 40（弱势）| 确认参与面窄 |

### 盘整/横盘

| 判定标准 | 说明 |
|:--------|:----|
| MA50 与 MA200 交织，无明确方向 | 无趋势 |
| 价格在区间内波动（上下 5-15%）| 区间震荡 |
| 成交量萎缩 | 缺乏方向性动力 |

## 三、IBD 五阶段市场分类

### 1. 确认上升（Confirmed Uptrend）

**特征：**
- 主要指数在 MA50 上方
- 出现 Follow-Through Day（FTD）确认底部
- 广度 > 60
- 成交量健康

**策略：** 满仓操作（90-100% 仓位）

### 2. 上升中（Uptrend Under Pressure）

**特征：**
- 指数在 MA50 附近或上方
- 出现 1-2 个派发日
- 广度有所下降
- 领涨股开始出现疲软

**策略：** 正常投资，适度减仓（75-90%）

### 3. 市场顶部（Market In Correction）

**特征：**
- 累计 5 个以上派发日（4-5 周内）
- 指数跌破 MA50
- 广度恶化
- 领涨股大幅下跌

**策略：** 大幅减仓，提高现金比例（50%+ 现金）

### 4. 下降趋势中（Market In Downtrend）

**特征：**
- 指数在 MA50 下方
- 均线空头排列
- 广度 < 40
- 领涨股普遍大幅下跌

**策略：** 仅持有最稳健的防御股，高现金（70%+ 现金）

### 5. 尝试反弹（Market Rally Attempt）

**特征：**
- 指数从低点反弹但尚未 FTD 确认
- 广度指标开始改善
- 尝试反弹的日期进行计数

**策略：** 开始关注买入机会，但先不行动

## 四、Follow-Through Day（FTD）识别

FTD 是 IBD 方法中**确认底部**的核心信号。

| 条件 | 要求 |
|:----|:----:|
| **时机** | 底部后第 4 天或之后 |
| **涨幅** | 主要指数单日涨幅 > 1.2-1.7%（取决于当前市场）|
| **成交量** | 当日成交量 > 前一日 |
| **确认** | 之后市场不跌破 FTD 当日低点 |

> 2020 年 3 月 COVID 底部后出现 FTD（4 月 2 日），确认了新一轮牛市。2008 年 10 月出现假 FTD，之后继续下跌。

---

## 五、顶部识别信号

| 信号 | 说明 | 可靠性 |
|:----|:----|:-----:|
| **派发日** | 指数下跌且成交量 > 前一日 | 4-5 周内 5 个派发日 = 顶部警示 |
| **广度背离** | 指数新高但 A/D 线下降 | 中高 |
| **领涨股崩溃** | 过去最强的股票开始大幅下跌 | 高 |
| **IPO 热潮** | 大量低质量公司上市 | 中 |
| **媒体情绪** | 主流媒体开始鼓吹"这次不一样"| 低 |

### 派发日的判定标准

| 条件 | 要求 |
|:----|:----:|
| **价格** | 指数下跌 |
| **成交量** | 成交量 > 前一日 |
| **幅度** | 跌幅 > 0.2%（越大越可靠）|
| **计数** | 4-5 周内累计 > 5 次 = 顶部确认 |

---

## 六、底部识别信号

| 信号 | 说明 | 可靠性 |
|:----|:----|:-----:|
| **FTD** | 反弹 4 天后放量上涨 | 高 |
| **恐慌性抛售** | 指数暴跌 + 成交量暴涨 | 中高 |
| **V 型底 vs 圆底** | V 型底（快速反弹）或 W 底（双底更可靠）| W 底更可靠 |
| **广度恢复** | A/D 线在指数之前见底 | 中 |
| **领涨股建立底部** | 之前的领涨股形成底部形态 | 中高 |

### 典型底部结构（W 底 / 双底）

```
左底（低点） -> 反弹 -> 右底（略高或略低） -> 突破颈线 -> 确认
    |           |            |                    |
 放量大跌     缩量反弹    成交量萎缩            放量突破
```
