# 研究目录结构 —— 简化规划

> 2026-09-05 起生效。原则：**目录即真相**——文件放哪里，就决定了它是什么；
> 网站报告中心与 AI 一律按此规则解读，不再靠文件名猜。

## 一张图

```
research/
├── 060-companies/<TICKER>-<中文名>/     ← 公司域（报告中心逐公司展示）
│   ├── YYYY-MM-DD/                      ← ★ 自有报告：七层分析产出（一天一目录）
│   │   ├── 00-INDEX.md  01~08 层(.md/.json)
│   │   ├── adversarial_check.json       ← 红队栏数据
│   │   └── sources/                     ← 该日取数存档
│   ├── own/                             ← ★ 自有报告：非七层的本人/本人委托产出（2026-09-05 已全量迁入）
│   ├── community/                       ← ★ 外来资料：书籍摘要、社区文章、公众号、电话会实录
│   ├── <散文件>.md                       ← ❌ 已废除：书架不允许未归类状态，散文件必须迁 own/ 或 community/
│   ├── README.md  TODO.md               ← 元文件，不进书架
│   └── sources/  temp/                  ← 机器目录，网站不展示
└── 070-reports/                         ← 行业/主题研究域（暂不进报告中心，待归类）
    ├── batch/                           ← fengbatch 批量筛选产物
    └── <研究专题>.md / <专题目录>/
```

## 三条判据（人能背、AI 能执行）

| 判据 | 归类 | 理由 |
|------|------|------|
| 在日期目录 `YYYY-MM-DD/` 里，且是 01~08 层产出 | **自有** ✍️ | 七层状态机工具生成，红队栏随目录走 |
| 在 `own/` 子目录里 | **自有** ✍️ | 主人亲判：确属本人产出的散文件移进来 |
| 其余（根目录散文件、`community/`、书系子目录） | **外来** 📥 | 默认外来，宁可标错来源不错认作者 |
