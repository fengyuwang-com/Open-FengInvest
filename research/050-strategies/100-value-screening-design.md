# 全市场筛选层设计 v2 — 多因子排名系统

## 问题

FengInvest 现有框架（L0→L3）一次分析一只股票，缺乏从全市场批量发现候选的能力。

**关键担忧：** 纯价值指标（低 PE/PB、高股息）会漏掉苹果这类"贵的好生意"。苹果常年 PE > 25，
但 ROE ~150%、品牌护城河极深、自由现金流惊人——单看 PE 它永远"不值得买"，但它是过去 20 年最好的美股之一。

**核心思路：** 不要硬杠杠（PE<15），要**多因子排名**。全市场打分排名，Top N 推给你选。

## 四维因子框架

```
┌──────────────────────────────────────────────────┐
│                    总得分                         │
│    Score = 价值×0.25 + 质量×0.35 + 增长×0.25     │
│            + 动量×0.15                            │
└──────────────────────────────────────────────────┘
```

**权重逻辑：** 为什么质量（Quality）最高？因为 L2a 层证明"好生意比便宜更重要"。
这个权重偏向会选出"好生意合理价"类型的标的——正好符合你已有的段永平+巴菲特框架。

### 1. 价值（Value）25%

| 因子 | 计算方式 | 说明 |
|------|---------|------|
| PE | 行业 PE 分位（越低越好） | 跨行业 PE 不可比，用行业内百分位 |
| PB | 历史 PB 分位 | 相对自身历史，不是绝对数 |
| 股息率 | 绝对排名 | 只有正向有意义 |
| FCF 收益率 | FCF / 市值 | 比 PE 更难造假 |

### 2. 质量（Quality）35% ← 核心权重

| 因子 | 计算方式 | 为什么重要 |
|------|---------|-----------|
| ROE | 近 3 年平均 | 段永平"好生意"的量化代理 |
| 毛利率 | 近 3 年平均 | 护城河的量化代理 |
| 负债率 | Debt/Equity，越低越好 | 安全边际的量化代理 |
| 盈利稳定性 | EPS 逐年增长年数 | 好生意的一致性验证 |

**苹果在质量维度得分极高:** ROE 远超同行、毛利率 45%+、净现金、EPS 持续增长。
即使价值分只有中游，综合排名依然靠前。

### 3. 增长（Growth）25%

| 因子 | 说明 |
|------|------|
| 营收 3 年 CAGR | 收入的真实增长 |
| EPS 3 年 CAGR | 盈利增长（比营收更严格） |
| 市场预期增长 | 分析师一致预期（可选） |

### 4. 动量（Momentum）15%

| 因子 | 说明 |
|------|------|
| 6 个月价格收益率 | 中期趋势 |
| 相对强度（vs 大盘） | 跑赢/跑输幅度 |

**为什么动量是必要维度：** 没有动量的筛选会陷入"价值陷阱"——股票便宜是因为确实不行。
动量信号帮助区分"真低估"和"基本面恶化"。

## 不是硬过滤

**这套系统不会说：** PE>15 → 排除。

**它会说：** 全市场 2000+ 股票每个拿四个维度的分数→加权总分→排名→给你 Top 30。

这意味着：
- 一只 PE=8 股息 8% 的银行股，价值分爆表，质量中游，综合排名高
- 一只 PE=28 的科技股（苹果），质量分爆表，增长好，综合排名也高
- 一只 PE=5 但 ROE=2% 负债率 80% 的垃圾股，价值分高但质量分极低，排名不会靠前

**你要的能力就是这个：** 不能错过好生意，也要能筛出真便宜。

## 执行流程

```
┌──────────────────────────────────────────────────────────┐
│  Phase 1: 数据管道                                        │
│  从 yfinance / akshare 拉基本面数据 → fundamentals 表     │
│  增量更新（每周一次，全市场约 3-5 分钟）                   │
├──────────────────────────────────────────────────────────┤
│  Phase 2: 每日筛选                                        │
│  fengscreen.py --market US --top 30                       │
│  → 输出排名 JSON + CLI 表格                               │
│  → 可选维度：价值/质量/增长/动量/综合                     │
├──────────────────────────────────────────────────────────┤
│  Phase 3: 管道集成                                        │
│  候选列表生成后，用 /fenginvest <TICKER> 逐只分析          │
│  或按排名批量触发自动 L0 能力圈检查                        │
└──────────────────────────────────────────────────────────┘
```

## 预期产出示例

```
Rank  Ticker  综合分  价值   质量   增长   动量  亮点
────  ──────  ────  ────  ────  ────  ────  ────────────────
 1    AAPL    87    65    95    88    72    顶级质量+增长
 2    MSFT    85    60    92    85    78    质量+增长双高
 3    某银行   82    95    70    60    55    极度低估、高息
 4    GOOGL   81    55    85    90    70    增长强劲
...
```

注意这个列表不会全是低 PE 股——有贵的好的，也有便宜的可以的。
你在里面挑选感兴趣的标的，走 L0→L3 流程深入分析。

## v1 与 v2 的差异

| 维度 | v1（旧方案） | v2（新方案） |
|------|-----------|-----------|
| 哲学 | 价值因子硬过滤 | 四维度加权排名 |
| 目标 | 找出"低估" | 找出"值得研究" |
| 苹果 | 被筛掉（PE高） | 排名靠前（质量满分） |
| 硬杠杠 | PE<15, PB<1.5 | 没有硬杠杠，全部排名 |
| 输出 | 有限几个通过者 | Top 30 排名列表 |
| 操作 | 每只跑全流程 | 你从列表选感兴趣的 |
