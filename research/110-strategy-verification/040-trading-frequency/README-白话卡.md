## 1) 红绿灯结论

> **🟡 有条件·存疑（方向可信，"0.5%"这个精确数字不能直接采信）**

一句话理由：脚本实测的是 **SP500 指数 200 日均线择时 + 最短持有期约束**，把年交易次数从 6.1 次一路压到 1.3 次，各档 CAGR 全都挤在 5.8%~6.9%（跨度不足 1.2pp）、相邻档变化基本 ±0.1~0.6pp——**"交易频率对收益影响很小"这个方向成立**（与 Odean 1999 "交易是噪音"方向一致）；但两条硬伤不能瞒：**a)** README 方法表写的是"SP500 成分股四种再平衡频率"，和脚本实际做法**根本不是一套东西**；**b)** README 结论还停在"⏳ 待运行"，结果从没抄回去。加上单一指数一条时间序列、无显著性检验，"恰好 0.5%"没有依据。

## 2) 论断原文

> **（注册号漂移提示）** 000-52-claims.md 里 #40 登记为"散户换仓频率越高收益越低，换仓最多的 20% 年化跑输不动的约 6%"（引用 Odean；H₀：换仓频率与收益无关）；本目录实测的是**"交易频率降低一半（从每月改为每两月），年化收益仅提升约 0.5%"**。两个表述不是同一回事，本卡按目录实测口径写，注册号请你方核对。

白话版：把交易次数砍一半，一年下来也就多赚约 0.5 个百分点——意思是大部分交易是白做的噪音。

## 3) 我们怎么测的（0 代码，纯白话）

- **数据**：**一个** SP500 指数（^GSPC）的日收盘价，1927-12-30 ~ 2026-07-20（约 97.2 年、24,753 个交易日）。**注意 README 写"450+ 只成分股、约 2000-2026"，实际用的是指数本身，不是成分股组合。**
- **策略**：200 日均线择时（价 > 年线就持仓、< 年线就空仓），再叠加"买入后**最短持有 N 天**才能卖"来调节交易频率：N = 1 / 10 / 21 / 42 / 63 / 126 / 252 天，共 7 档。
- **成本**：每笔买卖合计 0.1%（脚本 tc=0.001）。
- **统计**：每档算年化 CAGR、最大回撤、每年交易次数；再逐档比较"交易次数降幅"对应的"CAGR 变化"。

| 最短持有 | 年化 CAGR | 最大回撤 | 每年交易数 | 合计交易 |

| 21 天（约 1 个月） | 6.62% | −51.6% | 3.3 次 | 324 |
| 42 天（约 2 个月） | 6.53% | −55.5% | 2.8 次 | 268 |
| 63 天（约 1 季度） | 6.63% | −53.1% | 2.4 次 | 232 |
| 126 天（约半年） | 6.28% | −64.4% | 1.9 次 | 180 |
| 252 天（约 1 年） | 6.91% | −68.2% | 1.3 次 | 128 |

相邻档 CAGR 变化（pp）：−0.23 / +0.81 / −0.09 / +0.10 / −0.35 / +0.63。
脚本自带结论："频率腰斩时 CAGR 变化 **−0.23%**"（它取的"接近减半"档是从 6.1 次/年 → 4.2 次/年，降幅 31%）。
verdict 字段："支持 — 频率减半对收益影响很小，接近 0.5% 论断"（6 档绝对值平均 0.37pp）。

> ⚠️ **诚实警示（无 audit，以下为本卡从脚本与结果核对）**：
> - 论断言"每月 → 每两月"降半，脚本并没有按"每月 → 每两月"这一档单独给结论——它挑的"接近减半"档，CAGR 变化是 **−0.23%（负的：频率略降收益反而小降）**。"恰好 0.5%"更像是对变化量的数量级印象，不是该档实测值。
> - **方向可信的部分**：7 档 CAGR 全挤在 5.8%~6.9%，绝对变化均值 0.37pp ≪ 1pp，确实"影响很小"。
> - **不可全信的部分**：单条指数一条时间序列、无 Bootstrap/t 检验；未复权 close；README 方法与脚本不符、结论没回填（还写着"⏳ 待运行"）。
