# 论断 #40 — 交易频率降低一半，每年仅提升 0.5% 收益

> **一句话：** 大多数交易是噪音。减少交易频率对收益影响微乎其微。

## 论断

"交易频率降低一半（从每月交易改为每两月交易），年化收益仅提升约 0.5%。"
这意味着绝大多数交易对收益几乎没有贡献，减少交易频率带来的好处非常有限。

## 回测方法

1. 以 SP500 成分股 10+ 年日线数据
2. 模拟四种再平衡频率：每月（21天）、每季（63天）、每半年（126天）、每年（252天）
3. 策略：在再平衡日等权买入组合，持有至下一个再平衡日
4. 统计各频率的年化收益、夏普比率、最大回撤、交易频率
5. 计算频率减半对收益的实际影响

## 数据

- 数据源: `data/market_data.db` (US 市场日线)
- 股票数: 约 450+ 只 (有 10+ 年数据的 SP500 成分股)
- 时间范围: 约 2000-2026
