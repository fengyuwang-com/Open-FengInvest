# 论断 #11 — VIX>30 恐慌期买入跑赢平静期

> 来源：research/000-52-claims.md

## 一句话

当市场恐慌情绪高涨（VIX > 30）时买入，比在市场平静时（VIX < 20）买入，后续 1-12 个月的收益更高。"别人恐慌我贪婪"这条经验，数据证明确实有效。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | VIX 和 SPX 日线，1990-01-02 至 2026-07-20（约 36 年） |
| 信号触发 | **恐慌**：VIX 收盘 > 30（734 个交易日）；**平静**：VIX 收盘 < 20（5755 个交易日） |
| 持有期 | 1 个月（21 交易日）、3 个月（63 日）、6 个月（126 日）、12 个月（252 日） |
| 成交规则 | 信号日收盘价买入，T+N 收盘价卖出 |
| 基准对比 | 恐慌期买入收益 vs 平静期买入收益 |

## 关键指标

| 指标 | 恐慌期买入 (VIX>30) | 平静期买入 (VIX<20) |
|:-----|:-------------------|:--------------------|
| 信号天数 | 734 | 5755 |
| 1个月平均收益 | **+2.58%** | +0.63% |
| 3个月平均收益 | **+6.82%** | +1.96% |
| 6个月平均收益 | **+12.92%** | +4.48% |
| 12个月平均收益 | **+22.28%** | +10.61% |
| 1个月胜率 | 71.2% | 64.2% |
| 12个月胜率 | 87.4% | 85.7% |
| VIX>35 高恐慌 12个月收益 | **+28.39%** | — |
| VIX>40 极端恐慌 12个月收益 | **+32.97%**（胜率 96.1%） | — |

## 结论

✅ **支持** — 四个持有期（1/3/6/12 个月）全部验证通过。恐慌期买入的平均收益是平静期的 2-4 倍。VIX 越高，后续收益越强。
