# 52 条可证伪投资论断

> 从 FengInvest 系统中提取的全部可证伪（falsifiable）论断。
> 数据驱动、非纯粹股价驱动、有明确零假设。
> 来源：纪律规则、四大原则、退出纪律、组合管理、行为模式、宏观体制。

---

## 如何阅读

| 列 | 含义 |
|:---|:-----|
| **ID** | 论断编号 |
| **论断** | 可证伪的陈述（即"如果 X 则 Y"） |
| **来源** | 系统内哪个文件 |
| **零假设 H₀** | 凭什么说它可能不对 |
| **需要的数据** | 验证该论断需要哪些非股价独立数据 |
| **当前状态** | 已测试/未测试/不可证伪 |
