# 年线的指示作用——条件概率与持续期分析

> 基于恒生指数、标普500、上证指数、日经225、KOSPI等 2000-2026 年数据的实证检验
> 结论可证伪，方法可复现

---

## 一、研究问题

年线（200日均线）是技术分析中最常用的牛熊分界线之一。所谓"站上年线做多、跌破年线做空"是一种广为流传的经验法则。

本文要回答两个问题：

1. **条件概率**：如果一个指数已经在年线上方/下方持续了 N 天，它最终能坚持 120 天（半年）或 250 天（一年）的概率是多少？
2. **条件期望**：如果一个指数已经在年线上方/下方持续了 N 天，它平均还能再待多久？这比"完全没预测作用"的零假设强多少？

### 核心算法

**步骤 1：识别年线穿越事件**

对每个交易日 t，计算：
```
MA200(t) = 过去200个交易日收盘价的算术平均
above(t) = close(t) > MA200(t) ? 1 : 0
```

**步骤 2：提取持续段**

当 `above(t) ≠ above(t-1)` 时，标志着一次年线穿越。记录每一段连续处于上方或下方的天数。

**步骤 3：条件概率计算**

给定"年线上方已持续 N 天"，最终持续 T 天的条件概率：

```
P(total ≥ T | elapsed ≥ N) = count(streaks_where_total ≥ T) / count(streaks_where_elapsed ≥ N)
```

由于 T > N 时，满足 total ≥ T 的段必然也满足 elapsed ≥ N，简化为：

```
P(total ≥ T | elapsed ≥ N) = count(total ≥ T) / count(total ≥ N)
```

**步骤 4：零假设**

零假设（无预测作用）下，过去的持续时间不包含未来时长的任何信息。此时：

```
E[剩余时长 | elapsed = N] = E[总时长]（无条件期望）
E[总时长 | elapsed ≥ N] = N + E[总时长]
```

如果实际数据中 `E[总时长 | elapsed ≥ N] > N + E[总时长]`，则说明年线确实具有趋势持续性预测能力，倍数越高说明预测能力越强。

### 复现方法

```python
import yfinance as yf
import pandas as pd
import numpy as np

# 1. 获取数据
data = yf.download('^HSI', start='2000-01-01', end='2026-07-21')
close = data['Close'].squeeze().to_frame()
close.columns = ['close']
close['ma200'] = close['close'].rolling(200).mean()
close = close.dropna()
close['above'] = close['close'] > close['ma200']
close['change'] = close['above'] != close['above'].shift(1)

# 2. 提取持续段
streaks, cur, reg = [], 0, None
for i, row in close.iterrows():
    if reg is None:
        reg = row['above']; cur = 1
    elif row['change']:
        streaks.append((reg, cur))
        reg = row['above']; cur = 1
    else:
        cur += 1
if cur > 0:
    streaks.append((reg, cur))

above = [s[1] for s in streaks if s[0]]  # 年线上方段列表

# 3. 条件概率
for n in [5, 10, 20, 60]:
    rc = sum(1 for s in above if s >= n)
    rt = sum(1 for s in above if s >= 120)
    print(f'已持续>= {n:2d}d -> 站满半年: {rt/rc*100:.1f}% ({rt}/{rc})')

# 4. 条件期望
for n in [5, 10, 20, 60]:
    matched = [s for s in above if s >= n]
    total_avg = np.mean(matched)
    remaining_avg = total_avg - n
    print(f'已持续>= {n:2d}d -> 总时长均值{total_avg:.0f}d -> 还能再待{remaining_avg:.0f}d')
```

### 3.4 vs 零假设（无预测作用）

核心检验：**已站上年线10天（2周）→ 还能再待多久？比随机强多少倍？**

|------|---------------------|-------------------|------|:----:|
| **日本ETF(EWJ)** | 10+29=39d | **103d** | **2.7x** | ⭐⭐⭐ |
| **标普500** | 10+58=68d | **165d** | **2.4x** | ⭐⭐⭐ |
| **台湾加权** | 10+42=52d | **110d** | **2.1x** | ⭐⭐ |
| **印度SENSEX** | 10+48=58d | **121d** | **2.1x** | ⭐⭐ |
| **KOSPI** | 10+35=45d | **90d** | **2.0x** | ⭐⭐ |
| **恒指** | 10+39=49d | **96d** | **2.0x** | ⭐⭐ |
| **上证** | 10+34=44d | **87d** | **2.0x** | ⭐⭐ |
| **韩国ETF(EWY)** | 10+42=52d | **99d** | **1.9x** | ⭐⭐ |
| **日经225** | 10+35=45d | **74d** | **1.6x** | ⭐ |
| **沪深300** | 10+33=43d | **72d** | **1.7x** | ⭐ |

**结论**：年线穿越确实有趋势持续性预测能力，但强弱因市场而异：

- **最强（2.4-2.7x）**：日本ETF(EWJ)、标普500。美日市场在年线上方的趋势一旦确认，持续性强
- **中等（1.9-2.1x）**：台湾、印度、KOSPI、恒指、上证、韩国ETF。零假设的2倍左右
- **最弱（1.6-1.7x）**：日经225（指数本身）、沪深300。预测能力有限

### 周线数据降噪（简略）

使用日线已足够。周线测试结果显示结论一致，数字按周换算后更加平滑。

### 指数 vs ETF 差异

同一市场使用指数本身和ETF分别测试，结果存在差异：

| 市场 | 指数倍数 | ETF倍数 | 差异 |
|:----|:--------:|:-------:|:----:|
| 日本 | 1.6x (^N225) | **2.7x** (EWJ) | ETF显著更强 |
| 韩国 | 2.0x (^KS11) | 1.9x (EWY) | 基本一致 |

差异解释：ETF在美国交易，受美股投资者行为影响，趋势自我强化效应可能更明显。也可能是ETF本身的管理费/套利机制导致。

### 年线的微观机制：支撑位 vs 自我实现

年线的"预测能力"来源可能并非神秘的趋势惯性，而是更朴素的机制：

**回踩反弹假说**：所谓"趋势持续"的微观结构可能是：
```
突破年线 → 涨一段见顶 → 回踩年线 → 撑住 → 继续
                                     → 跌破 → 假突破结束
```
即年线作为**技术支撑位**的角色，可能比趋势惯性本身更能解释现象。当大量参与者将年线视为牛熊分界线时，回踩年线会触发"抄底"行为，形成自然支撑。

**自我实现的预言**：正因为年线是技术分析中最广为人知的参考线之一，市场参与者参照同一信号交易——年线之上做多、之下做空——这种行为本身就放大了年线的有效性。这与本文核心结论一致：预测能力确实存在，但倍数有限（1.6-2.7x），远非圣杯。

**实际含义**：年线的有效性部分来自"大家都用它这个事实"。如果未来算法交易全面取代人工判断，年线的预测能力可能下降。

## 五、与投资纪律的对照

本文数据可以用来验证奇衡DK-CAPITAL专栏中提出的几条纪律规则（后发制人、年线法则、2638法则、买分歧卖共识）的统计基础。

| 纪律规则 | 核心内容 | 本文数据支持？ |
|:---------|:---------|:--------------|
| **后发制人** | 等右侧确认（MA50>MA120+站稳MA50）再买入，不左侧抄底 | ✅ **支持**。噪音约1/4-1/3，过早入场被假突破吞噬的概率高。已站10天后条件期望2x，说明等确认是划算的 |
| **年线法则** | 价格低于年线=无追高风险，但仍需等右侧 | ✅ **部分支持**。低于年线确实降低追高风险，但上证上下对称（1.0x）说明在A股低于年线不等于马上会涨 |
| **2638法則** | 恒指在年线之下时控制仓位 | ✅ **支持**。恒指下方平均持续29d，无条件下方均值低于上方（1.3x不对称），说明大盘环境确实影响持仓体验 |
| **买分歧卖共识** | 高波动=分歧=机会，低波动=共识=风险 | ⚠️ **间接支持**。年线附近噪音大（1/4-1/3穿越仅1天），说明突破时刻本身处于分歧状态，需要等共识形成 |

### 核心结论

奇衡的纪律规则与本文数据**方向一致**，逻辑可以被数据支撑：

1. **为什么不追涨**：已站10天后平均还能待3-5个月，追涨不差那几天，等个回踩或右侧确认更踏实
2. **为什么不等跌透了买**：恒指和A股下方持续期不短（均值29-33天），"抄底"可能抄在半山腰
3. **年线的角色**：不是精确买卖信号，而是**趋势过滤器**——用来决定"当前是否适合做多"的宏观背景判断

这些规则不是"神奇的公式"，而是对年线统计特征的理性响应。

## 六、结论

1. **年线穿越有统计显著的预测能力**，但不是"站上去就能待一年"，而是"站上去2周后，平均还能再待3-5个月"——这个窗口足够完成一轮交易。

2. **预测能力因市场而异**：
   - 最强：美股（2.4x）和日本ETF（2.7x）——确认趋势后持续性强
   - 中等：台湾（2.1x）、印度（2.1x）、韩国（2.0x）、港股（2.0x）、A股（2.0x）
   - 最弱：日经225指数本身（1.6x）——噪音虽低但趋势力不强

3. **噪音严重**：约1/4-1/3的日线"穿越"只持续1天。年线适合做趋势确认的辅助参考，不适合做精确的进出场信号。

4. **不对称性普遍存在**：几乎所有市场上方持续期长于下方，但程度差异大。美股2.8倍，A股1.0倍（完全对称）。

5. **条件概率框架**比简单的"在年线上方/下方"二分法更有实用价值。

### 可证伪的预测

本文的核心观点可被以下证据证伪：
- 如果使用本文算法在不同市场（如日经225已在1.6x，进一步降低至<1.3x）
- 如果未来20年数据计算，倍数显著下降
- 如果在个股层面测试，发现无统计显著的持续效应

## 七、局限

- 本分析仅针对指数，个股层面可能存在差异
- 2000年至今的数据包含多个牛熊周期，但不同周期的表现可能有很大差异
- A股指数仅3.5年Futu数据，样本量不足
- 指数和ETF的差异需进一步研究
- 因果性存疑：年线本身不"导致"趋势延续
- **计价货币偏差**：非美市场（日经225、KOSPI、恒指等）以本币计价，但全球资本以美元计价。汇率本身有趋势（如日元长期贬值周期），可能使美元计价的实际趋势持续性系统性高于本币计价结果。日经225的1.6x（本币）vs EWJ的2.7x（美元）即是明证。后续可用美元计价重测所有市场，检验汇率叠加效应。
