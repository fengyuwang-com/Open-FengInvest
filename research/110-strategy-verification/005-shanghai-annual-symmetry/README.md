# 论断 #5 — 上证年线上下对称

> 来源：research/000-52-claims.md

## 一句话

上证综合指数在 200 日均线上方和下方的交易日大致对称——约 53% 在上方、47% 在下方，与美股"多数时间在年线上方"的特征不同。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | 000001.SS（上证综合指数），1997-07-02 至 2026-07-21 |
| 统计方法 | 逐日计算收盘价相对 200MA 的位置 |
| 对称判断标准 | 年线上方占比在 40%-60% 之间视为"对称" |

## 关键指标

| 指标 | 值 |
|:-----|:---|
| 分析总交易日 | 6,838 |
| 年线上方天数 | 3,621 |
| 年线下方天数 | 3,217 |
| 上方占比 | 52.95% |
| 下方占比 | 47.05% |
| 上下方比例 | 1.13:1 |

## 结论

✅ **支持** — 上证指数在年线上方 vs 下方的分布近似对称（53%/47%），与美股（68%/32%）形成鲜明对比。这一特征的差异源于 A 股的强周期性——牛短熊长、涨跌对称。
