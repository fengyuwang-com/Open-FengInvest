# 论断 #28 — 下跌>15%时启动基本面检查

> 来源：research/000-52-claims.md

## 论断

买入后继续下跌>15%时启动基本面检查：
- 如果基本面不变 → 持有
- 如果基本面恶化 → 割
此规则比无规则硬扛减少回撤>20%。

## 零假设 H₀

有规则 vs 无规则无差异。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US (S&P 500) + CN (沪深300) + HK (恒生) |
| 信号触发 | 买入后价格回撤超过15% |
| 组合 A | 硬扛不动（继续持有） |
| 组合 B | 止损退出 |
| 组合 C | 基本面检查（恶化则割，不变则持）— 需要 fundamentals 数据 |
| 持有期 | 触发后 20/63/126 个交易日 |
| 对比 | 三组合在持有期内的最大回撤 |

**基线结论：** 简单止损(-15%)在短期(20d)因锁定亏损而回撤更大，但中长线(63d+)有效降低回撤20-45%。预期基本面检查策略可以在短期缩小止损的负面影响，在中长期维持甚至提升降低效果。

### 基本面检查结果（CSMAR 数据已入库）

全市场三市场统一结论：

| 持有期 | 硬扛(A)回撤 | 止损(B)回撤 | 基本面检查(C)回撤 | C vs A 改善 | C vs B |
|:------:|:-----------:|:-----------:|:----------------:|:-----------:|:------:|
| **US** | | | | | |
| 20日 | 13.22% | 15.00% | 13.58% | -2.72% ❌ | C更好（避免不必要止损）|
| 63日 | 20.60% | 15.00% | 18.67% | **+9.35%** ✅ | B更好 |
| 126日 | 26.60% | 15.00% | 22.84% | **+14.11%** ✅ | B更好 |
| **CN** | | | | | |
| 20日 | 10.23% | 15.00% | 10.95% | -6.99% ❌ | C更好 |
| 63日 | 18.96% | 15.00% | 17.71% | **+6.57%** ✅ | B更好 |
| 126日 | 26.41% | 15.00% | 23.59% | **+10.66%** ✅ | B更好 |
| **HK** | | | | | |
| 20日 | 12.18% | 15.00% | 12.61% | -3.56% ❌ | C更好 |
| 63日 | 20.77% | 15.00% | 19.16% | **+7.74%** ✅ | B更好 |
| 126日 | 27.30% | 15.00% | 23.86% | **+12.58%** ✅ | B更好 |

**核心结论：**
- 基本面检查(C)中长期(63d+)优于硬扛(A)，改善幅度 6-14%
- 但简单-15%止损(B)在所有周期都优于基本面检查(C)——锁定亏损纪律远强于主观判断
- 基本面的价值在短期(20d)：避免不必要的止损（C比B好）
- **论断"减少回撤>20%"不成立** — 实际改善仅 6-14%
- 建议：长线持仓用-15%硬止损+B基本面检查辅助判断何时重新入场
