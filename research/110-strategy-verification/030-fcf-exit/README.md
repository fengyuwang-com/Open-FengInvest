# 论断 #30 — PE高于95%分位，或市值/FCF>50倍，应该清仓

> **一句话：** 当一只股票贵到离谱（PE历史最高5%）或者市值/FCF>50倍，清仓确实能避免单笔亏损，但也会错过后续上涨——因为高估值信号并不总是对应下跌。

---

## 这个论断在说什么

比#29更严格的清仓策略：满足任一条件即卖：

1. **PE高于历史的95%分位** — 比#29的80%更极端
2. **市值 / 自由现金流 > 50倍** — 市值相对于现金流太贵

### FCF的准确计算

自由现金流 = 经营现金流（operating_cf_net）- 资本支出（capital_expenditure）

2026-07-23已从CSMAR补填CAPEX，FCF计算可用。

---

## 怎么测的

| 维度 | 说明 |
|:-----|:------|
| **数据** | CSMAR A股（PE_TTM/OCF/CAPEX/市值），日线价格 |
| **股票池** | 286只CN股票 |
| **信号** | PE>95%分位 或 市值/FCF>50（FCF>0时才计算） |
| **策略** | 有信号 → 清仓0%；否则满仓 |
| **持有期** | 3/6/12个月 |

---

## 结果

**论断有条件 🟡** — 清仓确实完全避免了亏损（策略回撤=0），但退出信号区间的平均持有收益是正的，说明清仓时错过了不少上涨。

| 指标 | 退出信号区间(持有) | 退出信号区间(清仓) | 无信号区间 |
|:-----|:-----------------|:-----------------|:----------|
| **3个月平均收益** | 4.37% | 0% | 3.95% |
| **6个月平均收益** | 8.11% | 0% | 7.85% |
| **12个月平均收益** | 17.04% | 0% | 18.48% |
| 退出信号占比 | ~26% | - | - |
| 退出区间胜率 | ~50% | - | - |

### 为什么？

1. **退出信号太频繁（26%）**：每4个季度检查就有1次退出信号。如果26%的时间都在空仓，长期累积收益少很多。
2. **退出区间胜率≈50%**：有信号时持有并不一定亏钱（胜率约50%），所以清仓很多时候是"白清"。
3. **FCF>50倍的条件过宽**：市值/FCF>50在A股中很常见（特别是高成长公司FCF低），导致很多正常股票也被清仓了。

### 什么时候有用？

如果把阈值收紧到更极端的水平（如PE>99%分位 或 FCF收益率<1%即市值/FCF>100），误报率会大幅降低，清仓策略可能更有价值。
