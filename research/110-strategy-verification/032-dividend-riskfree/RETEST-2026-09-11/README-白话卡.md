# 白话论断卡 #32 — 股息率>无风险利率且可持续派息的公司长期跑赢不派息公司

- **复测日期**：2026-09-11
- **判定**：❌ **复测否定**（方向反了：派息组显著跑输）
- **引擎**：`dividend-vs-rf`（`python tools/fengverify.py 32`）
- **结果文件**：[results.json](results.json)

## 论断在说什么（人话）

"买入股息率比无风险利率高、且派息可持续的公司，长期持有比买不派息的公司赚得多"——息价原则的量化表达。

## 数字结果

| 指标 | 数字 |
|:-----|:-----|
| 设计 | US 股票年度队列（2012-2025，共 14 个），每年首个交易日建仓、持有 252 交易日 |
| A 组 | 股息率（过去 365 天派息/现价）> 无风险利率（^TNX）且过去 5 年 ≥3 年有派息 |
| B 组 | 截至 t 从未派息的 US 股票 |
| **年均差（A−B）** | **−13.49%**（派息组跑输） |
| 95% CI（股票层 two-sample bootstrap，2000 次）| **[−17.1%, −10.0%]**，全负 |
| 队列胜率 | 21%（14 个队列里只有 3 个 A 组赢：2016/2021/2022）|
| 样本外（最后 3 个队列）| 均差 −25.8%，方向一致 |

## 判定理由与注意事项

1. **零假设被强烈拒绝**：不是"无关"，是显著反向。跑输集中在成长股大年（2013 −21.8%、2020 −49.9%、2023 −42.4%）——不派息组被科技/成长股主导，2012-2025 美股长牛恰好是成长股的超级行情。
2. **解释性阈值已量化披露**（铁律一）："可持续派息"= 过去 5 个日历年 ≥3 年有派息；持有期 1 年（"长期"的量化代理，1 年偏短，若用 3-5 年持有差距可能收窄但方向难翻转——未验证）。
3. **口径边界**：本测的是"派息 vs 不派息"的收益差，不是"高股息策略失败"——A 组本身年均 15-20% 也是正收益；否定的是"跑赢不派息公司"这个相对论断。
4. **幸存者偏差**：本地库只有当前成分快照，两组都偏乐观；退市的高息股（如被裁息的银行股）缺下跌段，方向上对 A 组略有利，因此否定结论偏保守。
5. 数据源：本地 DB `dividends`（US，5.4 万行）+ `daily_data` + `^TNX` 无风险利率，全本地无外部依赖。

## 对系统的含义

- 息价原则里"股息是回报之锚"在美股 2012-2025 样本内**不构成选股优势**；股息的价值应理解为现金流纪律与回撤缓冲，而非超额收益来源。
- 与 #33（回购漂移→低 PE 高 ROE 🟡）合并看：股东回报形式（回购/股息）本身不是选股信号。
