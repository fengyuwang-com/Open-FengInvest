# 论断 #32 — 股息率高于无风险利率时，持有该股票跑赢

> **一句话：** 高股息率股票（>4%）的胜率确实更高（54.8% vs 49.8%），但平均收益反而更低——因为高股息股涨得慢，分红收益弥补不了涨幅差距。

---

## 这个论断在说什么

当股票分红回报超过国债利率时，理论上股票的性价比比债券高。

### 数据限制

**数据库中不包含中国10年期国债收益率。** 本脚本使用方法A（固定阈值4%）为主，方法B（外部国债利率）为预留。

### 股息率计算

TTM股息率 = 过去12个月每股股息之和 ÷ 当前股价

---

## 怎么测的

| 维度 | 说明 |
|:-----|:------|
| **数据** | dividends表 + daily_data + cn_financials |
| **股票池** | 286只CN股票 |
| **方法** | 股息率>4% 组 vs <=4% 组 |
| **持有期** | 3/6/12个月 |

---

## 结果

**论断被拒绝 ❌** — 高股息率组平均收益反而低于低股息率组。

| 指标 | 股息率>4% | 股息率<=4% | 超额 |
|:-----|:---------|:----------|:----|
| **3个月平均收益** | 3.11% | 4.04% | **-0.94%** |
| **6个月平均收益** | 6.14% | 7.45% | **-1.31%** |
| **12个月平均收益** | 13.51% | 17.13% | **-3.62%** |
| 3个月胜率 | 54.8% | 49.8% | |
| 6个月胜率 | 55.3% | 49.8% | |
| 12个月胜率 | 58.1% | 50.8% | |
| 平均股息率(高组) | 5.8% | - | |
| 信号占比 | ~12% | - | |

### 有趣的矛盾

高股息率组**胜率更高**但**平均收益更低**：
- 高股息股多为成熟/防御型股票（银行、公用事业等），"不怎么会跌"
- 但也"不怎么会涨"——涨幅小，分红收益弥补不了这个差距
- 低股息率组（成长股）胜率低（~50%），但一旦上涨幅度很大

### 需要外部数据

方法B（国债利率比较）目前没有数据。如果能获取CN 10Y国债利率历年数据（Investing.com/Wind），可以更准确地验证"股息率>国债利率"这个论断。

### 当前建议

- 高股息股适合防守（降低波动），不适合追求超额收益
- "股息率>无风险利率"可能更适合债券替代策略，而非超额收益策略
