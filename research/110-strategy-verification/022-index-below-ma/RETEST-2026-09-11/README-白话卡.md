# 论断 #22 白话卡：大盘跌破年线时降仓到 30%，短期回撤会更低吗？

> 复测日期：2026-09-11 ｜ 引擎：`annual-line-reduce-mdd`（fengverify.py 22）｜ 结论：**✅ 支持（方向成立，幅度远小于旧口径宣称）**

## 一句话说人话

**30 个市场指数全部验证：跌破年线把仓位降到 30%（而不是清仓），确实能让滚动半年窗口的回撤更低——平均降 17%，样本外也成立。** 这是年线家族四条论断里第一条复测后仍站得住的，而且和 #2 的教训正好凑成一对：**降一部分（30%）比全清（0%）好——全清是"回撤降得少还赔上收益"，降三成是"回撤真降了、上涨也还在场"**。

## 怎么测的（普通人版）

- 规则：昨天收盘在年线（200 日均线）下方 → 今天只留 30% 仓位；在上方 → 100% 满仓。买卖时扣 0.25% 成本，现金不计利息（保守）。
- 对照组：永远满仓不动。
- 量法：每 126 个交易日（约半年）算一段的最大回撤，"降仓版比满仓版回撤低多少"就是降幅。全库 30 个指数、11,048 个窗口混在一起统计。
- 公平性：仓位由**前一天**收盘决定、管**今天**的涨跌（不偷看未来）；后半段数据单独复跑（样本外）；固定随机种子可重跑复核。

## 数字

| 指标 | 结果 |
|---|---|

| 窗口中位数 | +0.99%（大部分窗口降幅很小，效应集中在熊市段） |
| 样本外（各指数后 20%） | **+14.47%**，仍为正 |
| 30 个指数方向 | **30/30 窗口均值全部为正** |
| 全程最大回撤降幅 | 大多为正；最高 Nifty 46.8%/吉隆坡 46.3%/DAX 45.8%/澳洲 45.3%/标普TR 44.4%；最低创业板指 +1.7%，仅富时100 一家为负（−3.9%） |

## 判定与旧口径

- 判定 **✅**：这是**方向性（定性）论断**——只说"回撤更低"，不说降多少。主判据 = 降幅 >0 且置信区间下限 >0，两条都满足（铁律一：不给方向性论断硬安阈值，#2 的教训）。
- 旧台账写"✅ 回撤降低约 69%"——**幅度明显夸大**（旧法只测 US/CN/HK 三指数、旧窗口口径）。方向对，数字不可比、不可引用 69%。

## 红绿灯（10 项）

判据对齐 ✅ ｜ 价格口径 ✅ ｜ 无前视 ✅ ｜ 成本 ✅（只对切换差额扣 25bps，现金不计息）｜ 显著性 ✅（圆形块 bootstrap 2000 次，块长 22）｜ 重叠样本 ⚠️（相邻窗共享约 83% 数据 + 跨指数同日历相关，块 bootstrap 缓解非消除）｜ 样本外 ✅ ｜ 幸存者偏差 ✅（指数层面不适用）｜ 旧口径对照 ⚠️（69% 不可比）｜ 可复现 ✅

## 给普通人的启示（将进 D4 策略卡素材）

1. **"跌破年线降仓到三成"是可执行的防守动作**：日线看一眼均线，手动调仓，每天几分钟。
2. **别清仓**：#2 已证全清 0% 仓位版在个股上失效、OOS 为负；30% 底仓版 30/30 指数为正——**留着底仓既保住反弹参与度，也照样压回撤**。
3. **别指望它天天有用**：中位数窗口只降 1%，好处集中在熊市；它是保险，不是收益引擎。
4. 代价：牛市段会跑输满仓（年线上方无差别，但切换点附近有摩擦）；富时100 这类长期震荡市里几乎白忙。
