# 论断 #22 — 大盘低于年线降仓降回撤

> 来源：research/000-52-claims.md

## 论断

大盘低于年线时降仓位至<30%，比不降仓位的组合在短期内回撤低。

## 零假设 H₀

不降仓位无额外风险。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US SP500 + CN 上证 + HK 恒生 |
| 信号触发 | 收盘价 < 200日均线 |
| 组合 A | 持仓30%，现金70% |
| 组合 B | 持仓100% |
| 持有期 | 20 / 63 / 126个交易日（~1/3/6个月）|
| 对比 | A的最大回撤 vs B的最大回撤 |

## 运行

```bash
python research/110-strategy-verification/022-index-below-ma/verify-022-index-below-ma.py --all-markets
```

## 结果

| 市场 | 持有期 | 回撤A(30%) | 回撤B(100%) | 降低% | 支持? |
|:-----|:------:|:---------:|:-----------:|:-----:|:-----:|
| US | 20日 | 1.74% | 5.70% | 69.48% | ✅ |
| US | 63日 | 3.32% | 10.69% | 68.96% | ✅ |
| US | 126日 | 4.74% | 15.04% | 68.47% | ✅ |
| CN | 20日 | 1.77% | 5.80% | 69.48% | ✅ |
| CN | 63日 | 3.51% | 11.28% | 68.87% | ✅ |
| CN | 126日 | 4.91% | 15.43% | 68.16% | ✅ |
| HK | 20日 | 2.12% | 6.92% | 69.39% | ✅ |
| HK | 63日 | 4.02% | 12.89% | 68.86% | ✅ |
| HK | 126日 | 5.76% | 18.18% | 68.31% | ✅ |

**结论：** ✅ **全市场全期限支持。** 大盘低于年线时降仓至30%，平均降低回撤约68-69%。这一结论在US/CN/HK三个市场保持惊人的一致性，且不受持有期影响。年线法则有效。
