# 论断 #34 — PB<1 + 股息率>3%的银行股有超额收益

> **一句话：** 在银行股中选"跌破净资产+高分红"的组合，年化收益5.14%，比持有全部银行股多赚1.37%/年——而且最大回撤从65%降至22%。**这个策略有效。**

---

## 这个论断在说什么

A股银行股长期低估（很多破净），但分红稳定。用PB<1和股息率>3%做双重筛选：

- **PB < 1（破净）：** 股价低于每股净资产，市场过度悲观
- **股息率 > 3%：** 银行依然在稳定分红，运营健康
- 同时满足 = "被错杀的银行股"

---

## 怎么测的

| 维度 | 说明 |
|:-----|:------|
| **数据** | CSMAR（PB）+ dividends + daily_data |
| **股票池** | 24只银行股（industry_csrc='J66'，有价格数据） |
| **筛选** | PB < 1 AND TTM股息率 > 3% |
| **权重** | 等权重，季度再平衡 |
| **基准** | 全部银行股等权 |
| **回测期间** | 2005年3月 ~ 2026年6月 |

---

## 结果

**论断被支持 ✅** — 策略超额+1.37%/年，同时最大回撤从65.79%降至22.59%。

| 指标 | 策略(PB<1+股息率>3%) | 基准(全部银行股) |
|:-----|:------------------|:--------------|
| **累积收益** | **290%** | 220% |
| **年化收益(CAGR)** | **5.14%** | 3.77% |
| **超额年化** | **+1.37%** | - |
| **最大回撤** | **22.59%** | 65.79% |
| **夏普比** | **0.24** | 0.19 |
| 季度胜率 | 37.6% | 52.9% |
| 平均每期选中 | 8只 | 24只 |

### 关键发现

1. **超额收益来自回撤控制而非更高收益**：策略年化5.14%并不高，但最大回撤只有22.59%（基准65.79%）。因为PB<1的银行股已经"跌不动了"。

2. **夏普比0.24 > 0.19**：风险调整后的回报更好。

3. **银行股整体收益不高**：银行股基准年化只有3.77%，策略5.14%——都远低于#33的15.94%。银行股是"慢钱"。

4. **胜率反而更低**：策略季度胜率37.6% < 基准52.9%，说明选中银行股经常也亏，但亏得少——这才是回撤控制的来源。

### 实际意义

- 适合作为低风险底仓配置
- 在银行股组合中加入此筛选，可以大幅降低尾部风险
- 可与#33的低PE+高ROE策略组合使用（在不同市场环境中表现）
