# 白话论断卡 #21 — 上证跌破 2638 就降到三成仓，6 个月回撤能降三成吗？

> 复测日期 2026-09-11 · 引擎 rule-2638-position-cap · `python tools/fengverify.py 21`
> 数据：上证综指 000001.SS（1997-07-02 ~ 2026-08-21，7,060 个交易日，前复权）

## 一句话结论：❌ 差 1 个百分点没过线（降幅 29.05% vs 判据 30%），而且这条规则 2019 年后已永久失活

论断声称"上证 <2638 时仓位 ≤30%，6 个月内回撤比满仓低 >30%"。协议复测：**31% 的判据没到**——但更重要的是，**上证指数自 2019-02-11 之后再也没有回到过 2638 下方，这条规则在今天已经永远不会触发**。

## 旧结论为什么是 ✅67.2%？

旧口径只统计了**规则触发期间的窗口**（跌破 2638 时），相当于只考"规则起作用的时候它表现多好"，把 2019 年后永不触发的 7 年和 1998 前后的时间全部剔除。协议复测按论断原话"6 个月内回撤低 >30%"做**无条件全窗口**统计——规则必须经常起作用才配得上这个承诺。

## 这对你的操作意味着什么

1. **这条法则已经死了**：上证在 2,600 点位太久远了，规则 2019 年起零触发。留着它只占脑子内存。
2. 即便在它活着的年代，它也只是"勉强及格线以下"的降回撤工具：全程最大回撤只降 3.6%——因为 2008 和 2015 两次大崩盘都发生在 2638 上方，规则全程旁观。
3. 与 #2 年线法则（同为 ❌）合起来看：**固定价位/移动均线类"跌破就减仓"规则的真实降回撤能力在 0~45% 区间，远低于口诀承诺，且都有长期失灵时段**。
4. 它真正证明的只有一件事：熊市里仓位轻确实回撤小（这是算术，不是预测力）。
