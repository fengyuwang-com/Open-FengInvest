# 论断 #1 — 年线上方买入收益优于下方

> 来源：research/000-52-claims.md

## 一句话

当股价站上 200 日均线（年线）时买入，未来 1/3/6 个月的胜率和平均收益均优于在年线下方买入。持有期越长，优势越明显。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | 全部 19 个市场的全部股票，含 US/CN/HK/JP/KR 等 |
| 信号触发 | 每个交易日：收盘价在 200MA 上方 / 下方 |
| 持有期 | 20 天（约 1 月）、60 天（约 3 月）、120 天（约 6 月） |
| 分组 | 每个股票每日分为 "above" 组（close > 200MA）或 "below" 组（close <= 200MA） |
| 统计指标 | 各组胜率、平均收益率、胜率差值 |

## 关键指标（19 市场汇总）

| 持有期 | 年线上方胜率 | 年线下方胜率 | 差值 | 信号量（上/下） |
|:-------|:------------|:------------|:-----|:---------------|
| 20天 | 55.5% | 53.9% | +1.5% | 749万 / 471万 |
| 60天 | 59.7% | 56.6% | +3.1% | 744万 / 467万 |
| 120天 | 63.1% | 58.6% | +4.5% | 737万 / 463万 |

## 结论

✅ **支持** — 年线上方买入在大多数市场（17/19）有更高胜率，长期持有（120天）效果最明显。但年线信号在美股（US）和A股（CN）的区分力很弱。
