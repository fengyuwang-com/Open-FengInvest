# 论断 #8 — 月涨幅>30%后次月上涨概率<40%

> 来源：research/000-52-claims.md

## 论断

月涨幅 >30% 的标的，次月继续上涨的概率 <40%。

## 零假设 H₀

月涨幅对未来收益无预测能力，次月涨跌概率≈50%。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US (S&P 500) + CN (沪深300) + HK (恒生) |
| 信号触发 | 某日历月收盘价较上月收盘价涨幅 >30% |
| 持有期 | 次月整月（持有到次月末收盘） |
| 成交规则 | 当月最后一个交易日收盘买入，次月最后一个交易日收盘卖出 |
| 基准对比 | 随机月份买入的胜率（≈50%） |
| 统计检验 | 次月上涨概率是否显著 <40% |

## 运行

```bash
python research/110-strategy-verification/008-monthly-surge/verify-008-monthly-surge.py --all-markets
```

## 数据来源

- 数据库：`data/market_data.db` — daily_data（前复权 close）

## 回测结果

| 指标 | US SP500 | CN CSI300 | HK HSI |
|:-----|:---------|:----------|:-------|
| 总信号数 | 2,070 | 1,744 | 332 |
| 次月上涨次数 | 1,133 | 848 | 174 |
| 次月上涨率 | 54.7% | 48.6% | 52.4% |
| 有信号的股票数 | 371/503 | 268/300 | 70/85 |

## 结论

❌ **拒绝**（三市场一致）

月涨幅>30%后次月继续上涨的概率在 48-55% 之间，接近随机水平(50%)，并非论断预测的 <40%。美股还略微偏正(54.7%)，说明暴涨后有一定动量延续效应。

注意: v1 简单版本，使用月度收盘价。未来可扩展周度分析、多阈值(20%/50%)、不同持有期。
