# 白话论断卡 · 论断 #8「月度暴涨后动量反转」

> 复测版（引擎：`fengverify.py` monthly-surge-prob 模式，契约见 000-claims-def.md）。全卡 0 代码，5 秒扫结论，30 秒看懂方法，要抠细节点证据链。

---

## 1) 红绿灯结论

> **❌ 不成立（拒绝）**

一句话理由：**月涨幅 >30% 之后次月继续上涨的概率是 51.6%，不是论断说的 <40%**——确实比普通日子略低一点点（对照组 54.6%，差约 3 个百分点且统计显著），但远没到"反转成不到 4 成上涨"的程度。旧脚本三市场结论（48-55%）在新引擎 19 市场全量复测下再次确认。

---

## 2) 论断原文

> 单月涨幅 >30% 的标的，次月继续上涨的概率 **<40%**（月度动量反转）。
> —— 000-52-claims.md #8；H₀：月涨幅 >30% 无预测能力（次月上涨概率 = 50%）。

白话版：一只股票一个月暴涨超过 30% 之后，下个月还能涨的可能性不到 40%，"暴涨之后大概率回落"。

---

## 3) 我们怎么测的（0 代码，纯白话）

- **数据**：本地数据库 19 个市场全部股票（约 2000 只，含 US/CN/HK/JP/KR 等），用每日前复权收盘价。
- **找信号**：对每只股票的每个交易日，看它**过去 20 个交易日（≈1 个月）涨了多少**；涨幅 >30% 那天就算一次"暴涨日"（信号组），其余日子算对照组。
- **看结果**：每出现一次暴涨信号，从**次日开始往后数 20 个交易日（次月）**，看这个月结束时股价比开头高还是低。高=上涨（记 1），低=下跌（记 0）。
- **算概率**：把所有暴涨信号日的"上涨"占比算出来，对照 40% 的判断线；同时给对照组（没暴涨的普通日子）同样算一个上涨率作基准。
- **防偷看**：信号用的 20 天涨幅在当天收盘就能知道，结果的涨跌只数之后的 20 天，不存在"拿未来预测未来"。
- **统计检验**：把每只股票坍缩成"一个上涨率"，用 2000 次重抽样给出 95% 置信区间，避免"单只股票反复暴走"造成的假信号。

## 4) 关键数字（全部市场汇总，直接来自 results.json）

| 指标 | 数字 | 说明 |
|:-----|:----:|:-----|
| 信号组·次月上涨率 | **51.6%** | 暴涨日之后次月上涨的天数占比（17.2 万天样本） |
| 信号组·股票等权上涨率 | **50.7%** | 每只股票一票，避免大票刷屏 |
| 信号组 95% 置信区间 | 49.6% – 51.6% | 重抽样 2000 次；整条区间都在 40% 线上方很远 |
| 对照组·次月上涨率 | 54.6% | 没暴涨的普通日子，次月上涨基准 |
| 信号组 − 对照组 | **−3.0 个百分点** | 暴涨后确实略低于基准，方向是"弱反转" |
| 差异的 95% 置信区间 | −4.1 ~ −2.1 个百分点 | 不含 0 → 弱反转是真的，但幅度太小 |
| 样本外（后 20% 时段） | **53.3%** | 独立时段重测，依然远离 40% 线 |
| 判据线（42 条里唯一说 <40%） | 40% | 结论要求的"反转上限" |

> 📌 **重点**：51.6% ≈ 50%（掷硬币），和论断要的 <40% 差着 10 个百分点的鸿沟。暴涨后"稍微弱于普通日子"（−3pp）这个现象是真实存在的，但把它说成"大概率回落"就言过其实了。

分市场细数（US 54.8% / CN 48% 级 / HK 52% 级…）见 `results.json` 的 per_market。

## 5) 是否可采信（协议红绿灯）

按方法论铁律一~四 + 8.1 回测标准协议逐项核对：

| 检查项 | 状态 | 一句话说明 |
|:-------|:---:|:-----------|
| 判据对齐：测的确实是论断说的那个量 | ✅ | 论断说"次月上涨概率 <40%"，主判据就是信号组上涨概率 vs 阈值 |
| 价格口径：复权 / 交易成本 | ✅ | 前复权收盘价；本论断是概率统计、不涉及策略收益，成本不参与计算 |
| 成交时机：无前视 | ✅ | 信号 T 日收盘确定，评估从 T+1 起算 |
| 显著性：差异有统计检验 | ✅ | 股票级 block Bootstrap 2000 次：信号组均值 CI [49.6, 51.6]，与基准差异 CI 不含 0 |
| 重叠样本处理 | ⚠️ | 逐日滚动 20 天窗口高度重叠 → 已用"每股坍缩均值 + 股票级 bootstrap"缓解；跨股同日历相关未建模 |
| 样本外验证（后 20%） | ✅ | 53.3%，与全样本同向拒绝 |
| 幸存者偏差（含退市股） | ⚠️ | 本地库仅当前成分股快照，不含退市/被剔除股 → 上涨率方向已知（受高估收益影响）；现有数据无法修复 |
| 方法对标权威文献（铁律四） | ⚠️ | 采用标准事件研究口径 + Bootstrap；未做多阈值（20%/50%）敏感性遍历 |

> **结论**：判据、口径、显著性、样本外四项全绿，两条 ⚠️ 均不影响本判（幸存者偏差会**高估**上涨率，只会让"拒绝"更稳而不是翻案）。这条论断可以放心记为 **❌ 不成立**。

## 7) 下一步（≤3 条）

1. **多阈值敏感性**：把 30% 换成 20%/50%/100% 跑一遍，看"极端暴涨（>100%）"是否出现更接近反转的行为 —— 论断可能只在极端档才成立。
2. **换持有期**：把"次月 20 天"换成 5/60/120 天，探测反转是否延迟出现（短期动量、中期反转的经典时间结构）。
3. **事件样本去重叠**：同一标的连续多日触发信号时只取第一个，复核弱反转（−3pp）的稳健性。
