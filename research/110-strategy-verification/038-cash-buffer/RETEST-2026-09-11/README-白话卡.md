# 白话论断卡 — #38 满仓 vs 15% 现金（暴跌加仓能力）

> 复测日期：2026-09-11 ｜ 引擎：cash-buffer ｜ 判定：✅ 支持 ｜ 原话：现金比例<10% 的组合在暴跌时失去加仓能力，3 年收益跑赢保持 15% 现金的概率 <60%

## 一句话结论

**论断成立**：584 个 3 年窗口里，满仓组合只跑赢"85% 仓位+15% 现金（暴跌时加仓）"策略 **49.5%** 的次数——和抛硬币差不多，远低于 60% 的门槛。留 15% 现金不是"拖后腿的保险"，在波动大的市场里它反而是**净收益来源**。

## 我们测了什么

- 7 个有指数数据的市场（US/CN/JP/HK/KR/TW/IN，其余 10 市场指数分类无数据已披露），每市场取日期覆盖最长的主指数。
- 584 个 3 年滚动窗口（756 交易日、步长 126），两种打法对比：
  - **A 满仓**：100% 指数。
  - **B 现金缓冲**：85% 指数 + 15% 现金（现金 0 收益、每日再平衡），指数从高点回撤 ≥20% 时把现金一次投入。
- block bootstrap 2000 次（固定种子 20260820），窗口池后 20% 作样本外。

## 关键数字

| 市场 | 满仓跑赢频率 | ≥20% 回撤窗口占比 |
|:-----|:-------------|:------------------|
| US | 57.1% | 53.9% |
| IN | 54.9% | 74.5% |
| JP | 53.9% | 73.9% |
| CN | **39.2%** | **96.1%** |
| HK | 41.7% | 94.4% |
| TW | 39.2% | 88.2% |

- 均值差：满仓 3 年 CAGR 平均只比现金策略高 **0.31 个百分点**——收益差可忽略。
- **成熟市场（US/JP/IN）是五五开，波动大的市场（CN/HK/TW/KR）现金策略赢大多数窗口**。中国窗口里 96% 出现过 ≥20% 回撤——在这些市场，满仓意味着暴跌时只能干瞪眼。
- 回撤 ≥20% 的触发很常见：全样本 584 窗口平均 3 个里 2 个遇到暴跌，"等暴跌加仓"不是稀有事件，是常态机会。

## 怎么读（给普通人）

1. **满仓的"多赚"是幻觉**：平均只多赚 0.31%/年，代价是暴跌时没有子弹——而暴跌在新兴市场几乎年年见。
2. **15% 现金不是防守，是进攻的预付款**：跌 20% 买进去的那一笔，长期看基本把现金拖累全部赚回，还常常反超。
3. **结合 #23 滚存结论**（震荡市滚存 +21.5%、牛市抽水）：留现金/减仓在震荡与暴跌市场是对的，单边大牛市才吃亏——而没有人能预知哪年是大牛市。
4. 实操：永远留 10-15% 现金；跌 20% 分批投出去，别一次梭哈（本引擎测的是一次投入，分批只会更稳）。

## 判定说明（诚实披露）

- 现金按 0 收益计（未计利息/货基收益）——这偏乐观于满仓一侧，即**真实世界现金策略会更好看**，结论方向更稳。
- 判据的 60% 阈值是原话自带的量化（"跑赢...的概率 <60%"），非解释性补丁。
- 指数口径无幸存者问题；10 个市场指数分类在库无日线，未覆盖已披露。
