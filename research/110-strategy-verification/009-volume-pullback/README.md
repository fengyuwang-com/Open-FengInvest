# 论断 #9 — 缩量回踩支撑位不破后反弹概率>60%

> 来源：research/000-52-claims.md

## 论断

缩量回踩支撑位不破后，后续反弹概率 >60%。

## 零假设 H₀

缩量回踩无预测能力，后续涨跌概率≈50%。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US SP500 + CN CSI300 + HK HSI |
| 信号触发 | 价格从 50MA 上方回落至 50MA 附近(±1%)，成交量 < 20日均量×0.7 |
| 持有期 | 支撑确认后持有 20 日 |
| 支撑确认 | 触发后 5 日内价格不跌破 50MA |
| 基准对比 | 随机买入的胜率(≈50%) |

## 运行

```bash
python research/110-strategy-verification/009-volume-pullback/verify-009-volume-pullback.py --all-markets
```

## 结果

| 市场 | 胜率 | 信号数 | 结论 |
|:-----|:----:|:------:|:----:|
| US SP500 | 73.0% | 25,191 | ✅ 支持 (>60%) |
| CN CSI300 | 66.4% | 5,743 | ✅ 支持 (>60%) |
| HK HSI | 71.2% | 2,110 | ✅ 支持 (>60%) |

**结论：** ✅ **全市场支持。** 缩量回踩支撑位的反弹概率在 US (73.0%)、CN (66.4%)、HK (71.2%) 均超过 60% 阈值，论断获得三市场一致支持。
