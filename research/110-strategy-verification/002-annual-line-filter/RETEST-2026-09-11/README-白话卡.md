# 白话论断卡 #2 — 年线过滤能把最大回撤降一半以上吗？

> 复测日期 2026-09-11 · 引擎 annual-line-filter-mdd · `python tools/fengverify.py 2`
> 数据：19 市场 2,012 只个股 + 30 条市场指数（本地库，前复权）

## 一句话结论：❌ 降不到一半——个股平均只降 3.3%，指数最好的也只降 47.5%

论断声称"跌破年线空仓能把最大回撤比买入持有降低 >50%"。协议复测（信号用昨日收盘、每次换仓扣 25bps、空仓不计息）后：**论断不成立**。年线过滤确实降回撤，但幅度远不到一半，且换来的是频繁换仓。

## 个股层面（2,012 只，主判据）

| 指标 | 数值 |
|------|------|
| 每股回撤降幅均值 | **3.34%**（判据要求 >50%）|
| 中位数 | 5.23% |
| 95% CI | [2.16%, 4.48%] |
| 样本外（后 20% 区间） | **−1.14%**（过滤后反而更差）|
| 分市场 | 19 个市场均值全部 <16%，三个市场（英国/香港/新西兰）为负 |

**为什么这么差？** 个股崩盘（比如苹果 90 年代跌 90%+）往往在跌破年线前就已经开跌，而且熊市里反复上穿下穿年线，每次都被咬一口：换仓 200+ 次的股票一抓一大把。空仓躲掉的跌幅，一大半被"跌一半才出场 + 反弹回来又进场接着跌"吃掉了。

## 指数层面（30 条指数，参照口径——论断实战语境是指数择时）

| 表现最好的 | 降幅 | | 表现差的 | 降幅 |
|------|------|---|------|------|
| 科创板50 | 47.5% | | 富时100 | **−39.3%**（更差）|
| 德国 DAX | 46.0% | | KOSPI | −4.3% |
| S&P 500 全收益 | 45.0% | | 创业板指 | −2.6% |
| 沪深300 | 44.2% | | 上证综指 | 21.9% |
| 法国 CAC | 44.5% | | 道琼斯 | −1.0% |

- **30 条指数没有一条达到 50%**；而且这是挑出来的"好成绩"——富时100 用了过滤反而回撤大增 39%。
- 过滤后的指数最大回撤本身仍然吓人：S&P 500 过滤后 MDD 还有 **54.7%**（论断给人的想象是"躲过大跌"，实际只是从 86% 降到 55%）。
- 样本外更不稳：上证综指 OOS 降幅 −21.4%、沪深300 OOS −91.8%（过滤在最近时段基本失效）。

## 旧结论为什么记成 ✅7/7？

旧台账写"✅ 已测（7/7支持）"，但旧口径 README 自己写的是 🟡"约 43%，未达 50%"——两处自相矛盾。本次协议复测取更严格的口径（全程 NAV MDD + 成本 + 股票级 bootstrap）：**❌ 定谳**。旧测试还有两个宽松处：不计换仓成本、用"每月采样窗口回撤"摊薄了单次崩盘的深度。

## 这对你的操作意味着什么

- "跌破年线就清仓躲熊市"这个口诀**降回撤有效但远没有传说中那么灵**：指数级别大约省 20-45% 的回撤，代价是每年多次换仓 + 可能完全失效的时段（A股 OOS）。
- 它**不能**让你"躲过大跌"：过滤后回撤仍有 30-55%。
- 作为仓位管理的辅助规则可用，作为"降低一半风险"的承诺不可信。
