## 3) 我们怎么测的（0 代码，纯白话）

以下按**当前仓库脚本 verify-042** 与 **results.json** 反推核对（两者字段不一致，见 ⚠️）：

- **数据**：US 市场个股 + SP500 指数；"市值代理"= **股价最高的 30 只**股票（README 自己承认 2009 年后高股价科技股会让模拟超额虚高）。

- **对照**：同一起点后 3 年的 SP500 指数收益；组合收益 − 指数收益 = 超额。
- **统计**：统计全部滚动 3 年窗口里"超额 < −20%"的占比，**≥50% 判"支持"**。
- **⚠️ 对不上账**：当前脚本输出的字段是 `n_windows_total / p_below_20pct / all_results`（按起点）；results.json 里却是 `period_stats`（按年份 2014~2026）和结论文案，**不是同一版脚本的产物**；而 README 的数字（20 窗口、0%）与两者又都对不上——**三份材料互相矛盾**。
