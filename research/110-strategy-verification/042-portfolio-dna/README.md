# 论断 #42 — 组合DNA不变但市场在变，3年后落后基准>20%

> **一句话：** 固定持有 top 市值股票 3 年不调仓，并没有想象的那么糟糕。

## 论断

"投资者的组合风格（DNA）往往不变，但市场风格每年都在变。如果一个组合 3 年不调整核心持仓结构，大概率落后基准超过 20%。"

## 回测方法

1. 取 SP500 中市值最大的 30 只股票（按股价排序），每 3 年再平衡一次
2. 对比 SP500 指数，计算滚动 3 年的超额收益
3. 测试 2005-2021 期间的 20 个滚动窗口

**注意：** 使用"股价最高"作为市值代理指标，极端行情下可能选出有偏的样本（如 2009 年后的高股价科技股导致模拟超额收益虚高）。

## 结果

| 指标 | 值 |
|:-----|:---|
| 分析窗口数 | 20 (2005-2021) |
| 跑赢基准 | 50% |
| 落后 >10% | 0% |
| 落后 >20% | 0% |
| 中位超额收益 | +0.14% |

结论：❌ **拒绝** — 固定 DNA 组合在 3 年内落后 >20% 的概率几乎为零（0%）。

**解释：** 持有 SP500 中最大市值的股票 3 年，实际上表现接近或小幅落后指数。由于大市值股票的交叠（重仓的成分股本身也占指数权重），固定组合与指数的差异有限，很难产生超过 20% 的分化。
