# 论断 #31 — 安全边际 > 30% 时买入，胜率 > 80%

> **一句话：** 当股票价格比"应该值"便宜30%以上时买入，胜率虽未达80%，但收益几乎是普通买入的2倍——安全边际策略不能保证不亏，但能让你赚更多。

---

## 这个论断在说什么

格雷厄姆式价值投资：只在价格远低于内在价值时买入。

### 安全边际的计算

1. **内在价值** = 历史中位数PE × 当前EPS
2. **安全边际** = (内在价值 - 股价) / 内在价值

例如：某股中位数PE=20，EPS=1元，内在价值=20元
- 股价=13元 → 安全边际=35% > 30% → 买入信号

---

| 维度 | 说明 |
|:-----|:------|
| **数据** | CSMAR（PE_TTM + EPS），日线价格 |
| **股票池** | 286只CN股票 |
| **持有期** | 1年 / 2年 / 3年 |

## 结果

**论断被拒绝 ❌** — 胜率最高仅61.4%（3年），远未达80%。但平均收益显著高于无安全边际组。

| 指标 | 安全边际>30% | 无安全边际 | 差距 |
|:-----|:-----------|:----------|:----|
| **1年平均收益** | **+20.93%** | +11.96% | **+8.97pp** |
| **2年平均收益** | **+37.91%** | +21.66% | **+16.25pp** |
| **3年平均收益** | **+57.71%** | +31.62% | **+26.09pp** |
| 1年胜率 | 55.6% | 50.3% | |
| 2年胜率 | 57.8% | 51.5% | |
| 3年胜率 | 61.4% | 53.5% | |
| 信号频率 | 10.7% | - | |

### 关键发现

1. **胜率远未达80%**：安全边际>30%组的最高胜率是3年期的61.4%。与80%差距很大。主要原因是：价格便宜≠马上涨——股票可能长期低估（价值陷阱）。

2. **但平均收益非常显著**：1年持有，安全边际组比无安全边际组多赚9个百分点；3年多赚26个百分点。说明安全边际策略虽然不能保证赚钱概率，但能大幅提高赚钱幅度。

3. **持有时间越长效果越好**：从1年到3年，超额从9pp扩大到26pp，说明安全边际对长期投资的增益更明显。

4. **信号频率约10.6-10.7%**：大概每10次季度检查中有1次出现安全边际>30%的买入机会，不算罕见。

### 实际意义

- 安全边际策略的真正价值不是"不亏钱"，而是"赚更多"
- 配合其他过滤器（如ROE>15%排除价值陷阱）可以进一步提升
- 建议降低胜率预期至55-60%，但关注平均收益的提升
