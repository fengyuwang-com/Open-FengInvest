# 论断 #35 — 等权组合跑赢市值加权

> 来源：research/000-52-claims.md

## 论断

S&P 500 等权重组合（每月再平衡）的长期收益和风险调整收益优于市值加权组合。

## 零假设 H₀

等权组合与市值加权组合的年化收益无显著差异，或等权组合收益更低。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US 503 只股票，2010-01 至 2025-12 |
| 信号生成 | 每月初按所有股票等权分配 |
| 持有期 | 1个月，每月再平衡 |
| 对比基准 | 按月初价格加权的市值加权组合 |
| 统计指标 | 年化收益、最大回撤、夏普比率、月胜率 |

## 关键指标

| 指标 | 等权组合 | 市值加权 |
|:-----|:-------|:-------|
| 年化收益 | 12.2% | 11.2% |
| 最大回撤 | 37.2% | 32.6% |
| 夏普比率 | 1.49 | 1.35 |
| 月胜率 | — | — |

## 结论

✅ **支持** — 等权组合年化 12.2% 跑赢市值加权 11.2%，超额 +1.0%/年。夏普比率也更高（1.49 vs 1.35）。代价是回撤更大（37.2% vs 32.6%），因为等权组合暴露更多小盘股风险。
