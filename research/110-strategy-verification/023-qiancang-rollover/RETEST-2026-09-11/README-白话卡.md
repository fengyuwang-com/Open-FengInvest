# 论断 #23 白话卡：浮盈 30% 就把本金收回来（钱仓滚存），震荡市里真的更划算吗？

> 复测日期：2026-09-11 ｜ 引擎：`qiancang-rollover`（fengverify.py 23）｜ 结论：**✅ 支持（震荡域成立，但这是结构性近必然；代价是牛市段大幅跑输）**

## 一句话说人话

**成立，但要听全**：凡是"涨了 30% 又跌回来"的震荡行情，先收回本金的账户终值比死扛的**平均多 21.5%**（10,584 个两年窗口，10,000+ 只股票，100% 的股票为正，样本外 +19.6%，回撤还平均少 36%）。但同一批触发过滚存的窗口**无条件看平均差 −38%**——大涨不停的车上，你提前下车收本金，就吃不到后面的肉。**滚存是震荡市的赢家、单边牛市的输家，方向论断在论断声称的域内成立。**

## 规则怎么跑的（普通人版）

- 买入一只股票，价格涨到入场价 130% 的那天，卖出刚好收回本金的份额（剩下的都是利润仓，继续拿着），卖出收 0.25% 成本，现金不计利息（保守）。对照组：一直拿到底。
- 每 504 个交易日（两年）算一个窗口，比较期末两边的钱。
- "震荡市"按论断口径 = 窗口结束时股价相对入场在 ±20% 以内（包括从未涨到 30% 的窗口——那些两边一样，计 0，保守）。

## 数字

| 指标 | 结果 |
|---|---|
| 震荡域终值差均值 | **+21.46%**（股票级 bootstrap CI 21.0 ~ 21.5，下限远高于 0） |
| 股票正差占比 | **100%**（9,300+ 只无一例外——这是数学结构：平盘收尾时高点止盈不可能吃亏） |
| 样本外（各股后 20% 窗口） | **+19.63%** |
| 触发窗口回撤降幅 | **平均 36.3%**（本金已收回，后续下跌伤不到本金） |
| **代价**：触发窗口无条件平均差 | **−38.07%**（60,290 个窗口——单边上涨里提前收本金 = 少赚） |
| 分市场震荡域 | 最高 HK +32.7%、CN +23.5%、KR +22.7%；最低也在 +18% 以上 |

## 判定

- 判定 **✅**：论断只说"震荡市终值更优"（定性方向），震荡域内均值 >0 且 CI 下限 >0，成立（铁律一）。
- 旧台账"✅ 有条件"与复测一致——这次给了条件的量化画像：**条件域内 +21%，域外代价 −38%**。
- ⚠️ 必须披露：震荡域用窗口末结果事后判定（"震荡市"无法事前定义）；且震荡域内滚存占优接近数学必然，**本卡的真正信息不是"滚存必胜"，而是"滚存的盈亏完全取决于后市形态"**。

## 给普通人的启示（D4 策略卡素材）

1. **滚存 = 免费保险 + 昂贵彩票**：震荡和下跌里它保本金（MDD 少 36%），单边牛市里它少赚近四成。
2. 适合**拿不住利润、账户经不起回撤**的人：把"浮盈 30% 收回本金"当作强制纪律，睡得着觉。
3. 不适合**想吃到完整趋势**的人——那应该用 #22 的年线减仓（30/100 滑动仓位）而不是一次性抽本金。
4. 与 #22 合并的仓位哲学：**风险控制动作都有牛市代价，选哪条取决于你更怕回撤还是更怕踏空**。
