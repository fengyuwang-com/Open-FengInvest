# 论断 #4 — SP500 年线上/下比例 = 2.8

> 来源：research/000-52-claims.md

## 一句话

标普 500 指数历史上约 68% 的交易日收盘价在 200 日均线上方（远低于 74%），上方/下方比例约 2.12，低于论断声称的 2.8。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | ^GSPC（S&P 500），1927-12-30 至 2026-07-20，共 98 年日线数据 |
| 统计方法 | 从第 200 个交易日开始，逐日计算收盘价在 200MA 上/下方 |
| 起始时间 | 1928-10-09（第一个有效 200MA） |
| 统计指标 | 上方天数、下方天数、比例 |

## 关键指标

| 指标 | 值 |
|:-----|:---|
| 分析总交易日 | 24,554 天（约 98 年） |
| 年线上方天数 | 16,682 天 |
| 年线下方天数 | 7,872 天 |
| 上方占比 | 67.9% |
| 上下方比例 | 2.12:1 |

## 结论

❌ **拒绝** — 实际比例约为 2.12，低于论断声称的 2.8。标普 500 历史上约 2/3 时间在年线上方，但未达到 3/4 的比例。
