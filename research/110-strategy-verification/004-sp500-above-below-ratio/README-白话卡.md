## 1) 红绿灯结论

> **❌ 原论断不成立（修正后的 fact 可采信）**

一句话理由：**论断声称上/下天数比 = 2.8x，实测只有 2.12x（68% vs 32%，24,554 个交易日、数据库独立重算一致）——"2.8x"这个数字本身是错的**；代码算得很对、也按照 ±0.5 容差正确地**拒绝**了 2.8x，错的是论断源头数字和旧 README 的"✅ 支持"误标。

## 2) 论断原文

> 标普 500 年线上方持续期是下方的 2.8 倍（牛市远长于熊市）。
> —— 000-52-claims.md #4；H₀：上/下持续期对称。

白话版：说美股约 3/4 时间待在年线上方（2.8 倍）；事实是约 **2/3** 时间（**2.12 倍**）。

## 3) 我们怎么测的（0 代码，纯白话）

- **数据**：一个指数 ^GSPC（S&P 500）1927-12-30 ~ 2026-07-20 全部历史日收盘价，共 24,554 个"有 200MA 的有效交易日"（刨掉了前 199 个不足 200 日均线的日子）。
- **分组**：从第 200 个交易日开始，逐日比较"收盘价 > 200 天均线"→ 记**上方**；否则记**下方**。
- **统计**：数上方/下方天数，比例 = 上方天数 ÷ 下方天数；顺带按年份、按年代各算一遍（results.json 未保存分年明细，全量数字见脚本可重跑）。
- **成交 / 成本**：不需要。这是**天数占比**的纯统计，不涉及买卖，没有成本问题。
- **对照**：无对照组。这类"事实陈述"型统计不需要对照组。

（方法表与脚本逐一核实：脚本计算与 audit 独立重算完全一致，详见 audit.md。）

## 4) 关键数字（直接来自 results.json）

| 指标 | 数值 |
|:------|:----:|
| 分析总交易日 | 24,554 天（约 98 年） |
| 年线上方天数 | 16,682（**67.94%**） |
| 年线下方天数 | 7,872（**32.06%**） |
| 上/下天数比例 | **2.1192** |
| 论断声称比例 | 2.8 |
| 代码判定 `claim_supported` | **false**（\|2.1192 − 2.8\| = 0.68 > 0.5 容差） |

> ⚠️ **判据说明（audit 核实）**：代码**没有判据错位**（比的就是"天数比例"），计算层面**没有错误**（audit 对数据库独立重算一遍：16682 / 7872 / 2.1192 逐项一致）。真正的问题是**论断源头数字 "2.8" 本身错误** + 旧 README（顶层 000-README.md #4 行）曾误标"✅ 支持"、还一边写"≈2.8x"一边自用 2.12x，自相矛盾并无视代码的 false 判定。**修正后的事实**是"约 2.12x（约 68% 时间站上年线）"，与 Brock et al. (1992) 对指数趋势持久性的方向描述一致，但精确比值须以本库复权数据重算为准。
> 注：本统计用未复权收盘价，但"天数占比"只是价格相对 200MA 的位置统计，除权/拆股不影响计数，口径上无碍。
