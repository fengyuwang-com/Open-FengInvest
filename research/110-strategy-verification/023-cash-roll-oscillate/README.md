# 论断 #23 — 钱仓滚存震荡市优于持有

> 来源：research/000-52-claims.md

## 一句话

在震荡市中（6 个月涨跌幅 -5%~+5%），每月买入动量最强的 20% 股票并持有 1 个月，月均收益 +2.00%，跑赢 SPY 持有（+1.48%），跑赢概率 64.3%。震荡市里轮动策略确实优于死抱。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US 股票池（480 只 S&P 500 成分股），1993 年至 2026 年 |
| 震荡市定义 | SPY 过去 6 个月累计收益在 -5% ~ +5% 之间（112 个月） |
| 钱仓滚存策略 | 每月末：计算所有股票过去 1 个月的收益，排序选前 20%，等权重买入，持有 1 个月 |
| 基准对比 | 同期 SPY 买入持有 |
| 持仓数量 | 前 20% 的股票，等权重 |
| 换仓频率 | 每月一次 |

## 关键指标

| 指标 | 钱仓滚存 | SPY 持有 |
|:-----|:---------|:---------|
| 月均收益 | **+2.00%** | +1.48% |
| 年化收益 | **+26.84%** | +19.31% |
| 月波动率 | 4.81% | 4.30% |
| 最大回撤 | 31.56% | 26.94% |
| 跑赢月数 / 总月数 | **72 / 112** | 40 / 112 |
| 跑赢概率 | **64.3%** | 35.7% |

## 结论

✅ **支持** — 在震荡市中，钱仓滚存策略月均跑赢 SPY 0.52 个百分点，64.3% 的月份表现更好。代价是波动率和最大回撤略高。
