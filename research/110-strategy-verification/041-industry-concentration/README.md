# 论断 #41 — 行业集中度>40%时 -30% 回撤概率>50%

> **一句话：** 过于集中在某个行业会增加下行风险，但远没有"50%概率暴跌"那么夸张。

## 论断

"当组合行业集中度超过 40% 时，发生 -30% 回撤的概率超过 50%。"
这意味着如果你把超过 40% 的资金押在同一个行业，有超过一半的概率会面临暴跌。

## 回测方法

1. 以 SP500 中 482 只股票按 11 个行业分类
2. 对 2010-01 至 2024-12 的每个起始月份：
   - 生成 200 个随机组合（2-8 个行业，随机权重）
   - 跟踪 6/12/24 个月内的最大回撤
   - 记录行业集中度（最大行业权重）
3. 按集中度分桶统计暴跌（回撤 >30%）概率

## 数据

- 数据源: `data/market_data.db` (US 市场 482 只股票日线)
- 行业信息: fundamentals 表的 sector 字段
- 时间范围: 2010-2024

## 结果

| 集中度 | 12个月暴跌概率 | 平均最大回撤 |
|:-------|:--------------|:------------|
| <20%   | 0.4%          | 8.5%        |
| 20-30% | 1.3%          | 8.8%        |
| 30-40% | 1.6%          | 9.0%        |
| 40-50% | 1.3%          | 9.1%        |
| 50-60% | 1.5%          | 9.3%        |
| 60-70% | 1.8%          | 9.6%        |
| 70-80% | 1.5%          | 10.0%       |
| >80%   | 2.2%          | 10.3%       |

结论：❌ **拒绝** — 集中度>40% 时暴跌概率仅 1.5%，远低于 50% 阈值
