# 论断 #29 — PE高于历史80%分位时减仓，能减少回撤？

> **一句话：** 如果一只股票的PE（市盈率）已经贵到了过去十年里最贵的20%区间，这时候把仓位降一半...并**不能**减少回撤。因为高PE区间并非总对应亏损——实际上高PE区间的后续收益和正常PE区间差别不大。

---

## 这个论断在说什么

这个论断基于"估值均值回归"理念：当一只股票的估值（PE）极端偏高时，未来大概率会回调。所以：

1. **信号触发：** 每个季度末检查持仓股票的PE_TTM，计算它在历史数据中的百分位。
2. **行动：** 如果PE高于历史80%分位（即比过去80%的时间都贵），把仓位降到50%。
3. **预期效果：** 减少估值回归带来的回撤。

### PE百分位的计算

PE百分位 = 当前PE在历史序列中的排位。比如：
- PE在80%分位 = 当前PE比过去80%的时间都高

---

## 怎么测的

| 维度 | 说明 |
|:-----|:------|
| **数据** | CSMAR A股（PE_TTM），日线价格 |
| **股票池** | 286只CN股票 |
| **信号触发** | 每季度末检查PE历史百分位 |
| **策略操作** | PE > 80%分位 → 仓位降至50%；否则满仓 |
| **持有期** | 3个月 / 6个月 / 12个月 |

---

## 结果

**论断被拒绝 ❌** — PE高于80%分位时减仓并未减少回撤，因为高PE时期的后续收益竟然也是正的。

| 指标 | 高PE区间(持有) | 高PE区间(减仓50%) | 正常PE区间 |
|:-----|:--------------|:-----------------|:----------|
| **3个月平均收益** | 4.17% | 2.08% | 4.28% |
| **6个月平均收益** | 7.59% | 3.80% | 8.63% |
| **12个月平均收益** | 17.59% | 8.80% | 19.61% |
| 高PE信号占比 | 17.8% | - | - |

### 为什么？

1. **高PE≠要跌：** A股高PE股票（一般对应成长股）反而有不错的后续收益。PE高可以是因为盈利暂时低（周期底部），而不是估值泡沫。
2. **减仓只减收益不减风险：** 减仓至50%只是把预期收益砍半，但"是否亏损"的概率分布没变——所以胜率不变。
3. **PE百分位的问题：** CSMAR 35年数据太长，扩展窗口的80%分位包括了早期极度低估时期的PE，导致现在看起来PE总是"偏高"，但这个偏高不一定代表要回调。

### 可能的改进方向

- 改用固定窗宽（如过去5年）而不是全部历史
- 结合其他估值指标（PB、PS）一起看
- 只在PE>95%分位（比#30）时才操作
