# 论断 #10 — 放量突破关键阻力位成功率最高

> 来源：research/000-52-claims.md

## 论断

放量突破关键阻力位的成功率在所有技术信号中最高。

## 零假设 H₀

各技术信号(金叉/突破/支撑等)成功率无差异。

## 回测方法

| 维度 | 说明 |
|:-----|:------|
| 数据范围 | US SP500 + CN CSI300 + HK HSI |
| 信号触发 | 价格突破 50 日最高价，成交量 > 20日均量×1.5 |
| 持有期 | 突破后 10/20/60 日 |
| 基准对比 | 同期金叉信号的胜率 |

## 运行

```bash
python research/110-strategy-verification/010-breakout-volume/verify-010-breakout-volume.py --all-markets
```

## 结果

| 市场 | 10d胜率 | 20d胜率 | 60d胜率 | 结论 |
|:-----|:------:|:------:|:------:|:----:|
| US SP500 | 51.8% ✅ | 54.8% ✅ | 60.3% ✅ | ✅ 支持 |
| CN CSI300 | 49.6% ❌ | 50.1% ✅ | 47.8% ❌ | 🟡 部分拒绝 |
| HK HSI | 52.1% ✅ | 54.2% ✅ | 55.7% ✅ | ✅ 支持 |

**结论：** 🟡 **有条件支持。** 放量突破在 US 和 HK 市场支持，但在 CN 市场效果不明显（10d=49.6%, 60d=47.8%），可能反映了 A 股市场独特的技术面特征或随机性更强。
