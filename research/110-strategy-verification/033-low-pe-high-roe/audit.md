## 1. 数据口径核查（铁律三）

| 项目 | 情况 | 影响 |
|:-----|:-----|:-----|
| **复权** | `verify-033-*.py:88-89` 购买和卖价都用 `daily_data.close`（`load_prices`），**未复权**；季度收益 `(fp-cp)/cp` 直接用原始收盘价。 | **高 —— CN 高送转/除权会让季度收益掺入假涨跌，直接扭曲超额收益。** |
| **财务公告时滞 / 前视偏差** | `verify-033-*.py:160` 选 `accper <= qdate` 的最新财务**忽略 `declare_date`（公告日）**。即用 3/31 财报就在 3/31 当期选股，但 A 股年报实际 4 月底才公告。**典型前视偏差**：在财务数据尚不可得时就使用了它。 | **高 —— 系统性虚增超额。这是本回测最严重问题。** |
| **买入时点前视** | `verify-033-*.py:174` `cp = get_price_at(prices, qdate)` 用季度末当天收盘价作买入价，与财务数据同点。 | 中 —— 与上一条叠加，是"未来信息"在当期被用。 |
| **盈利过滤偏差** | `verify-033-*.py:168-171` 过滤 `pe<=0 和 roe<=0`（剔除亏损股），选择标准与基准过滤不同步。 | 中 —— 策略只碰盈利股，基准却含过滤后仍可选的池，底数不对称。 |
| **基准口径** | `verify-033-*.py:219` 基准 = `candidates`（当季通过过滤的所有股票）等权，README 却写"等权全部 CN A股"。 | 中 —— README 对基准的描述与实际算法不符（实际是"池内过滤后"等权）。 |
| **生存偏差** | 股票池 `cn_stocks` 从 `stkcd_map` 取 `matched=1` 且日线>1000 天的（`verify-033-*.py:27-36`），未明确声明是否含已退市股。 | 中 —— 若剔除退市股会高估。 |
| **交易成本** | 全程未计。 | 中 —— 季度再平衡、持仓仅 8 只换手高，未计佣金/印花税。 |

## 2. 显著性（铁律二）

- **无任何显著性检验**：无 t 检验 / Bootstrap / 置信区间。"超额+3.21%/年"是**单一时间序列点估计**，未检验是否会因样本/参数而反转。
- 持仓集中到**平均 8 只**（README 数据），交集样本极窄 → 过拟合与运气成分高，缺显著性检验使该"超额"可信度更低。

## 3. 权威文献对照（铁律四）

- 文献（经 Crossref 核实）：
  - Fama & French (1993) *Common Risk Factors in the Returns on Stocks and Bonds*, JFE 33(1), 3–56. DOI 10.1016/0304-405x(93)90023-5 —— 价值因子 HML 方法。
  - Novy-Marx (2013) *The Other Side of Value: The Gross Profitability Premium*, JFE 108(1), 1–28. DOI 10.1016/j.jfineco.2013.01.003 —— 质量/盈利因子。
  - Frazzini, Kabiller & Pedersen (2018) *Buffett's Alpha*, NBER WP #19681, DOI 10.3386/w19681 —— "价值+质量+低波"组合解释。
- **标准做法**：因子组合应做**多空排序投资组合 + 时间序列回归/t 统计量 + 因子协整检验**，样本要宽（含小市值/退市）、用复权价、控制财务公告时滞、计成本。
- **与本实现的差异**：本实现无显著性检验、未复权、未处理公告时滞（前视）、池过窄。**达不到因子论文的方法水准。**

## 4. 复核后建议结论

**🟡 原「✅ 超额+3.21%/年」降级**，在下列修正后需重跑才能定论：

1. **修前视偏差（最关键）**：用 `declare_date` 限制财务数据可用时点，不能用 `qdate` 当天的财报+收盘价。
2. **复权价**：季度收益改用前复权/后复权价格。
3. **交易成本 + 生存偏差**：声明并计入换手成本，确认池含退市股。
4. **显著性**：对超额做 Bootstrap 或 t 检验，报 p 值/置信区间。
5. 对齐 README 与实际算法参数（股票池、基准口径）。

修正重跑后，若超额仍显著为正，才可回 ✅；否则维持 🟡 或 ❌。
