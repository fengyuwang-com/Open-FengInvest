# 论断 #33 — 低PE + 高ROE组合长期跑赢市场

> **一句话：** 每季度选"又便宜又好"的股票（低PE∩高ROE），等权买入并季度再平衡——21年回测年化15.94%，跑赢市场3.21个百分点。**这个策略真的有效。**

---

## 这个论断在说什么

经典的价值+质量双因子组合：

1. **低PE（价值）：** PE最低的20%
2. **高ROE（质量）：** ROE最高的20%
3. **交集：** 同时满足两者

### 为什么有效

- 低PE提供"安全垫"，高ROE提供"增长引擎"
- 季度再平衡确保始终持有最优标的

---

## 怎么测的

| 维度 | 说明 |
|:-----|:------|
| **数据** | CSMAR（PE_TTM + ROE_A），日线价格 |
| **股票池** | 286只CN A股 |
| **筛选** | PE_TTM最低20% ∩ ROE_A最高20% |
| **权重** | 等权重，季度再平衡 |
| **基准** | 等权全部CN A股 |
| **回测期间** | 2005年3月 ~ 2026年6月（21.2年） |

---

## 结果

**论断被支持 ✅** — 策略累积收益2316%，超额年化3.21%，21年回测验证有效。

| 指标 | 策略(低PE+高ROE) | 基准(全市场等权) |
|:-----|:--------------|:--------------|
| **累积收益** | **2,316%** | 1,276% |
| **年化收益(CAGR)** | **15.94%** | 12.73% |
| **超额年化** | **+3.21%** | - |
| **最大回撤** | 69.08% | 63.26% |
| **夏普比** | **0.50** | 0.47 |
| **季度胜率** | 56.5% | 58.8% |
| 平均每期持仓 | 8只 | 286只 |

### 关键发现

1. **超额收益显著且稳定**：21年跑出3.21%年化超额，这不是运气。

2. **回撤略高但夏普更好**：策略最大回撤69.08% vs 基准63.26%，但夏普比0.50 > 0.47，说明单位风险回报更好。

3. **持仓非常集中**：平均每期只持有8只股票（从286只中筛选），筛选条件非常严格。

4. **交集vs并集**：如果只用低PE单因子（取前20%就有57只），超额收益可能更小但更稳定。这里用交集虽然持仓少，但选出的都是"又便宜又好"的真正核心。

### 实际意义

- 适合作为A股组合管理的核心策略
- 建议扩展到更多股票（全A股而非仅沪深300成分）以增加选股池
- 与其他因子（动量、低波）组合可能进一步提升
