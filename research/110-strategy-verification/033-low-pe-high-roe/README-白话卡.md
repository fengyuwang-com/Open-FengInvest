## 1) 红绿灯结论

> **🟡 有条件·存疑（原"✅ 超额 +3.21%/年"不可直接采信）**

一句话理由：**判据对（比年化收益）、结果本身也亮眼（策略 15.94% vs 基准 12.73%）**，但复核抓出一串硬伤——**财务数据在公告日之前就被拿来选股（前视偏差）**、用**未复权**价算季度收益、**完全没有显著性检验**、基准口径与 README 对不上，且平均只持 8 只、最窄 3 只——修正这些之前，"+3.21%/年"不能当真。

## 2) 论断原文

> **（注册号漂移提示）** 000-52-claims.md 里 #33 登记为"持续大规模回购的公司，股价长期表现优于不回购的公司"（H₀：回购与长期表现无关）；但**本目录实际测的是"低PE + 高ROE 组合长期跑赢市场"**，README / audit / 结论总览（000-CONCLUSIONS.md #33）全都按后者。本卡按目录实测口径写，注册表编号口径请你方核对修正。

白话版：每季度挑"又便宜（PE_TTM 最低 20%）又优质（ROE_A 最高 20%）"的 A 股，等权买入、季度再平衡，21 年跑下来年化 15.94%，比全市场等权（12.73%）每年多赚 3.21 个百分点。

## 3) 我们怎么测的（0 代码，纯白话）

- **数据**：本地库 CN A 股，财务表（PE_TTM、ROE_A）+ 日线收盘价；约 286 只、2005-03-31 ~ 2026-06-30 共 85 个季度。
- **选股**：每季度末，取 PE_TTM 最低 20% ∩ ROE_A 最高 20% 的**交集**（交集不足 3 只时退化为只用低 PE 组——这点 README 没写）。
- **持有 / 再平衡**：等权买入，持到下一季度末，季度再平衡。
- **基准**：代码里是"当季通过筛选、有价格的候选池**等权**"；README 写的是"等权全部 CN A 股"——**两处口径对不上**。
- **统计口径**：季度收益 = (下季收盘价 − 本季收盘价) ÷ 本季收盘价；复利成 21.2 年年化。
- **关键瑕疵（audit 逐条核实）**：选财务用 `accper <= 调仓日`、**不看公告日 declare_date**（3/31 就用上 4 月底才公告的年报 = 前视）；价格未复权；没扣任何交易成本；没有任何显著性检验。

> ⚠️ **audit 核实的关键警告**：
> - **前视偏差（最严重）**：A 股年报 4 月底才公告，这个回测却在 3/31 当季就用了财报——等于"提前知道未来财报再买"，**系统性虚增超额**。
> - **未复权**：CN 高送转/除权会让季度收益掺入假涨跌，**直接扭曲超额**。
> - **无显著性检验**："+3.21%/年"只是单条时间序列的一个点估计，没给 p 值/置信区间；平均只持 8.1 只、最少 3 只，**过拟合与运气成分高**。
> - **基准口径矛盾**：README 写"全 CN A 股"，代码实为"池内过滤后等权"。
> - **README 数字是快照**："286 只 / 平均 8 只"是某次运行值，代码按 `HAVING COUNT(*)>1000` 动态选池，**复现性差**。

## 5) 是否可采信（协议红绿灯）

按方法论**铁律一~四** + 8.1 回测标准协议逐项核对：

| 检查项 | 状态 | 一句话说明（给非编程用户） |
|:-------|:---:|:---------------------------|
| 判据对齐：测的确实是论断说的那个量 | ✅ | 论断说"跑赢市场"，脚本比 CAGR/超额年化，判据一致（比 #1 规范） |
| 数据口径：复权 / 交易成本 / 退市股 | ⚠️ | 未复权、未计成本；盈利过滤（PE/ROE>0）与基准过滤不同步，底数不对称 |
| 前视偏差：财务公告时滞 | ❌ | 用 3/31 财报在 3/31 选股、忽略公告日，A 股年报实际 4 月底才公告 |
| 显著性：差异够大 + 有统计检验 | ❌ | 无任何 t/Bootstrap/CI；持仓平均 8 只样本太窄，运气成分高 |
| 样本外验证（回测期后 20%） | ❌ | 无 |
| 幸存者审计（含已退市股票） | ⚠️ | 未明确声明股票池是否含退市股 |
| 方法对标权威文献（铁律四） | ⚠️ | 因子论文标准做法（多空排序组合 + 时间序列回归 t 值 + 复权 + 公告时滞 + 宽样本；对照 Fama-French 1993 / Novy-Marx 2013）未达到 |

> **要采信需先**：用公告日限制财报可用时点、换复权价、加交易成本并确认含退市股、对超额做 Bootstrap/t 检验；**修正后若超额仍显著为正才回 ✅，否则维持 🟡 或 ❌**。
