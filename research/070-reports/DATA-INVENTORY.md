## 九、CSMAR 中国A股财务数据（新增）

CSMAR 数据库（闲鱼 0.1元）通过 `tools/feng_import_csmar.py` 导入，覆盖所有A股（含已退市）的详细财务报表。

### 9.1 覆盖概览

| 度量 | 值 |
|:-----|:----|
| 股票数 | 5,828（含已退市） |
| 行数 | 356,728 |
| 列数 | 197 个财务字段 |
| 时间范围 | 1990-12-31 ~ 2025-03-31 |
| 数据频率 | 季度（支持 `--mode annual` 切换年度） |

### 9.2 数据结构

| 表名 | 内容 |
|:-----|:------|
| `cn_financials` | 宽表：stkcd + accper + 资产负债表(53) + 利润表(22) + 现金流量表(7) + 比率因子(75+) + 行业分类(4) |
| `stkcd_map` | CSMAR Stkcd → 数据库 index_id 映射 |

### 9.3 关键字段分类

| 类别 | 字段数 | 示例 |
|:-----|:------:|:-----|
| 资产负债表 | 53 | total_assets, total_liabilities, total_equity, cash, accounts_receivable, inventory_net |
| 利润表 | 22 | total_revenue, net_profit, parent_net_profit, basic_eps_report |
| 现金流量表 | 7 | operating_cf_net, investing_cf_net, financing_cf_net |
| 盈利能力 | 18 | ROE_A/B, ROA_A/B, gross_margin, net_margin, EBIT, EBITDA, ROIC |
| 估值 | 12 | PE_TTM, PB, PS_TTM, market_cap_A/B, tobin_q_A-D, EV/EBITDA |
| 偿债能力 | 8 | current_ratio, quick_ratio, debt_to_asset_ratio, equity_multiplier |
| 增长 | 11 | revenue_growth, net_profit_growth, eps_growth, total_asset_growth |
| 每股数据 | 16 | eps_1, bvps_1, ocf_per_share_1, fcf_per_share_1 |
| 行业分类 | 4 | industry_csrc (证监会), industry_amac (行业协会) |

### 9.4 数据质量

- **基于最新年报摘要更新 fundamentals 表**：299/300 CN 股票已有最新基本面数据
- CN fundamentals 覆盖率从 75% → **100%**，数据源自正规审计年报而非 yfinance 抓取
- 含 5,530 只非持仓股票（已退市/未跟踪）的历史财务数据，支撑全市场回测

### 9.5 使用方式

```bash
python tools/feng_import_csmar.py              # 导入季度数据
python tools/feng_import_csmar.py --mode annual # 导入年度数据
python tools/feng_import_csmar.py --update-fund  # 更新 fundamentals 表
python tools/feng_import_csmar.py --status       # 查看进度
```

> 注意：导入脚本会创建 cn_financials 和 stkcd_map 表，--update-fund 用最新一期合并报表数据刷新 fundamentals。

1. **格雷厄姆 Net-Net 扫描** — 市值 < (流动资产 - 总负债)，无需 CAPEX
2. **巴菲特式 ROE 筛选** — ROE>15% + D/E<0.5 + OCF>NP
3. **深度价值筛选** — PE<20%分位 + PB<1 + 股息率>3%
4. **行业对标** — 证监会+行业协会双分类，PE/PB/ROE/毛利率对比
5. **PE 历史分位** — 35 年数据
6. **DCF 估值 ✅ 已就绪** — 自由现金流折现（CAPEX 已补）
