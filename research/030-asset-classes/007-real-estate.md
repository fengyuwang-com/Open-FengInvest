# 房地产（Real Estate）

## 一、资产特性

| 维度 | 说明 |
|:----|:----|
| **收益来源** | 租金收入 + 资产增值 |
| **长期年化回报** | REITs ~8-12%、实物房产 ~5-8%（随市场差异大） |
| **年化波动率** | REITs 15-22%、实物房产低流动性难以衡量 |
| **与其他资产相关性** | 与股票 0.5-0.7、与债券 0.0 至 -0.2、与通胀 0.3-0.5 |
| **流动性** | REITs 高（交易所交易）、实物房产极低（月-年才能卖出）|
| **杠杆率** | 行业普遍高（房地产为杠杆密集型行业）|

---

## 二、REITs（房地产信托投资基金）

### 基本结构

REITs 通过持有和经营产生收入的房地产，将大部分应税收入（90%+）作为股息分配给股东，从而避免公司层面的所得税。

| 维度 | REITs |
|:----|:------|
| 股息要求 | >90% 应税收入必须分红 |
| 税收 | REIT 层面免所得税、股东层面按股息纳税 |
| 资产要求 | >75% 资产必须是房地产、现金或国债 |
| 收入要求 | >75% 收入来自租金或按揭利息 |

### REITs 的分类

| 类型 | 子类 | 特征 | ETF 代表 | 利率敏感度 |
|:----|:----|:----|:--------|:---------|
| **权益型（Equity REITs）** | | 租金收入为主（~90% 收入） | VNQ | 中 |
| | 住宅 | 公寓、单户出租 | | 中 |
| | 商业办公 | CBD 写字楼、园区 | | 高 |
| | 零售 | 商场、购物中心、便利店 | | 中高 |
| | 工业/物流 | 仓库、数据中心 | | 中低 |
| | 医疗 | 医院、养老院 | | 低 |
| | 酒店/度假 | 酒店、度假村 | | 高 |
| | 数据中心 | IT 基础设施 | | 中低 |
| | 通信铁塔 | 通信基站租赁 | | 中低 |
| **按揭型（Mortgage REITs）** | | 房贷利息收入为主 | REM | 极高 |
| **混合型（Hybrid REITs）** | | 两者都有 | — | 高 |

### REITs 的关键指标

| 指标 | 含义 | 与普通股票 |
|:----|:----|:----------|
| **FFO（运营资金）** | 净利润 + 折旧摊销 - 资产出售收益 | 替代 P/E |
| **P/FFO** | 估值指标，类似 P/E | REIT 标准估值 |
| **AFFO（调整后FFO）** | FFO - 经常性资本支出 | 比 FFO 更接近"真实可分配现金" |
| **NAV（净资产价值）** | 房地产组合的市场价值 - 负债 | 折价/溢价交易的参照 |
| **同店增长（Same-Store NOI）** | 已有物业的同比净营收增长 | 衡量运营质量 |
| **股息率** | REIT FFO 派息率通常高 | 平均 3-6% |

## 三、实物房产

### 类别

| 类别 | 投资门槛 | 年化回报（历史、地区差异大） | 注意 |
|:----|:-------:|:-------------------------:|:----|
| **自住房** | 极高 | 4-6%（长期升值率，含自住的"隐性租金"）| 居住属性为主，投资为辅 |
| **出租住宅** | 高 | 6-10%（净租金+增值） | 管理成本、维护、空置率 |
| **商业地产** | 极高 | 7-12%（净租金+增值） | 经济周期敏感、租户风险 |
| **土地** | 高 | 波动大 | 无现金流，纯投机赌升值 |

### 实物房产 vs REITs

| 对比维度 | 实物房产 | REITs |
|:--------|:--------|:------|
| 投资门槛 | 极高（数十万起步） | 低（一股即可） |
| 流动性 | 极低（出售需数月） | 高（T+0） |
| 管理成本 | 高（维修、管理、租户）| 低（专业管理团队）|
| 杠杆 | 可以、普遍 | 公司层面自带 |
| 税务优势 | 折旧抵扣、1031 交换 | 分红正常纳税 |
| 集中度 | 极高（1-2 套房） | 低（已充分分散）|
| 透明度 | 低（成交价不透明） | 高（公开披露）|

## 四、房地产的驱动因子

| 因子 | 对 REITs 的影响 | 对实物房产的影响 |
|:----|:---------------|:---------------|
| **利率** | 利率 ↑ → 融资成本 ↑ → REITs 价格 ↓ | 按揭利率 ↑ → 购买力 ↓ → 价格压力 |
| **经济周期** | 扩张 → 出租率 ↑、租金 ↑ | 同向，但滞后 6-12 个月 |
| **就业** | 就业 ↑ → 住房需求 ↑、商业需求 ↑ | 驱动租金和价格的核心 |
| **人口** | 人口流入 → 需求↑ | 长期最根本驱动 |
| **通胀** | 租金随通胀↑ | 租金和房价随通胀上涨 |
| **信贷条件** | 商业贷款宽松 → 利好 | 按揭利率和 LTV 是关键 |

### 利率影响详解

房地产是典型的利率敏感型资产：

- 短期（0-6 个月）：利率上升 → REITs 价格下跌（与债券一样受折现率冲击）
- 中期（6-18 个月）：过渡期，市场消化
- 长期（>18 个月）：经济良好 → 租金和出租率上升 → 基本面改善抵消利率冲击

> 2022 年 REITs 因利率上升大幅下跌（VNQ -17%），但 2023 年受益于经济韧性和租金上涨部分恢复。

## 五、在组合中的作用

| 投资目标 | 建议配置 | 逻辑 |
|:--------|:-------:|:----|
| 收入和增长 | 10-20%（REITs）| 高股息 + 长期资本增值 |
| 通胀对冲 | 5-15% | 租金随通胀上涨 |
| 分散化 | 5-10%（REITs）| 与股债相关性中低 |
| 实物资产替换 | 自住房（因人而异）| 居住价值 + 潜在增值 |

### 现实注意点

- REITs 有"利率敏感和成长"的双重属性
- 在利率快速上升期（如 2022 年），REITs 也可能会大幅下跌
- 实物房产的"分散化效果"往往被高估（高度集中在本地市场 + 与当地经济高度相关）
- 2024-2026 年办公 REITs 因 WFH（远程工作）趋势面临结构性挑战
