# 黄金（Gold）

## 一、资产特性

| 维度 | 说明 |
|:----|:----|
| **类别** | 实物商品 / 货币替代品 |
| **收益来源** | 价格增值（无现金流、无票息、无股息） |
| **长期年化回报** | 约 5-7%（1971 年金本位废除以来） |
| **年化波动率** | 12-20% |
| **与其他资产相关性** | 与股票低（0.1-0.3）、与国债负相关（-0.2 至 -0.4）、与美元负相关 |
| **流动性** | 极高（全球日均交易量 ~$1500亿） |
| **存储成本** | 实物 0.5-1%/年（保险+保管），ETF ~0.4%/年 |
| **交易时间** | 24 小时（全球市场接力） |

## 二、定价核心驱动

### 1. 实际利率（最重要的定价因子）

黄金与实际利率呈**强负相关**——因为黄金不产生利息，当实际利率下降（或为负）时，持有黄金的机会成本降低。

| 实际利率环境 | 黄金表现 | 逻辑 |
|:-----------:|:--------:|:----|
| 负实际利率 | 极大利好 | 持有黄金的机会成本为零，甚至为负 |
| 低正实际利率（0-1%） | 温和利好 | 债券收益有限，黄金仍有吸引力 |
| 高正实际利率（>2%） | 利空 | 生息资产有吸引力，黄金承压 |
| 快速下降中 | 利好 | 预期变化比绝对值更重要 |

> 实际利率 = 名义利率（10Y 国债收益率）— 预期通胀（TIPS breakeven 或 CPI）

### 2. 美元指数

黄金以美元计价，与美元通常呈负相关（-0.3 至 -0.5）。

| 美元走势 | 黄金影响 | 例外 |
|:-------:|:--------|:----|
| 美元走强 | 黄金承压 | 危机时期可能同时走强 |
| 美元走弱 | 黄金受益 | — |
| 去美元化叙事 | 结构性利好 | 央行储备多元化 |

### 3. 避险需求

| 触发事件 | 黄金反应 | 特征 |
|:-------|:--------|:----|
| 地缘政治危机 | 短期脉冲上涨 | 通常持续 1-4 周，之后回落 |
| 金融危机（2008） | 初期下跌，之后大涨 | 流动性危机初期所有资产被抛售 |
| 高通胀 | 温和上涨 | 通胀对冲功能 |
| 信用危机（货币贬值） | 大涨 | 货币信用受质疑时最强 |

> 黄金在**流动性危机初期**通常与股票同跌（2008、2020 年 3 月），之后率先反弹。

### 4. 央行购金

| 年份 | 全球央行净购金（吨） | 主要买家 |
|:---:|:-----------------:|:---------|
| 2022 | 1,082 | 中国、土耳其、印度、乌兹别克斯坦 |
| 2023 | 1,037 | 中国、波兰、新加坡、利比亚 |
| 2024 | ~900 | 中国、波兰、印度、土耳其 |
| 2025 | ~800（截至Q2） | 中国连续 18 个月增持 |

中国央行为近年最大买家，推动黄金的结构性需求。

## 三、历史年化回报

| 时间段 | 年化回报（美元计） | 备注 |
|:-----:|:----------------:|:----|
| 1971-1980 | +32% | 布雷顿森林体系解体，滞胀 |
| 1981-2000 | -5% | 沃尔克加息，实际利率高位 |
| 2001-2011 | +20% | 新兴市场需求，量化宽松 |
| 2012-2015 | -8% | 实际利率回升，美元走强 |
| 2016-2020 | +11% | 负利率，贸易战，COVID |
| 2021-2025 | ~12% | 央行购金，去美元化，地缘冲突 |
| 1971-2025（全部） | ~8% | 高于通胀但低于股票 |

## 五、持有方式对比

| 方式 | 优点 | 缺点 | 费用 |
|:---|:----|:----|:---:|
| **实物（金条/金币）** | 无对手方风险、隐私性高 | 存储和保险不便、买卖价差大 | 存储 0.5-1%/年 |
| **黄金 ETF（GLD/IAU）** | 流动性好、方便交易、价差小 | 管理费、对手方风险 | 0.25-0.4%/年 |
| **黄金期货** | 杠杆、流动性极高 | 到期展期、保证金管理复杂 | 交易佣金+展期 |
| **金矿股（GDX/GDXJ）** | 有经营杠杆、股息可能 | 不纯粹跟随金价、运营风险 | 管理费 0.5%+ |
| **央行数字货币（数字黄金）** | 极小可买、极流动性 | 非常新、认可度有限 | 平台费 |

> 金矿股 ≠ 黄金。金矿股是股票，反映企业经营（成本、产量、管理），波动通常为金价的 1.5-2 倍。

## 六、在组合中的作用

| 投资目标 | 建议配置 | 逻辑 |
|:--------|:-------:|:----|
| 通胀对冲 | 5-10% | 事件驱动性对冲 |
| 尾部风险保护 | 2-5% | 危机时表现（流动性危机初期除外） |
| 分散化 | 3-7% | 低相关性提升风险调整回报 |
| 投机 | 视情况 | 跟随实际利率和美元趋势 |
