# 公司债（Corporate Bonds）

## 一、资产特性

| 维度 | 说明 |
|:----|:----|
| **收益来源** | 票息收入 + 信用利差变化 + 利率变化 |
| **长期年化回报** | 投资级 3-6%、高收益 5-9% |
| **年化波动率** | 投资级 4-8%、高收益 8-14% |
| **与其他资产相关性** | 与国债正相关（0.3-0.5）、与股票正相关（投资级 0.5-0.6，高收益 0.6-0.8）|
| **信用风险** | 投资级低至高收益高（违约率明显不同）|
| **流动性** | 投资级高（交易活跃），高收益中（市场狭窄）|

### 回报分解

```
公司债总回报 = 无风险利率变化 + 信用利差变化 + 票息收入 + 违约损失 - 流动性溢价

其中：
  - 无风险利率部分 → 与国债一致（久期因素驱动）
  - 信用利差部分 → 反映经济预期和风险偏好
  - 违约损失部分 → 长期平均 0.5-2% 年化
```

## 二、分类体系

### 按信用评级

| 分类 | 评级（标普/Moody's） | 特征 | 典型收益率溢价 | 年化违约率 |
|:----|:------------------:|:----|:------------:|:--------:|
| **AAA** | AAA / Aaa | 最高质量，近无风险 | 0.3-0.6% | <0.1% |
| **AA** | AA / Aa | 高质量 | 0.4-0.8% | 0.1-0.2% |
| **A** | A / A | 中高质量 | 0.6-1.2% | 0.2-0.4% |
| **BBB** | BBB / Baa | **投资级最低档** | 1.0-2.5% | 0.3-0.6% |
| **BB** | BB / Ba | **高收益/垃圾级** | 2.5-5.0% | 0.8-2.0% |
| **B** | B / B | 高度投机 | 4.0-7.0% | 2-5% |
| **CCC** | CCC / Caa | 极高风险 | 6-12%+ | 8-15%+ |
| **D** | D / D | 违约 | — | 100% |

> 机构投资者通常只能买投资级（BBB- 及以上）。CCCs 是"堕落天使"或高风险投机。

**关键评级概念：**
- **堕落天使（Fallen Angel）**：原投资级降至高收益（BBB- 至 BB+），价格通常大幅下跌
- **明日之星（Rising Star）**：高收益升至投资级，价格通常上涨

### 按其他维度

| 分类 | 子类 | 特征 |
|:----|:----|:----|
| **期限** | 短期（1-3Y）、中期（3-7Y）、长期（>7Y） | 久期影响利率敏感度 |
| **担保** | 有担保（Secured）、无担保（Senior Unsecured）、次级（Subordinated） | 违约后回收率不同 |
| **结构** | 固定利率、浮动利率（FRN）、可转债 | 利率环境偏好不同 |
| **区域** | 美国、欧洲、新兴市场（美元债/本币债） | 外汇 + 区域风险 |

## 三、信用利差分析

### 什么是信用利差

信用利差 = 公司债收益率 - 同期限国债收益率

它反映市场对其信用风险的定价。

| 环境 | 利差水平（投资级） | 利差水平（高收益） | 信号 |
|:----|:---------------:|:--------------:|:----|
| 经济强劲 | 0.8-1.2% | 2.5-3.5% | 风险偏好高 |
| 正常 | 1.0-1.5% | 3-4% | 健康环境 |
| 压力初期 | 1.5-2.5% | 4-6% | 警惕 |
| 危机 | 2.5-4%+ | 6-10%+ | 恐慌/机会 |

### 利差变动的驱动

| 驱动因素 | 对利差的影响 | 说明 |
|:--------|:----------|:----|
| 经济增长 | 扩张→利差收窄，衰退→利差扩大 | 最重要的宏观驱动 |
| 企业盈利 | 利润上升→利差收窄 | 盈利恶化是利差扩大的先行指标 |
| 流动性条件 | 宽松→利差收窄，紧缩→利差扩大 | 直接影响风险偏好 |
| 波动率 | VIX ↑→利差扩大 | 波动率压制风险资产 |
| 资金流动 | 流入→利差收窄，流出→利差扩大 | 技术面因素 |

## 四、违约周期

### 历史违约率（高收益）

| 时间 | 年均违约率 | 备注 |
|:---:|:---------:|:----|
| 1980-1990 | 3.5% | 储贷危机 |
| 1991-2000 | 2.8% | 科技泡沫 |
| 2001-2010 | 4.2% | 互联网泡沫+全球金融危机 |
| 2011-2020 | 2.0% | 超低利率环境 |
| 2021-2025 | 1.8% | 疫情后低违约（政府支持） |
| **长期平均** | **~2.5%** | — |

违约率与经济衰退高度相关。衰退期高收益违约率可达 5-10%。

### 回收率

| 债务优先级 | 平均回收率 |
|:---------|:--------:|
| 银行高级贷款 | 60-80% |
| 有担保高级债券 | 50-70% |
| 高级无担保债券 | 30-50% |
| 次级债券 | 10-30% |
| 可转债 | 10-25% |

## 六、信用市场作为领先信号

HYG/LQD 指数是宏观风险的领先指标：

- 信用利差急剧扩大 → 通常领先股市下跌 2 周-3 个月
- 高收益债价格率先下跌 → 中小企业财务压力先于大公司显现
- HYG/LQD 的 3 月 ROC < -3% → 信用事件预警信号

**2022 年例外：** 美联储加息导致的利差扩大不同于经济衰退驱动的利差扩大，对预测衰退的可靠性降低。

## 七、在组合中的作用

| 投资目标 | 建议配置 | 逻辑 |
|:--------|:-------:|:----|
| 收益增强 | 15-30%（投资级） | 比国债高 1-2% 收益率 |
| 组合稳定 | 10-20%（短期投资级） | 低波动，稳定票息 |
| 高收益 | 5-15%（高收益） | 高票息，风险和股票类似 |
| 保守型 | 0-10% | 纯国债已经足够 |
