# 卖出决策框架

> **核心原则：卖出比买入更难，认错比赚钱更反人性。**
> docs/08-exit.md 回答"跌多少/涨多少卖"，本文档回答"为什么卖"和"为什么现在卖"。

---

## 一、卖出的四种原因

卖出只有四种根本原因，其他都是这四类的变体。

| 原因 | 定义 | 难度 | 常见错误 |
|:----|:-----|:----:|:--------|
| **论文到期** | 投资逻辑已经完全兑现，价格已反映预期 | 中 | 过早卖出（涨了就拿不住） |
| **论文失效** | 买入的核心假设被推翻，逻辑不成立 | 高 | 拖而不决（等回本/再观察） |
| **机会成本** | 持仓虽然没问题，但有更好的去处 | 极高 | 频繁换仓，为"看起来更好"放弃"确实好" |
| **风险控制** | 组合层面需要调整风险暴露（非个股层面） | 高 | 把风控当借口卖出好仓位 |

**这四类的优先顺序：** 论文失效 > 风险控制 > 论文到期 > 机会成本。

- 论文失效必须立即处理，资产还在但逻辑已死。
- 风险控制涵盖的是系统性、流动性、集中度，不是个股基本面。
- 论文到期可以从容计划，通常是减仓而非清仓。
- 机会成本最容易被滥用——"更好的机会"往往是事后才知道。

### 四种原因的和止盈止损的关系

| 卖出原因 | docs/08-exit.md 对应的规则 | 本文扩展 |
|:---------|:--------------------------|:---------|
| 论文到期 | 止盈规则（PE 历史分位、趋势反转） | 什么情况下到期也不卖（继续持有超预期的公司） |
| 论文失效 | 论文失效分级表 | 模糊地带处理方法（部分兑现、部分失效） |
| 机会成本 | 无 | 完整的新老标的比较框架 |
| 风险控制 | 止损规则 | 组合层风控（集中度、对冲、流动性压力） |

## 二、论文到期 vs 论文失效

这是最容易被混淆的一组概念。两者都触发卖出信号，但逻辑完全相反。

### 论文到期：逻辑兑现，价值回归

**定义：** 买入时的预期已经体现在价格中，后续上涨空间有限。

**经典场景：**

- **困境反转成功。** 比如买了处于周期底部的化工股，3个季度后行业供需改善，价格翻倍，研究报告中所有的正面预期都已实现。此时留下的风险是"反转结束后怎么办"——如果没有第二阶段的叙事，剩下的就是均值回归。
- **事件驱动落地。** 比如买了等待港股通开放的标的，开放后溢价消失，股价已经反映了流动性溢价。后续没有新的催化剂。
- **价值发现完成。** 市场已经按照你的逻辑重新定价了公司。比如你发现某只资产折价50%的股票，等到折价收窄到10-15%，说明你的研究优势已经耗尽。

**怎么办？** 取决于后续空间：

| 后续空间判断 | 动作 |
|:------------|:-----|
| 仍有增长动力（盈利持续增长消化估值） | 持有，但定期重审催化剂是否兑现 |
| 逻辑已尽但价格仍有惯性 | 减半仓，用剩下仓位走完趋势 |
| 逻辑已尽且价格开始走弱 | 清仓 |
| 公司基本面仍在改善且估值未泡沫化 | 减仓但不离场（参考 §4 分批退策略） |

**关键区分：到期不代表股价马上跌。** 公司可能因为基本面惯性继续上涨一段时间。但作为价值投资者，你应该问："如果现在我还没买，我会在这里建仓吗？"如果答案是否定的，就应该卖。

### 论文失效：逻辑已死，假设不在

**定义：** 买入的核心假设被新信息推翻。

**经典场景：**

- **监管改变竞争格局。** 买入互联网教育股时假设"监管环境稳定"，双减政策一出，核心假设直接崩塌。这是最清晰的论文失效——不是暂时的利空，而是行业规则的变化。
- **护城河被突破。** 买入某硬件公司时假设"技术壁垒3年不可跨越"，但竞争对手提前1年实现了同等性能。技术护城河的消失往往比商业模式护城河更突然。
- **核心人物离开。** 买入一家依赖创始人能力的公司，假设"核心管理层不会变动"，但创始人突然离职或健康出问题。这在深度价值投资中尤其致命——你投的就是这个人。

**如何处理：**

| 失效程度 | 判定标准 | 动作 |
|:---------|:--------|:-----|
| **核心论点推翻** | 买入论文中的1-2条核心假设不成立，且无法用其他假设替代 | 立即清仓，无观察期 |
| **关键假设动摇** | 一个重要的前提条件出现不确定性，但最终结果未定 | 降50%仓位，留一半观察1个季度 |
| **外围假设失效** | 非核心假设不成立，但核心逻辑仍在 | 降仓20-30%，重新评估估值 |

**立即清仓 vs 观察期的选择：** 当信息不对称对你极端不利时（比如发现了财务造假、行业政策180度转向），没有观察期——你的信息优势已经变成了信息劣势。当信息只是暂时不确定时（比如管理层变动但新CEO有类似背景、一个季度的业绩miss），可以降仓观察。

### 模糊地带：部分兑现 + 部分失效

这是投资中最难的场景之一，也是最容易导致决策瘫痪的地方。

**案例：** 买了某AI芯片公司，假设：
- 假设A：GPU需求增长50%（兑现50%）
- 假设B：该公司在新一代制程上领先两年（已失效，竞争对手追上来了）
- 假设C：估值30x PE合理（目前40x，偏高）

**决策树：**

1. 核心假设是什么？——如果假设B是你的核心论点（技术领先=定价权），那么B失效就是半条命没了。
2. 假设A兑现的程度能弥补B的损失吗？——如果需求增长超预期（80%）可以部分对冲竞争，那么可以保留一半仓位。
3. 新的价格是否已经反映了B的失效？——如果股价已经跌了30%，部分失效已被市场消化，继续持有可能OK。

**实操建议：** 画一个简单的表格——每个假设权重、兑现程度、剩余风险。如果加权兑现率 < 60%，就降仓。不做精确到小数点的数学，但必须做这个思考过程。

| 假设 | 权重 | 兑现度 | 加权得分 |
|:----|:----:|:------:|:--------:|
| 假设A: 需求增长50% | 40% | 50% | 20% |
| 假设B: 制程领先两年 | 40% | 10% | 4% |
| 假设C: PE 30x合理 | 20% | 40% | 8% |
| **加权合计** | 100% | — | **32%** |

32% < 60%，降仓。

## 三、机会成本换仓

> 世界上最贵的三个字是"万一涨了"。——Howard Marks

### 为什么难

机会成本卖出没有"错了"的外部信号。论文失效有明确的逻辑冲突，论文到期有价格的提示，但机会成本完全是内部比较：**你持有的东西没问题，你新发现的东西可能更好。**

这就是问题所在——"可能更好"永远无法在当前验证。

### 换仓决策公式

预期回报差 > 交易成本 + 税负 + 不确定性溢价

| 因素 | 含义 | 估算方法 |
|:----|:-----|:---------|
| 预期回报(A) | 新标的的年化预期回报 | L2a/L2b综合打分转换 |
| 预期回报(B) | 现有持仓的年化预期回报 | 同上（当前估值下的预期） |
| 交易成本 | 买卖佣金 + 滑点 | A股 ~0.1%，港股 ~0.2%，美股 ~0.05% |
| 税负 | 卖出实现的资本利得税 | A股暂免，港股 ~0.1%印花税，美股长期0%/短期最高37% |
| 不确定性溢价 | 新标的的不确定性高于老标的 | 建议 5-10% 年化额外要求 |

**简化版：新标的低估程度要比老标的深一倍的确定性，才值得换仓。** 如果一个标的低估20%你已经在持有，新标的至少低估40%才值得考虑换仓——因为你已经验证了老标的（认识偏误少），新标的还只是纸上分析。

### 实证：频繁换仓的代价

- **Terry Odean 1997-1999 研究：** 散户换仓频率越高，收益越低。换仓最多的散户年化跑输不动的投资者约 6%。因为他们倾向于卖出涨幅好的去追涨幅更好的，结果卖出的继续涨、买入的开始跌。
- **行为解释（禀赋效应 + 近因效应）：** 你持有3个月的标的，你对它的了解程度远低于你自认为的了解程度。每一个新标的看起来都更有吸引力，只是因为你还不了解它的缺点。

### 换仓检查清单

在决定换仓前，问自己：

1. 我认识这个"新机会"多久了？——如果少于2周，等。第一个月的激情最危险。
2. 这个新标的的缺点在哪里？——如果我说不出它最大的3个风险，我还没懂它。
3. 如果我清仓后新标的涨了20%，而老标的也涨了20%，我后悔吗？——如果后悔，说明我只是想换一个"涨得更快"的，而不是一个"风险回报更好"的。
4. 如果是全仓换，那新标的值得我放弃所有分散风险吗？——换仓建议分3次，每次间隔1周以上（见 §4）。

### 不卖也是一种仓位管理

有时候正确做法不是什么都不做，而是：**持有不动，新机会用小仓位建仓。** 这避免了"全有或全无"的二元思维——你不需要卖掉A才能买B。FengInvest 组合本来就有仓位的灵活性，只需在新标的的过轻仓位上开始建仓即可。

## 四、卖出执行

决定了"为什么卖"之后，要解决"怎么卖"的问题。

### 一次清 vs 分批退

| 场景 | 推荐方式 | 理由 |
|:----|:--------|:-----|
| 论文失效（核心推翻） | 一次性清仓 | 等待成本大于择时成本 |
| 论文到期（逻辑已尽） | 分批退（2-3次，每周1次） | 减少择时风险，平滑卖出价 |
| 机会成本换仓 | 分批退 + 分批建仓 | 双重平滑，避免全仓进出 |
| 风险控制（降集中度） | 按比例一次性减仓 | 控制目标明确，执行越干脆越好 |
| 流动性差的小票 | 分批退，大幅拉长周期 | 一日成交量 < 日均20x你的持仓时，一次清会砸穿 |

### 分批退的条件和节奏

**条件：** 当你对"要不要卖"有判断，但对"什么时候卖"没有判断时——分批退。

**三种节奏：**

1. **固定时间**：每隔N个交易日卖1/N仓位。最简单，不依赖价格判断。
2. **固定价格阶梯**：每上涨/下跌X%卖一部分。适合"越大越卖"的策略。
3. **混合型**：先卖一半（按时间），剩下一半等价格信号（如跌破均线、放量大阴线）。

**案例：** 重仓A股消费龙头，论文已兑现（估值从15x PE涨到25x），但公司基本面仍然优秀。

```
第1周：卖1/3 → 保留核心仓位
第2周：如果股价继续涨 → 再卖1/3
第3周：剩1/3作为"走完最后一程"仓位 → 设止盈止损条件单
总共：卖出2/3，保留1/3。
```

### 流动性考量

**小市值/低换手标的：**

- 持仓占日均成交量比例 ＞ 10% 就需要分批
- 使用 TWAP（时间加权平均）或 VWAP 策略，而非一次性挂单
- 避免财报前后、期权到期日等波动高峰
- 考虑使用大宗交易（港股/美股部分市场支持）

## 五、税务与持有周期

> 卖出决策中，税是确定性的，收益是不确定性的。忽视税收等于无偿给税务局送钱。

### 不同市场的税率差异

| 市场 | 短期（<1年） | 长期（>1年） | 特殊说明 |
|:----|:-----------:|:-----------:|:--------|
| **A股** | 暂免（个人） | 暂免（个人） | 印花税单边0.05%，换仓成本极低 |
| **港股** | 0%资本利得税 | 0%资本利得税 | 印花税双边0.1% + 交易征费，无持有周期优惠 |
| **美股（非美国居民）** | 按普通收入税率（最高37%）| 0%（非居民）| 非美国居民不需缴长期利得税！注意避让30天洗售规则 |
| **美股（美国居民）** | 最高37% | 最高20% | 净投资收入税再加3.8%，持有周期至关重要 |

**对中国大陆投资者的关键提示（注意：本文仅供参考，请咨询税务专业人士）：**

- 投资港美股的资本利得税规定因居民身份和账户类型不同而存在差异，卖出前应结合自身情况评估税务影响。
- **税务不应成为不卖的理由。** 不要为了"省税"而持有一只已经该卖的公司。
- 在边际税率高的年份，可考虑延后卖出或使用损失抵补。

### Tax-Loss Harvesting（税收损失收割）

**时机：** 通常在12月底（市场流动性较好且有时间调整仓位），或在个股出现20%以上回撤时。

**操作步骤：**

1. 卖出亏损的持仓，实现亏损
2. 用实现的亏损抵补已经实现的盈利，降低资本利得税
3. 遵守洗售规则（wash-sale rule）：卖出后30天内不买回相同或实质相同的证券（美股）

**A股的特殊性：** 目前个人投资者免征资本利得税，TLH在A股无意义。

### 捐赠/赠与的税务优化

持有大幅增值股票时，可以考虑捐赠增值股票代替现金捐赠：
- 捐赠者：无需缴资本利得税，可按市值抵扣捐赠额度
- 受赠方：免税接收

## 六、持有偏误检查清单

> 不愿意卖，很多时候不是因为理性分析，而是因为心理偏误。

每次卖出决策犹豫时，逐条检查：

### 1. 处置效应（Disposition Effect）

| 检查问题 | 常见表现 |
|:---------|:---------|
| 我是不是更愿意卖盈利的股票而不是亏损的？ | 过早卖出赢家，过久持有输家 |
| 我是不是因为"浮亏还没实现"所以不卖？ | 把浮亏当成未变现，影响客观判断 |
| 如果我现在持有现金，我会买这只股票吗？ | **最好的偏误检测问题**——如果不会，就卖 |

**偏差矫正：** 忘记买入价。当前的决策应该只基于"当前的估值+未来的预期"，和历史成本无关。

### 2. 锚定（Anchoring）

| 检查问题 | 常见表现 |
|:---------|:---------|
| 我是不是觉得"从高点跌了这么多，应该涨回来"？ | 以历史高点为锚，不关心基本面是否已经变化 |
| 我是不是觉得"比我买的时候便宜，所以是机会"？ | 以买入价为锚，不比较当前价格和当前价值 |
| 我是不是在等某个特定价格再卖？ | 看着25%等着回本就卖，股价跌到15%了还在等 |

**偏差矫正：** 把K线上的价格标记全部去掉。只看当前的基本面、估值和未来预期。

### 3. 禀赋效应（Endowment Effect）

| 检查问题 | 常见表现 |
|:---------|:---------|
| 我是不是给持有的股票更高的估值？ | 因为是"我的"所以觉得它比实际值钱 |
| 我是不是更关注这只股票的好消息？ | 选择性注意确认偏差 |
| 我是不是每天都在看持仓的新闻？ | 持仓在认知中的权重超过了它在组合中的权重 |

**偏差矫正：** 假设你从未买过这只股票，现在有机会买入——你要不要？如果你犹豫了，说明你不该持有。

### 4. 沉没成本（Sunk Cost Fallacy）

| 检查问题 | 常见表现 |
|:---------|:---------|
| 我是不是在"等回本"？ | "亏了这么多不想认输" |
| 我是不是在计算"如果我卖在这里就亏了X%"？ | 把已亏损算入未来决策 |
| 我是不是因为"已经持有这么久"所以继续持有？ | 时间投入造成的虚假承诺 |

**偏差矫正：** 过去的亏损是沉没成本，和未来的预期回报零相关。唯一应该问的问题是："从今天开始，持有这只股票的预期回报是多少？"

### 5. 信息偏差（Information Bias）

| 检查问题 | 常见表现 |
|:---------|:---------|
| 我是不是觉得"再多看一份报告就能决定"？ | 用收集信息替代做决策 |
| 我是不是反复打开同一个页面？ | 虚假的控制感 |
| 我买了之后是不是还在天天看？ | 买入之前没有做足功课，买入后不停担心 |

**偏差矫正：** 买入前的研究是最重要的决策输入。卖出的判断不需要和买入一样高的确定性——卖出时的信息从来不会齐全。如果你的买入逻辑三年后看起来是对还是错，你现在就有足够的信号。

## 七、与 FengInvest 框架集成

### 卖出信号从哪一层来

| 来源 | 信号类型 | 对应卖出原因 |
|:----|:---------|:------------|
| **L1 红灯** | 技术面极端（VIX飙升/放量暴跌/恐慌指数>40） | 风险控制（减仓而非清仓） |
| **M 层变化** | 宏观体制切换（从扩张到衰退、利率转向） | 风险控制（组合防守） |
| **L2a 变化** | 定性判断变化（护城河变窄、管理层更换、竞争格局恶化） | 论文失效（最核心信号） |
| **L2b 变化** | 定量指标恶化（营收增速转负、FCF缩水、ROE跌破阈值） | 论文失效/论文到期 |
| **L3 红灯** | 碰撞输出为红灯 | 重审买入逻辑，论文到期或失效 |
| **新标的出现** | L4报告中发现更高确定性机会 | 机会成本换仓 |

### 卖出流程

```
发现卖出信号
    │
    ├─ 来自 L1（市场情绪） → 检查组合集中度 → 考虑减仓 10-30%
    │
    ├─ 来自 M 层（宏观变化） → 重新评估行业/因子暴露 → 调整行业配比
    │
    ├─ 来自 L2a/L2b（基本面变化）
    │   │
    │   ├─ 核心假设还在？ → 继续持有，更新观察点
    │   ├─ 关键假设动摇？ → 降仓 50%，观察 1 季
    │   └─ 核心假设被推翻？ → 立即清仓
    │
    ├─ 来自 L3 红灯
    │   │
    │   ├─ 定性检查：这是短期噪音还是长期问题？
    │   ├─ 论文检查：碰撞引擎发现了什么我忽略的矛盾？
    │   └─ 执行决策：根据模糊地带处理框架操作
    │
    └─ 来自 L4 报告（定期重审）
        │
        ├─ 论文更新：重写买入论文（对比原始版本）
        ├─ 退出生效条件更新
        └─ 如果发现偏误 → 执行 §6 检查清单
```

### L4 报告中的退出策略部分

每个 L4 报告应包含退出策略，不仅包括 docs/08-exit.md 中的价格触发条件，还包括：

1. **论文有效期**：该论文的有效期预期（3个月/6个月/2年/持续跟踪）
2. **关键假设**：买入必须成立的前提条件（最多3条，标注权重）
3. **失效信号**：哪些具体信息出现意味着论文失效
4. **到期处理**：论文兑现后是否继续持有的判定标准
5. **重审节奏**：L1日频/M层周频/L2a季频的追踪安排

**模板：**

```
## 退出条件
- 论文类型: [困境反转/价值发现/成长买入/事件驱动]
- 论文有效期: [6个月]
- 核心假设(权重):
  1. [市场份额持续提升 50%]
  2. [毛利率回到30%以上 30%]
  3. [估值中枢至少15x PE 20%]
- 失效信号: [连续2季营收增速<10% / 毛利率<25% / 市值/FCF>35x]
- 到期动作: [若12个月内到达目标价 → 减半仓，剩下的观察6个月]
- 重审节奏: [L1每日 / L2b每月 / L2a每季]
```
