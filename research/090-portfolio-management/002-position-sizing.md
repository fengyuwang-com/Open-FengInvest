# 仓位计算方法论

> **仓位管理是投资中唯一可以完全控制的因素。** 选股决定赚不赚，仓位决定赚多少和亏多少。一个平庸的选股系统配合优秀的仓位管理，可以长期存活并盈利；一个顶尖的选股系统配合糟糕的仓位管理，迟早爆仓。

---

## 一、仓位计算的本质

### 1.1 为什么仓位比选股更重要

大多数投资者把 90% 的精力花在"买什么"上，只有 10% 花在"买多少"上。这是本末倒置的。

一个简单数学：假设两个策略——

| 策略 | 胜率 | 盈亏比 | 选股能力 | Kelly仓位 | 满仓下的最终财富 |
|:----|:----:|:------:|:--------:|:---------:|:---------------:|
| A | 60% | 1:1 | 一般 | 20% | +20%/次 |
| B | 40% | 3:1 | 较低 | 10% | +20%/次（同A） |
| C | 80% | 0.5:1 | 高选股 | 40% | +20%/次 |

结论：**不同胜率和赔率的组合，可以通过仓位调整达到相同的长期增速。** 选股者真正的优势不是"能看对"，而是"看对时押得多、看错时押得少"。

### 1.2 FengInvest 的仓位哲学

FengInvest 采用三条核心原则：

1. **凯利框架 + 分数化。** 从标准 Kelly 出发，通过分数化（1/4、1/8、1/16）处理模型不确定性，避免过度自信。
2. **置信度驱动。** 仓位大小直接来自 L3 碰撞输出的置信度（high/medium/low），每一档对应明确的 Kelly 分数和仓位区间。
3. **宏观/市场修正。** M 层的四灯（宏观、估值、趋势、情绪）和 L1 的纪律灯不改变置信度本身，但对仓位做乘法折扣。

## 二、Kelly 公式详解

### 2.1 标准 Kelly 公式

```
f* = (bp - q) / b
```

其中：
- `f*` = 最优仓位比例（占资金百分比）
- `b` = 赔率（盈亏比，即盈利时的收益除以亏损时的损失）
- `p` = 胜率（盈利概率）
- `q` = 败率（1 - p）

**例1：** 一个投资机会，60% 概率赚 20%，40% 概率亏 10%。
```
b = 20% / 10% = 2
p = 0.6, q = 0.4
f* = (2 × 0.6 - 0.4) / 2 = 0.8 / 2 = 0.4 = 40%
```
→ Kelly 建议押 **40%** 资金。

**例2：** 一个稳健机会，70% 概率赚 15%，30% 概率亏 8%。
```
b = 15% / 8% = 1.875
p = 0.7
f* = (1.875 × 0.7 - 0.3) / 1.875 = 1.0125 / 1.875 ≈ 0.54 = 54%
```

### 2.2 Kelly 公式的实际问题

标准 Kelly 在投资中存在三个致命缺陷：

| 问题 | 表现 | 后果 |
|:----|:-----|:-----|
| **参数不确定性** | 胜率 p 和赔率 b 都是估计值，不可精确知道 | 输入微小的偏差 → 仓位大幅偏离最优 |
| **尾部风险低估** | 标准 Kelly 假设收益分布是已知的（硬币/赌局），但股市有厚尾 | 黑天鹅事件下实际亏损远超模型预测 |
| **波动性** | 全 Kelly 会产生巨大回撤（即使长期增长最优） | 大多数人在回撤 50%+ 时放弃策略 |

**实测数据：** Thorp 在统计套利中使用 1/2 Kelly 就已经获得了接近最优的复合增长率，而最大回撤降低了一半。

### 2.3 Fractional Kelly（分数凯利）

```
f_fractional = f* × k
```

其中 `k` 是分数系数（0 < k ≤ 1）。

FengInvest 使用三个分数档位：

| 分数 | 含义 | 适用场景 | 理论最大回撤（vs 全 Kelly） |
|:---:|:----:|:--------|:-------------------------:|
| **1/4 Kelly** | 极其保守 | 高置信度，但市场估值偏高或宏观不确定 | 约 6-8%（假设全 Kelly 回撤 25-30%） |
| **1/8 Kelly** | 保守 | 中置信度，正常市场环境 | 约 3-4% |
| **1/16 Kelly** | 试探 | 低置信度或市场环境不利 | 约 1.5-2% |

**选择 1/4 作为最高分数的理由：** Pabrai 的 Dhandho 方法建议 1/10 Kelly 起步。FengInvest 作为体系化分析框架（非个人主观判断），置信度输出比个人投资者的股评式判断更可靠，所以采用略高的 1/4 作为上限，但仍然保守足够抵御厚尾风险。

## 三、FengInvest 置信度 → 仓位映射表

**这是仓位计算的核心。** L3 碰撞引擎输出的置信度直接映射到仓位区间。

### 3.1 基础映射表

| L3碰撞结果 | 置信度 | Kelly分数 | 可用资金占比 | 单只上限 | 典型场景 |
|:----------|:-----:|:---------:|:----------:|:--------:|:--------|
| **BUY 高置信** | >80% | 1/4 Kelly | 15-20% | 15% | L2a整体🟢+量化🟢+L1🟢+M层无🔴 |
| **BUY 中置信** | 60-80% | 1/8 Kelly | 5-10% | 8% | L2a整体🟢但M层🔴/量化分歧 |
| **BUY 低置信** | 40-60% | 1/16 Kelly | 2-5% | 5% | 好生意🟢+安全边际🟡/其他层🔴 |
| **WAIT** | <40% | 0 | 0% | 0% | 安全边际🔴/L2a信号矛盾 |
| **PASS** | — | 0 | 0% | 0% | 好生意/护城河 RED |

### 3.2 映射表推导过程

以 BUY 高置信场景为例，演示数据如何从 L3 走到仓位数字：

1. **L3 碰撞引擎输出：** `confidence = "high"`（对应 >80%）
2. **假设胜率 p：** 80%（按历史回溯，系统 BUY 高置信指令的实际胜率）
3. **假设盈亏比 b：** 2:1（预期收益 20%，止损 -10%）
4. **标准 Kelly 计算：**
   ```
   f* = (2 × 0.8 - 0.2) / 2 = 1.4 / 2 = 0.70 = 70%
   ```
5. **分数化：** `1/4 Kelly` → `70% × 0.25 = 17.5%`
6. **取整 ±纪律约束：** 15-20%。再叠加单只上限 15%（P 层约束），最终为 15%。

中置信和低置信同理：

| 步骤 | 高置信 | 中置信 | 低置信 |
|:----|:-----:|:-----:|:-----:|
| 系统置信度 | >80% | 60-80% | 40-60% |
| 假设胜率 p | 80% | 65% | 50% |
| 假设赔率 b | 2:1 | 2:1 | 2:1 |
| 标准 Kelly f* | 70% | 47.5% | 25% |
| Fractional k | 1/4 | 1/8 | 1/16 |
| 分数 Kelly | 17.5% | 5.9% | 1.6% |
| 建议仓位区间 | 15-20% | 5-10% | 2-5% |

可以直接根据具体的碰撞规则号查找仓位：

| Rule 2 | 好生意+护城河🟢+安全边际🔴 | WAIT | medium | 0% |

| Rule 4 | 好生意🟡+安全边际🟡+绝对低估 | BUY | medium | 5-10% |

## 四、多标的资金分配

### 4.1 信号冲突时的处理

当同时出现多个 BUY 信号时，不能简单累加所有仓位（那样会超过 100%）。

**分配原则：**

1. **排名优先。** 按置信度从高到低排序，先配高置信，剩余资金配中置信，最后低置信。
2. **机会成本比较。** 每增加一个仓位，等于放弃了同资金投入其他标的的预期收益。
3. **现金作为另类仓位。** 如果所有 BUY 信号的总仓位建议 < 50%，剩余资金默认留在现金。这不是"踏空"，而是持有 ATM 期权。

### 4.2 分配算法示例

**场景：** 资金 100 万，三个 BUY 信号同时出现。

| 标的 | 置信度 | 建议仓位 | 绝对值 |
|:----|:-----:|:--------:|:------:|
| A (腾讯) | 高 | 15% | 15万 |
| B (茅台) | 中 | 8% | 8万 |
| C (小米) | 中 | 8% | 8万 |
| **总建议** | | **31%** | **31万** |

总仓位 31% < 100%，**全部执行，剩余 69% 留现金。**

**场景2：** 极端拥挤。

| 标的 | 建议仓位 |
|:----|:--------:|
| A | 15% |
| B | 15% |
| C | 15% |
| D | 15% |
| E | 10% |
| F | 8% |
| **合计** | **78%** |

总仓位 78% → 需要砍掉一部分。砍仓规则：

1. 优先保留高置信（>80%）的标的
2. 同置信度内，保留赔率更高的标的
3. 同信同赔，保留与自己持仓相关性低的标的（分散化收益）
4. 砍到总仓位 ≤ 70%（牛市上限）或 ≤ 50%（中性市）

### 4.3 现金的战略价值

现金不是"什么都没做"。在 FengInvest 框架中，现金有三重战略价值：

1. **再平衡燃料。** 当市场崩盘、其他标的出现 BUY 高置信信号时，现金让你有子弹。没有现金的人被迫在高位减仓或低位割肉。
2. **心理缓冲。** 满仓时，一个 -20% 回撤就让资金缩水 20%。持有 30% 现金，同比例回撤只亏 14%，并且还能在低位加仓。
3. **期权价值。** 现金 ≈ 一个 0 成本的看跌期权 + 一个未来任意标的的看涨期权。你不需要为它付时间价值。

**现金比例参考（结合 M 层）：**

| M层综合 | 最低现金要求 | 含义 |
|:-------|:----------:|:----|
| 宏观 🟢 + 情绪 🟢 | 无强制 | 可满仓，但单只仍守15%上限 |
| 宏观 🟢 + 情绪 🔴 | 至少 20% | 市场过热，强制留现金 |
| 宏观 🔴 + 情绪 🟢 | 至少 30% | 宏观风险，保守 |
| 宏观 🔴 + 情绪 🔴 | 至少 50% | 全面防守，仅保留最高置信标的 |
| VIX > 30 或恐慌指数极值 | 至少 60% | 系统性风险，只做 Deep Value |

## 五、仓位调整规则

### 5.1 建仓：分批策略

所有 BUY 信号，无论置信度高低，**禁止一笔满仓。** 必须分批入场。

| 置信度 | 批次数 | 每批比例 | 间隔条件 |
|:------|:-----:|:--------:|:---------|
| 高置信 | 2-3 批 | 第一笔 50%，第二笔 30%，第三笔 20% | 每批间隔 ≥1 周，或价格下跌 3-5% |
| 中置信 | 3 批 | 第一笔 40%，第二笔 40%，第三笔 20% | 每批间隔 ≥2 周，或价格下跌 5-8% |
| 低置信 | 4-5 批 | 每笔 20-25%，小步试探 | 每批间隔 ≥1 月，或价格下跌 8-10% |

### 5.2 加仓条件

已经持有的标的，加仓必须同时满足以下 **全部** 条件：

1. **置信度不降级。** L3 重新碰撞后，置信度仍为 medium 或 higher。如果降为 low，不再加仓。
2. **基本面未恶化。** L2a 没有新出 RED 灯。
3. **距离上次建仓/加仓 ≥1 个月。** 避免追涨式加仓。
4. **加仓后不超单只上限（15%）。**

**加仓金额：** 每次加仓金额 = 该标的可用空间 × 0.5。例如已持 A 10%（上限 15%），则加仓金额 = (15% - 10%) × 0.5 = 2.5%。这防止"越跌越加"的凹性风险。

### 5.3 减仓条件

减仓分为三种：

**A. 主动减仓（机会成本驱动）**
- 该标的置信度从 high 降到 medium → 减至中置信仓位（5-10%）
- 从 medium 降到 low → 减至低置信仓位（2-5%）
- 从 low 降到 WAIT → 清仓观察

**B. 被动减仓（价格超涨）**
- 价格超过 L0/L2a 估值区间上限 20%+
  → 减仓该标的的 1/3
- 价格超过上限 50%+
  → 减仓 2/3 或清仓（视上涨逻辑是否延续而定）

**C. 止损减仓（保护性）**
- 单笔亏损达 **12-15%** → 砍掉该笔的 1/2（非全量）
- 该标的总亏损达 **20%** → 全部清仓，重新评估
  - 重新评估前必须先跑 L3 碰撞引擎，确认基本面逻辑是否被破坏
  - 如果 L3 仍输出 BUY（置信度不降），说明价格下跌是市场错杀 → 考虑加仓（走加仓流程）

### 5.4 调整频率

仓位调整不是每天做的事。FengInvest 的推荐频率：

| 操作 | 默认频率 | 例外条件 |
|:----|:--------:|:---------|
| 重新计算仓位 | 每月一次 | 市场出现 ±5% 以上单日波动时，加算一次 |
| 再平衡 | 每季一次 | 单只仓位因价格变动偏离目标 > 40% 时（如目标 10%，实际涨到 14%+） |
| 止损 | 持续监控 | 不需要等月度/季度，到了条件就执行 |

## 六、与 FengInvest 框架的集成

### 6.1 数据来源链

仓位计算依赖以下 FengInvest 组件：

```
L3 碰撞输出 ──────────────────────────→ 置信度 + 裁决
    ↓
读取 temp_l3_<TICKER>.json ──────────→ decision, confidence, position_pct
    ↓
M层 market data ─────────────────────→ 四灯（宏观/估值/趋势/情绪）
    ↓
L1 discipline ───────────────────────→ overall_light
    ↓
┌────────────────────────────────────────┐
│ 仓位计算器：                            │
│ confidence → Kelly分数 → 基础仓位        │
│ M层四灯 → 调整系数（乘法）               │
│ L1红灯 → 特殊规则（Deep Value路径）      │
│ P层约束 → 上限检查（单只≤15%，行业≤35%） │
└────────────────────────────────────────┘
    ↓
输出：每个标的的建议仓位 + 现金比例
```

### 6.2 M 层四灯调整系数

M 层的四个灯（宏观、估值、趋势、情绪）不改变置信度本身，但对仓位做乘法调整：

| M 层灯色 | 调整系数 | 含义 |
|:--------:|:--------:|:-----|
| 🟢 | × 1.0 (无调整) | 市场环境支持 |
| 🟡 | × 0.75 | 市场中性，正常打 75 折 |
| 🔴 | × 0.5 | 市场风险，打对折 |

**计算公式：**

```
最终仓位 = 基础仓位 × min(M_调整系数)
```

**示例：** BUY 中置信（基础 8%），M 层显示 宏观🟡 + 估值🔴 + 趋势🟡 + 情绪🟢。取最差灯 = 估值 🔴，调整系数 = 0.5。最终仓位 = 8% × 0.5 = 4%。

**为什么取 min（最差灯）而不是平均：** 四个灯只要有一个是红灯，就代表系统中存在一个可以独立导致亏损的风险因子。平均会稀释风险信号。

### 6.3 L1 红灯时的特殊处理

L1 红灯（discipline RED）是严格的。L1 RED 时，框架强制走 **Deep Value 路径**：

1. 除非 four conditions 全部满足（好生意 + 极端低估 + 非价值陷阱 + 回归催化剂），否则直接 PASS （仓位 = 0%）
2. 即使 Deep Value 条件全部满足，仓位上限也 **必须 ≤ 1/8 Kelly**，即最多 5-8%
3. 因为 L1 红灯说明系统性纪律信号被触发——即使有 Deep Value 机会，也默认不确定性极高，需要大幅折扣

**L1 RED 时的仓位对比：**

| 信号 | 正常仓位 | L1 RED 时仓位 | 折扣 |
|:----|:--------:|:-------------:|:----:|
| BUY 高置信 | 15% | 0%（Deep Value 条件不满足）或最高 8%（条件全满足） | × 0 或 × 0.53 |
| BUY 中置信 | 8% | 0% 或 5%（Deep Value 路径） | × 0 或 × 0.625 |
| BUY 低置信 | 5% | 0% | × 0 |

### 6.4 完整计算示例

**假设：** 标的 A（腾讯），100 万资金

**输入数据：**

| 维度 | 数据 |
|:----|:-----|
| L3 碰撞 | BUY, confidence=high |
| M 层 | 宏观 🟡 + 估值 🟡 + 趋势 🟢 + 情绪 🟢 |
| L1 | GREEN |
| P 层单只上限 | 15% |
| 预期盈亏比 b | 2:1 |
| 系统历史胜率 p | 82% |

**计算步骤：**

1. **基础 Kelly：** `f* = (2 × 0.82 - 0.18) / 2 = 1.46 / 2 = 73%`
2. **分数 Kelly：** 高置信 → 1/4 → `73% × 0.25 = 18.25%`
3. **M 层调整：** 最差灯 = 🟡 → 调整系数 0.75 → `18.25% × 0.75 = 13.69%`
4. **P 层上约束：** 单只上限 15%，13.69% < 15%，不触发
5. **取整：** 13.69% → **14%**
6. **分批建仓：** 第一笔 7%，一周后或跌 3-5% 第二笔 7%

**最终仓位：14%（14 万元），分 2 批入场。**

## 七、常见问题

### 7.1 要不要卖旧买新？

当新标的出现 BUY 高置信，但资金已满仓（或接近满仓）时：

1. 比较新旧标的的 **每风险单位超额收益** = 置信度 × 预期涨幅 / 预期跌幅
2. 只有当新标的大幅优于旧标的（比值 > 1.5 倍）时，才考虑换仓
3. 换仓节奏：分 2-3 批卖出旧标的、买入新标的，降低择时风险

### 7.2 如何处理已大幅盈利的仓位？

盈利浮盈本身不构成减仓理由。但需要考虑：

- 如果盈利后仓位占比因上涨而远超目标（比如目标 10%，涨到 18%），触发再平衡：
  - 卖出超出部分（8%），锁定利润
  - 保留目标仓位（10%）继续持有
- 这叫"卖出涨幅，保留本金"，是风险管理的常见做法

### 7.3 仓位计算的纪律

1. **不因情绪调整仓位。** 恐慌时按规则减仓，贪婪时按规则加仓。不要反过来。
2. **不因"这次不一样"而破例。** 每条规则都是回测和逻辑验证过的，临时破例往往后悔。
3. **不推迟止损。** 到了条件就执行，没有"再看看"。
4. **每次加减仓记录理由。** 形成可追溯的决策日志，用于复盘。
