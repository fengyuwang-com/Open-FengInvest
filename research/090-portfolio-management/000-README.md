# 090 — 组合与决策管理

## 服务于
L3 碰撞（仓位建议）| L4（报告中的仓位/风险部分）| P 层（组合管理）

## 核心作用

框架在 L3 碰撞输出 BUY/WAIT/PASS+置信度后，**090-portfolio-management/ 负责回答"然后呢？"**：

- 置信度 → 买多少？（仓位计算）
- 当前宏观体制 → 组合怎么配？（体制映射）
- 何时调整？（再平衡）
- 何时走？（卖出决策）
- 整体组合怎么搭？（构建哲学）

## 推荐阅读顺序

1. `001-portfolio-construction.md` — 组合构建哲学（先有框架，再谈细节）
2. `005-macro-regime-map.md` — 宏观体制映射表（决定方向性配置）
3. `002-position-sizing.md` — 仓位计算（具体买多少）
4. `004-sell-framework.md` — 卖出框架（何时走）
5. `003-rebalancing.md` — 再平衡（持续维护）

## 与 docs/09-portfolio.md 的关系

`docs/09-portfolio.md` 是 P 层的硬约束（三轴集中度阈值、资金池、资金墙=买入预算、杠杆/回撤）。本目录是这些约束背后的**方法论**，两者互补使用。实际盘面由 `python tools/fengportfolio.py check` 运行期计算。
