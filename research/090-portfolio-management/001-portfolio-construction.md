# 组合构建哲学

## 一、问题定义

组合构建回答一个简单但残酷的问题：**你有一篮子股票，凭什么是这一篮子？**

大多数投资者构建组合的方式是"看到好的就买"。结果是组合没有灵魂——它只是个人偏好的集合，不是经过设计的系统。

FengInvest 框架下的组合构建回答三个问题：

1. **选什么**（喂什么给组合）— L1/L2 的资产选择，L3 碰撞给出方向
2. **买多少**（如何分配）— L3 置信度映射到仓位，P 层硬约束兜底
3. **如何搭**（整体结构）— 本文件的核心：范式选择、角色分配、DNA 检查

没有第 3 步的组合，就是一袋互不相关的股票。

| 维度 | 说明 |
|:----|:----|
| **核心问题** | 组合的整体结构是经过设计的，还是偶然叠加的？ |
| **上层输入** | L3 碰撞输出的 BUY/WAIT/PASS + 置信度（0-100%） |
| **下层输出** | 给 P 层的仓位建议 + 给 L4 的组合结构分析 |
| **硬约束** | docs/09-portfolio.md: 三轴集中度阈值（market/segment/combo/单标）+ 资金池 + 资金墙=预算 |
| **关键假设** | 不同范式适合不同市场环境和投资者性格，没有绝对最优 |

## 二、三种核心范式的对比

### 核心-卫星（Core-Satellite）

最主流的机构范式。核心仓（50-80%）是被动或准被动的宽基持仓，卫星仓（20-50%）是主动选股的集中押注。

| 维度 | 说明 |
|:----|:----|
| **核心角色** | 提供市场贝塔，保证不跑输指数太多 |
| **卫星角色** | 提供超额阿尔法，用深度研究换取超额回报 |
| **典型做法** | 核心 = 沪深 300 + 纳指 100 ETF；卫星 = 5-8 只深度研究个股 |
| **适用场景** | 有选股能力但不想被个股风险炸毁 |
| **最大风险** | 卫星仓位过大 → 核心失去意义；卫星仓位过小 → 超额贡献可忽略 |

> **经验法则**：卫星每只仓位 2-5%，合计 20-30%。如果你选的卫星跑不赢核心，说明不应该有卫星。

### 杠铃（Barbell）

两端重注，中间不做。一端是极度保守的资产（国债、现金），另一端是极度激进的资产（小盘成长、困境反转、新兴市场）。

| 维度 | 说明 |
|:----|:----|
| **保守端** | 国债/高评级债 + 现金，占比 40-60%，提供稳定性 |
| **激进端** | 高 Beta 个股/行业，占比 40-60%，提供弹性 |
| **缺失中间** | 不做"稳健增长"——那是骗人的（Howard Marks 语） |
| **适用场景** | 市场不确定性高，或投资者对中间地带没有信心 |
| **典型例子** | 60% 短债 + 40% 小盘深度价值（如 Buffett 早期合伙基金） |

杠铃的核心洞察是：**中间地带的风险调整后回报最差**。所谓"稳健增长"的股票，跌的时候不比成长股少多少，涨的时候比不过，唯一的优点是心理安慰。

### 等权/分散（Equal-weight / Diversified）

没有超重押注。每只 3-5%，行业均匀分布，30-50 只持仓。

| 维度 | 说明 |
|:----|:----|
| **优点** | 单只踩雷影响有限，不需要深度研究每只，心理负担小 |
| **缺点** | 产生均值回报，永远无法超额；好机会被迫只买小仓位 |
| **适用场景** | 没有明确的选股优势，或管理资金量太大无法集中 |
| **最大陷阱** | 假分散：买了 30 只全是同一个板块的"伪分散" |

> **FengInvest 立场**：等权分散是默认选项，但不是最优选项。如果你没有研究深度，分散是对的；但如果你有深度研究却仍然分散，就是在浪费研究。

### 三种范式对比表

| 维度 | 核心-卫星 | 杠铃 | 等权分散 |
|:----|:---------|:-----|:---------|
| **最高信念股仓位** | 5% (卫星) | 10-15% (激进端) | 3-5% |
| **持仓数量** | 15-25 | 10-20 | 30-50 |
| **追求目标** | 市场回报 + 适度超额 | 大赚或保本，不做中等 | 市场回报 |
| **研究深度要求** | 卫星需要深度 | 两端都需要深度 | 低 |
| **最大回撤** | 25-35% | 25-45% | 30-40% |
| **能否击败指数** | 能（卫星做对时） | 能（方向做对时） | 很难 |
| **维护工作量** | 中 | 中-高 | 低 |

**没有绝对最优范式**。选择取决于你的研究深度、市场信念、和心理承受力。

## 三、集中 vs 分散的数学

### 凯利视角下的集中度

凯利公式给出数学上的最优下注比例：

```
f* = (bp - q) / b

f* = 最优仓位比例
b = 赔率（预期上涨幅度 / 预期下跌幅度）
p = 胜率
q = 1-p = 败率
```

举例：你研究出某只股票有 60% 概率上涨 50%，40% 概率下跌 20%：

```
f* = (0.5 × 0.6 - 0.4) / 0.5 = (0.3 - 0.4) / 0.5 = -0.2
```

凯利给出 **不要押注**——因为期望值不足。反过来，如果概率是 70% 涨 50%、30% 跌 20%：

```
f* = (0.5 × 0.7 - 0.3) / 0.5 = (0.35 - 0.3) / 0.5 = 0.10
```

凯利说 10% 仓位。

关键启示：

1. **凯利天然反对过度分散**。如果你的研究真有信息优势，凯利会让你集中在少数机会上
2. **凯利天然反对过度集中**。除非胜率和赔率都极高，否则 f* 很少超过 20%
3. **Fractional Kelly** 是实践者共识。用 1/4 或 1/2 Kelly：如果你已经用了 Fractional Kelly，再加 P 层的 20% 上限，实际仓位不会超过凯利的 10-15%

### 持有多少只股票最优？

| 持仓数 | 组合波动率（相对市场） | 单只踩雷影响 | 超额潜力 |
|:-----:|:-------------------:|:----------:|:--------:|
| 1 | 300%+ | 毁灭性 | 极高 |
| 5 | ~150% | 严重 | 高 |
| 10 | ~120% | 可控 | 中 |
| 20 | ~110% | 低 | 中低 |
| 30 | ~105% | 极低 | 低 |
| >50 | ~100%（市场水平） | 可忽略 | 极低 |

研究证据（Evans & Archer 1968 的经典结论，后续被反复验证）：

- **10-15 只消除大部分非系统风险**。超过 15 只后，分散化收益急剧递减
- **30 只后基本无分散化收益**。再增加只是买了个心理安慰
- **核心-卫星的最佳点位在 15-25 只**：核心提供市场暴露，卫星提供超额

FengInvest 的结论：**15-25 只是最优区间**。少于 10 只风险太集中，多于 30 只超额被分散光。

### 行业集中度的量化思考

不要用感性判断"科技股太多了"。用数字定义——且按**正交轴**计算，不用单一"行业"桶：

```
集中度 = 按轴分组求和（占总资产%）
```

| 维度 | 🟡 黄（关注） | 🔴 红（超配） |
|:-----|:---:|:---:|
| market 轴 | >28% | >35% |
| segment 轴（细分板块） | >20% | >25% |
| market×segment 组合 | >15% | >20% |
| 单只标的 | >15% | >20% |

超过红线必须回答：**如果这个 segment 跌 40%，组合能承受吗？**

> **不做假分散**：买了 8 只科技股 + 2 只金融科技（本质还是科技）+ 1 只新能源科技（本质还是科技）= 11 只科技股，不是分散。
> **细分到风险驱动**：GICS 大类分不开 NVDA（逻辑/AI算力 fabless）与 Micron（存储 IDM 强周期）——segment 必须细到能区分同行业内不同风险驱动的标的（存储/代工/设计），词汇可扩展。

## 四、根据投资者类型选择范式

### 激进型：集中核心-卫星

| 维度 | 建议 |
|:----|:----|
| **核心** | 30-50%，宽基 ETF（沪深 300 / 纳指 100）|
| **卫星** | 50-70%，5-10 只深度研究个股 |
| **单只最大** | 15%（P 层上限 20%，这里自设更严）|
| **segment 轴上限** | 25%（P 层红线，这里自设更严）|
| **资金池** | 15-25%（真现金+准现金，市场高估时提升）|
| **适合条件** | 2 年以上研究经验的投资者，有 3 只以上深度覆盖的能力圈 |

L3 输出 BUY-高置信（80%+）时，激进型可在 P 层上限内执行。每只卫星必须有持续跟踪报告，否则视为 P 层违规。

### 稳健型：杠铃

| 维度 | 建议 |
|:----|:----|
| **保守端** | 40-50%，短债/货基/国债 ETF |
| **激进端** | 30-40%，5-10 只高信念个股 + 行业 ETF |
| **灵活端** | 10-20%，视市场机会调整 |
| **单只最大** | 10% |
| **segment 轴上限** | 25%（P 层红线）|
| **适合条件** | 有研究能力但不想承担大波动，或市场处于极端不确定时期 |

> 杠铃不等于"一半现金一半股票"。保守端必须是真正低风险资产（短债、国债），不是"我觉得防御型股票也算保守"。股票就不是保守资产。

### 保守型：高分散，ETF 为主

| 维度 | 建议 |
|:----|:----|
| **ETF** | 70-80%，覆盖宽基 + 行业 + 债券 |
| **个股** | 20-30%，3-8 只研究最深的标的 |
| **单只最大** | 5% |
| **segment 轴上限** | 20%（自设更严）|
| **资金池** | 15-20% 参考（真现金+准现金，非硬底线）|
| **适合条件** | 刚开始或管理他人资金，或者知道自己没有超额能力 |

保守型不需要频繁操作。季度再平衡 + 半年审视即可。

## 五、组合 DNA 框架

### 每个持仓的三个角色

FengInvest 要求每个持仓**显示标注角色**。你买入的每只股票必须回答：它在这个组合里扮演什么角色？

| 角色 | 定义 | 典型标的 | 预期回报 | 最大容忍下跌 |
|:----|:----|:---------|:-------:|:----------:|
| **增长引擎** | 提供组合的核心阿尔法，高信念、高集中 | 深度研究个股 | 15-25%/年 | -30% |
| **稳定器** | 降低组合波动，提供分红或防御属性 | 消费龙头、公用事业、短债 | 6-10%/年 | -15% |
| **对冲** | 在极端情景下保护组合 | 黄金、国债、看跌期权 | 0-5%/年 | -10% |
| **现金** | 干火药，等待机会 | 货基、短期逆回购 | 2-4%/年 | 0% |

### 组合层面的角色平衡

一个健康组合的角色配比参考：

| 投资者类型 | 增长引擎 | 稳定器 | 对冲 | 现金 |
|:---------:|:-------:|:-----:|:----:|:---:|
| 激进 | 50-60% | 15-20% | 5-10% | 15-20% |
| 稳健 | 25-35% | 30-40% | 5-10% | 20-25% |
| 保守 | 10-20% | 45-55% | 10-15% | 15-20% |

**角色失衡信号**：

- 增长引擎 > 70%：你是在赌博，不是在投资
- 没有稳定器：市场回调 20% 时你会失眠
- 没有对冲：但不需要所有人都有对冲——如果你认为近期无尾部风险，可以暂时不加
- 现金 < 10%：资金池太薄，失去了下跌时加仓的能力

### 如何检查组合"有没有灵魂"

每季度执行一次"组合 DNA 审计"，回答 5 个问题：

1. **你的组合有主题吗？** 如果说不出"我的组合偏重 XX 主题（如国产替代、老龄化、AI 应用）"，就是没有灵魂
2. **最大仓位的那只股票你真正懂吗？** 如果只能说出"估值低"或"行业好"这种泛泛理由 → 它在组合里的位置有问题
3. **组合里有没有让你睡得着的资产？** 如果没有稳定器，全仓都是进攻型，那你的回撤控制靠什么？
4. **去掉涨幅最高的 3 只，组合还成立吗？** 如果去掉就崩了，说明之前的盈利掩盖了结构缺陷
5. **当前组合是你主动设计的，还是偶然积累的？** 逐笔检查买入记录——如果是"看到好的就买了"组成的组合，强烈建议推到重建

> **FengInvest 不认可"组合不需要检查"的观点。** 检查不是对过去的否定，而是对现在的清醒认识。

## 六、与 FengInvest 框架的集成

### L3 碰撞输出如何输入组合构建

L3 碰撞的输出是一个元组 `(决策, 置信度)`，其中决策 ∈ {BUY, WAIT, PASS, SELL}。

```
L3 输出                    组合构建输入
─────────────────────────────────────────────
BUY + 置信度 80%+     →   增长引擎候选，仓位 10-20%
BUY + 置信度 50-80%   →   增长引擎或稳定器，仓位 5-10%
BUY + 置信度 <50%     →   谨慎观察，仓位 2-5%（或放入等待池）
WAIT                  →   不买入，放入观察清单
PASS                  →   禁止买入，12 个月内不得复议
SELL                  →   启动卖出流程（见 004-sell-framework.md）
```

具体流程：

1. L3 输出 BUY → 组合构建检查：
   - 当前该角色仓位是否已满？（如增长引擎 > 60%）
   - 与现有持仓的相关性是否过高？（P 层规则：>0.8 降仓位，>0.9 不增）
   - 如果是新行业，行业集中度是否超标？
   - 现金是否充足？
2. 通过检查 → 分配仓位，标记角色
3. 未通过 → 降级为 WAIT，记录原因

### L4 报告中的组合部分

L4 报告中应包含：

1. **当前组合结构**：增长引擎 / 稳定器 / 对冲 / 现金 的比例
2. **集中度仪表盘**：最大持仓占比、前 5 持仓占比、行业集中度
3. **与 L3 输出的对应关系**：最近 3 次 L3 碰撞的持仓是否符合预期表现
4. **组合 DNA 审计结果**：5 个问题的回答
5. **范式选择的合理性检查**：当前范式是否仍然适合市场环境？

### 组合构建的决策树

```
L3输出BUY
  ├─ 已有该仓位且达标 → 持有不增
  ├─ 已有该仓位但超涨 → 检查是否需要减仓
  ├─ 已有该仓位但超跌 → 检查基本面是否变化
  │   ├─ 变坏 → SELL
  │   └─ 未变 → 可加仓（L3高置信下）
  ├─ 新标的
  │   ├─ 同行业已有足够暴露 → 降仓位或等待
  │   ├─ 新行业且集中度达标 → 分配仓位，标记角色
  │   └─ 行业集中度超标 → WAIT，除非替换同行业更弱标的
  └─ 资金池不足（现金+准现金 < 15%）→ WAIT，除非其他持仓卖出腾出现金
```
