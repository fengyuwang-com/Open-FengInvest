# AI 学习工具和方法

> AI 最好的角色不是"给你答案"，而是"帮你更好地思考和理解"。

---

## 模式 1：AI 做 PPT/课件（读完一本后）

**适用场景：** 读完一本书，让 AI 帮你整理成课件，用来复习或讲给别人听。

**怎么做：**

```bash
# 方法 A：直接喂 AI 你的笔记（推荐）
在对话中粘贴你的读书笔记
→ "基于这些笔记，帮我做一份 10 页的 PPT 大纲，每页一个核心概念"

# 方法 B：AI 凭知识做（不推荐，可能不准）
"用《投资最重要的事》的核心内容，做一份 8 页 PPT
每页格式：
- 第 1 页：标题 + 一句话核心
- 第 2-7 页：每个关键概念 + 一句话解释 + 实战中的使用
- 第 8 页：总结 + 行动清单"
```

**输出保存到：** `outputs/课件-<书名>-<日期>.md`

## 模式 2：AI 当教练（学习中）

**适用场景：** 读到一个不理解的概念、想测试自己的理解、想讨论观点。

**对话示例：**

```
我：我刚读完《聪明的投资者》第 8 章"市场先生"。
    我想测试我是不是真懂了。你扮演一个投資者，
    我扮演市场先生。我们对话 5 轮，然后你给我反馈。
```

或：

```
我：我刚读完《投资最重要的事》关于"风险"的章节。
    帮我出 5 道判断题，测试我是否真的理解了 
    高风险≠高回报 这个核心概念。
```

或：

```
我：我在分析腾讯。我觉得它的护城河是网络效应。
    但我不确定。你帮我用芒格的 25 个心智模型
    逐一对照，看有什么遗漏。
```

## 模式 3：AI 测试你的理解（读完后）

**适用场景：** 确认自己真懂了，不是在"以为自己懂了"。

**怎么做：**

```
我：我刚读完《彼得·林奇的成功投资》关于 
    6 种公司分类的章节。帮我出 10 道题：
    - 5 道匹配题（给公司描述，匹配类型）
    - 5 道案例题（给真实公司，判断类型+理由）
    我不急着要答案，先让我自己答。
```

或：

```
我：我刚学完"安全边际"的概念。给我 3 个真实场景，
    让我判断有没有安全边际。我说完后你再给正确答案。
```

## 模式 4：AI 做案例分析（结合实战）

**适用场景：** 刚学了一个概念 → 找现实中的例子来验证。

**怎么做：**

```
我：我刚学完"护城河"的 5 种类型（品牌/转换成本/
    网络效应/规模优势/技术壁垒）。从 A 股或港股中
    各找一只代表性的股票，说明它属于哪种护城河。
    不要一次性全告诉我——每次给我一只，让我先猜，
    你再揭晓。
```

或：

```
我：我学完了周期理论。帮我看看现在的宏观数据，
    我们处于什么周期位置？我说我的判断，
    然后你给反馈。
```

## 模式 5：魔鬼代言人（最重要）

**适用场景：** 你已经有了一个观点，需要被挑战。

**怎么做：**

```
我：我认为腾讯目前值得买入，理由是……
    现在你扮演完全反对我的人。用芒格的"反过来想"
    方法，逐条反驳我。不要客气。
```

或：

```
我：我想在当前市场加仓。你扮演市场先生，
    用最悲观的方式说服我不要加。
```

**这个模式是防止"确认偏误"最有效的方法。** 每次你有了一个投资判断，强制做一次魔鬼代言人。

## 模式 6：AI 做回溯复盘

**适用场景：** 分析了一个股票，3-6 个月后回头看。

**怎么做：**

```
我：这是我 3 个月前对腾讯的分析（附 temp 文件）。
    现在股价是 XXX。帮我分析：
    1. 当时判断中哪些对了？哪些错了？
    2. 错的原因是什么？（缺数据/偏误/不可预见？）
    3. 我的 check list 应该加一条什么？
```

## 模式 7：每日/每周学习计划

```
我：我目前在读《穷查理宝典》第二阶段。
    帮我安排接下来一周的学习计划：
    - 每天 30 分钟
    - 周一三五读书，周二四做 AI 测试，周末实战分析
```

## 原则

| 该让 AI 做的 | 不该让 AI 做的 |
|-------------|---------------|
| 总结和整理你读过的东西 | 替你读书 |
| 出题测试你的理解 | 编造不存在的数据 |
| 挑战你的观点 | 替你做投资决策 |
| 帮你找案例 | 用自己的判断冒充权威 |
| 做 PPT/课件 | 写你没读过的书的"摘要" |

**核心只有一条：你在前面带路，AI 在边上辅助。反过来就完了。**
